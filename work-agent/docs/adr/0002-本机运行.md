# ADR-0002 本机运行

- 状态：已接受（ADR-0008 补充：个人节点仍然本机运行，另外可以选择接入共享空间；ADR-0014 补充：“本机”包括 macOS 和 Windows）
- 日期：2026-11-18
- 决策者：用户

## 背景

工作数据涉及公司信息。云端部署需要处理合规问题，而且数据会落在第三方服务器上。

## 决策

agent 运行在用户自己的电脑上（macOS 或 Windows，见 ADR-0014）：数据存本机，凭证存系统凭证库，OAuth 回调走 `127.0.0.1` 回环地址。

## 影响

- 电脑开着时才能执行定时任务。
- 本地服务要防 DNS 重绑定和跨站请求伪造（校验 Host、Origin）。
- 如果 Q2 选择团队使用，需要新 ADR 重新划定边界。
