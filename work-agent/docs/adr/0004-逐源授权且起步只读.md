# ADR-0004 逐源授权且起步只读

- 状态：已接受（第 4 条被 ADR-0007 取代：写操作必须经用户决定后执行）
- 日期：2026-11-18
- 决策者：用户

## 背景

用户要求：自己授权之后，系统才能读取数据。

## 决策

1. 每个数据源单独授权：飞书、Google 用 OAuth 授权码流程（带 PKCE 校验）；GitLab 用只读个人访问令牌（`read_api`）。
2. 申请最小权限：Gmail 只要 `gmail.metadata`（只读邮件头，不读正文）；飞书起步只要 `calendar:calendar:readonly` 和 `offline_access`。
3. 用户可以随时断开某个数据源，断开时删除凭证。
4. 第一阶段不对外部系统做任何写操作。

## 影响

- 需要读正文或消息的能力，要扩大权限范围，用户也要重新授权。
- 写操作的引入由 Q1 决定，需要新 ADR。
