# ADR-0001 文档驱动与决策记录

- 状态：已接受
- 日期：2026-11-18
- 决策者：用户

## 背景

系统会持续扩展，由多个会话并行设计和实现。没有统一依据的话，各模块会互相偏离，后期扩展容易受底层限制而大面积返工。

## 决策

1. 所有架构、决策、模块设计、评审都写在 `docs/` 下，作为审查依据和统一执行标准。
2. 主会话担任总架构师，负责总体架构、跨模块接口、ADR 和一致性审查。
3. 模块详细设计由并行会话按 `architecture/` 的约定编写，经审查批准后才能实现。
4. 已接受的 ADR 不改写，只能由新 ADR 取代。

## 影响

- 前期速度会慢一些，换来跨会话一致和可追溯。
- 流程细节见 `docs/README.md`。
