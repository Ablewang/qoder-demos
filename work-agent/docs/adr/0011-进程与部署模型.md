# ADR-0011 进程与部署模型

- 状态：提议（随总体架构一起评审）
- 日期：2026-11-18
- 提议者：总架构师

## 决策

1. **两个常驻进程**：
   - **大脑** `work-agentd`（Node）：内核、能力、调度、记忆、伙伴、本地接口、Web 控制台都在这里。登录时自动启动，崩溃后自动重启。由 MOD-01 的平台适配负责：macOS 用 launchd 的用户级 LaunchAgent，Windows 用当前用户的登录启动项（ADR-0014）。
   - **脸** 宠物客户端（Tauri 2）：登录时自动启动。退出宠物不影响大脑运行；大脑不在时，宠物显示“睡着了”，并提供“唤醒”按钮，点了就让平台适配启动大脑。
2. **自研连接器作为大脑的子进程**，通过 stdio 走 MCP 协议；开发和测试时可以在同一进程内运行。
3. **本地接口**只绑定 `127.0.0.1`，必须认证（约束 I18）。
4. **命令行**是大脑的薄客户端，也可以离线执行维护命令（迁移、导出、重新索引记忆）。
5. **定时任务考虑电脑休眠**：唤醒后按任务配置补跑一次或跳过；每个任务的上次执行时间都要持久化。
6. **飞书实时事件**（消息、卡片回调）优先用飞书“长连接”模式，由大脑主动连出，不需要公网地址（卡片回调能否走长连接待 Q6 验证）。
7. **安装包**：两个平台各出一个安装包，里面包括宠物客户端、大脑和 Node 运行时。首次运行时引导用户：设定人格 → 授权数据源 → 注册开机自启。

## 影响

- 平台适配要提供“开机自启”的安装、卸载、状态查询，以及“唤醒大脑”。
- 合盖或休眠期间没有实时处理；唤醒后靠增量同步追上。
