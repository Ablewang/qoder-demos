# ADR-0005 首批数据源

- 状态：已接受
- 日期：2026-11-18
- 决策者：用户

## 决策

| 数据源 | 接入方式 | 已核对的接口 |
|---|---|---|
| 飞书 | 复用用户已有的企业自建应用，以用户身份授权 | 授权页 `accounts.feishu.cn/open-apis/authen/v1/authorize`；换取凭证 `accounts.feishu.cn/oauth/v3/token`（v2 已标为历史版本）；日历用“查询日程视图” `GET /calendar/v4/calendars/:id/events/instance_view`（重复日程会展开成实例，时间跨度须小于 40 天，实例数少于 1000） |
| Gmail | 公司 Google Workspace 账号；Google Cloud 里创建“内部”类型、桌面应用客户端 | `gmail.metadata` 权限；`users.messages.list` 加 `messages.get?format=metadata` |
| GitLab | 公司自建实例，只读个人访问令牌 | `GET /api/v4/events`、`GET /api/v4/projects/:id` |

## 已知限制

- 飞书日程视图接口不返回当前用户的回复状态，已拒绝的会议也会计入。
- `gmail.metadata` 权限不支持 `q` 搜索参数，只能按时间倒序翻页。
- 飞书消息能否读取待 Q4 验证。
