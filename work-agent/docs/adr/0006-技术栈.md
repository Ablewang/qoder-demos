# ADR-0006 技术栈

- 状态：提议（随总体架构一起评审）
- 日期：2026-11-18
- 提议者：总架构师

## 提议

| 方面 | 选择 | 理由 |
|---|---|---|
| 后台进程语言与运行时 | TypeScript，Node 24 原生类型剥离直接运行 | 不需要构建步骤；飞书、GitLab、Google 的 SDK 和 MCP 生态都支持 TS |
| 后台进程分发 | Node 运行时随安装包打包（ADR-0014） | 用户不用自己装 Node；macOS 和 Windows 一致 |
| MCP | 官方 TypeScript SDK（支持 2026-07-28 的版本） | ADR-0009 |
| 本地存储 | `node:sqlite` | Node 内置，没有原生依赖；已验证 FTS5 trigram 能检索中文，也支持 `loadExtension`，以后可以接向量扩展 |
| 记忆 | Markdown 文件为准，SQLite 建索引 | ADR-0013 |
| 凭证 | 凭证库接口加跨平台 keyring 实现（候选 `@napi-rs/keyring`：macOS 钥匙串、Windows 凭据管理器） | ADR-0014；凭证不落明文文件，也不会出现在进程参数里 |
| 宠物客户端 | Tauri 2（界面用 TS，平台层用 Rust） | ADR-0015 |
| Web 控制台 | 由后台进程的本地 HTTP 服务提供；前端形态由 MOD-08 设计决定 | |
| 测试 | `node:test`；宠物客户端的测试方案由 MOD-12 决定 | |
| 类型检查 | TypeScript 7（`tsc`） | |
| 运行时校验 | 待定：引入 JSON Schema 校验库还是手写，由 MOD-01 决定 | 实体结构、连接器返回、模型输出、人格档案都需要在运行时校验 |

## 待评审的点

- `node:sqlite` 仍标记为实验特性。
- `@napi-rs/keyring` 是原生模块，要验证它在 Node 单文件打包或附带进程方式下能不能正常加载。如果不行，退而用平台命令（macOS 用 `security`，Windows 用 PowerShell 调用凭据管理器）。
