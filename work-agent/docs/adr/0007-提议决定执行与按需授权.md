# ADR-0007 自主程度：提醒、起草、给选项，用户决定后自动执行，需要时按需授权

- 状态：已接受
- 日期：2026-11-18
- 决策者：用户
- 关闭问题：Q1

## 背景

用户原话：“负责提醒、起草，给我选择，让我决策以后自动执行，如果需要授权则发起授权。”

## 决策

1. agent 的输出分三种：
   - **通知**：只提醒，不做任何动作；
   - **报告**：汇总分析；
   - **提议**：给出一个或多个可执行选项，选项里包含起草好的内容。
2. 提议必须由用户做出决定（选择一个选项，可以先编辑草稿），系统才自动执行该选项包含的所有动作。
3. 执行时如果发现权限不够，系统暂停执行，向用户发起授权请求；用户授权后从暂停处继续，不需要重新决定。
4. 第一版**不允许**无人确认的自动执行。“某类动作以后都自动执行”这类常设规则，等到以后由新 ADR 引入，策略接口先预留。
5. agent 用自己的机器人身份给用户本人发通知，不属于“以用户身份对外写入”，不需要审批。

## 影响

- 需要“提议—决定—执行—审计”这一层（`architecture/contracts.md` 第 5 节），这一层属于底层，第一阶段就要设计。
- 授权代理要支持增量授权：飞书重新授权时带上新的权限；Google 用 `include_granted_scopes=true`。
- 取代 ADR-0004 第 4 条“第一阶段不做任何写操作”：写操作可以做，但只能经过用户决定。
