# ADR-0021 桌宠本机权限与启动收口

- 状态：已接受，待实现验证与桌面实测
- 日期：2026-11-19
- 决策者：总架构师（用户已授权技术自评）
- 补充：ADR-0015、先行版协议 §2、§9；仅修改项目内 Tauri 权限，不更改 Qoder 或系统权限

## 背景

native 复评发现自定义命令没有独立 ACL、运行时 PATH 与 Node 环境可影响后台唤醒、相对数据目录不一致、固定临时文件跟随符号链接、外部拖动被点击穿透判断截获，以及几何与快捷键更新缺少边界保证。

## 决策

1. 在 Tauri AppManifest 登记全部自定义命令并生成默认拒绝的命令权限；项目 capabilities 按 pet、panel、bubble 的实际调用分配。替换 `core:default` 为实际调用所需的事件、资源、菜单和窗口权限，不提供通用文件、shell 或 Internet 权限。不得修改系统或 Qoder 全局权限。
2. Node 的可信绝对路径在本机开发构建时确定并校验主版本为 24；可由明确的构建变量指定，否则仅在构建时解析已授权开发环境中的 Node。运行时不遍历 PATH 选择可执行程序，使用该构建路径并再次校验版本。此切片仍为本机源码开发运行，不宣称可分发给其他电脑。
3. 后台子进程清空环境，再构造必要的 HOME、系统 PATH、TMPDIR、LANG 等非凭证字段与明确的 WORK_AGENT_DATA_DIR、WORK_AGENT_PORT、WORK_AGENT_DEV_ORIGINS、WORK_AGENT_LOG 配置；不继承 NODE_OPTIONS、NODE_PATH 或公司凭证。输入为 null；不将原始 stdout/stderr 直接持久化，启动诊断仅保存固定元数据及批准的脱敏日志字段。
4. WORK_AGENT_DATA_DIR 相对值统一按仓库根解析；客户端和唤醒子进程使用同一绝对目录。客户端目录、设置与日志文件拒绝符号链接，设置使用独占创建的唯一临时文件、0600 权限、同步写和原子 rename；不覆盖其他目录。
5. macOS 使用绝对 `/usr/bin/security` 和 `/usr/bin/open`；令牌只在内存中，校验格式，不输出凭证。Windows 凭证与窗口枚举继续明确 unsupported，不降级明文。
6. 初次显示宠物前设置点击穿透。鼠标按键若在团子之外开始，则整个按键序列保持穿透，不能因为拖过命中区截获；气泡也遵循外部拖动规则。轮询竞态仍需实际 OS 验证，不以模拟证明彻底正确。
7. show_aux 与 set_hit_areas 输入必须有限数值、正尺寸、有界数量，窗口几何约束在可用显示区域，命中区域按宠物尺寸限制。边界失败返回通用错误，不访问屏幕内容。
8. 快捷键更换先尝试新注册，成功后注销旧键；同键保持不变，失败保留原键。不注销非本应用持有的快捷键。

## 验证

要求离线 Rust 单测覆盖数据路径、符号链接、临时写、几何、外部拖动状态、环境白名单与诊断脱敏；Cargo 编译验证 ACL 配置。禁止测试读取真实 Keychain 或启动可见 app。焦点、Spaces、DPI、多屏、后台存活和实际拖动仍保留未实测状态。
