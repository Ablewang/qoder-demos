## 实际验证

1. 交付后复跑 `node --disable-warning=ExperimentalWarning --test test/memory/memory.test.ts`：23/23 通过。
2. 修复 RMC-01 后同一命令：24/24 通过，失败 0；耗时约 1.17 秒。
3. `npm run typecheck`：退出码 0，无诊断。后台和客户端仍在开发，这不是它们的交付验收。
4. 临时 fixture 中创建一条带 evidence/about 的事实及一条已认证规则，清空短期证据、mem_fts、mem_items、mem_files 后 reindex：规则未恢复，事实 evidence 数组变为空、about 丢失，并产生一条规则 issue。未触碰用户实际数据。
5. 保留 mem_items 时的普通 reindex 能保留 evidence/about，且不删除墓碑；不把该结果等同于完整索引丢失后的恢复。
