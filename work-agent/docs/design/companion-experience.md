# 团子伙伴体验规格 v1

- 状态：已批准（产品方向）；实现尚未验收
- 日期：2026-11-19
- 依据：ADR-0016

## 1. 桌面生活

团子不是只在有通知时出现的机器人。空闲时可以趴着、揉脸、伸懒腰、玩小球、戴耳机轻轻摇晃或打盹，鼠标靠近会看向鼠标，摸头会舒服地眯眼，拖起时会抱紧自己的小道具。动作不索取注意力，不追着鼠标挡住操作。

| 场景 | 表现 | 边界 |
|---|---|---|
| 窗口边停靠 | 身体趴在窗口上沿，爪子搭边；气泡朝有空间的一侧展开 | 只用窗口几何，不读窗口内容；窗口消失时返回桌边 |
| 自己玩耍 | 安静地玩球、看小本子、伸懒腰，短动作之间有停顿 | 可降低频率、关闭或固定位置；不移动系统鼠标 |
| 自己听歌 | 戴耳机、点头；用户启用真实音频时显示播放/暂停/静音控制 | 默认静音；不扫描音乐库、不控制其他应用、不联网找歌 |
| 有工作事项 | 放下道具，展示事实和选项；点击进入可核验的预览 | 不用可爱话术催用户采纳；忽略后不反复纠缠 |
| 正在处理任务 | 显示真实运行进度，而不是无限转圈 | 区分准备中、等权限、失败和完成 |
| 开会/演示/勿扰 | 音频停止，动作暂停或隐藏，普通气泡排队 | 会后合并去重，不把积压逐条轰炸 |
| 后台断开 | 客户端保留少量离线动作，标明办公功能离线 | 不假装仍在同步、记忆或完成任务 |

工作状态和视觉动作分开：增加“玩球”皮肤动作不应改工作执行器。安静模式 > 用户操作 > 待授权/高优先工作 > 普通工作展示 > 自娱。角标是否可见遵循用户的演示隐私设置。

## 2. 工作入口

单击看待办与最新结果，双击或明确聊天入口开始对话。提醒必须说明“为什么现在提醒、依据是什么、下一步是什么”，提供稍后、忽略和源系统链接。发送、创建会议等动作必须先展示完整目标和内容；气泡空间不足时打开面板，不能省略预览直接确认。

首次使用不用等一周：授权后可手动查看近期日历负荷及已有工作线索；缺少数据时明确说缺少什么，不编结论。M2 至少完成一个真实闭环：选中需要处理的线程或事项 → 查背景 → 起草 → 用户确认 → 自动执行 → 返回结果。

## 3. 好玩但不占用工作

基础互动、听歌、所有办公本领不随等级上锁。成长只增加装饰、动作和已核实的熟悉程度；用户删记忆、拒绝提醒、暂停使用都不扣能力。先提供少量高质量动作，不以复杂数值养成拖延生产力功能。

动画本机执行，不因空闲动作调用 LiteLLM；遮挡、隐藏、离屏时降帧或停止。长时间后台活动不做高频窗口全量扫描。默认无声音，真实音频和扫描范围由用户选择。

## 4. 前置验证

MOD-12 需验证透明窗口、点击区域外穿透、窗口边跟随、窗口关闭/最小化、多屏与 DPI 变化、睡眠唤醒、拖动、气泡边界、安静模式和音频停止。macOS 与 Windows 分别实测，不把概念图当作实现证据。

共享屏幕识别不保证系统全局可知：采用已验证的平台信号、日历忙碌和显式勿扰；检测权限缺失要提示并提供一键演示模式。隐私承诺不依赖模型猜测用户是否在开会。

## 5. 扩展

皮肤是带版本、锚点、命中区域和语义动作映射的纯素材包，不执行任意脚本。基础动作缺失则映射到同语义的默认动作。外部音乐/播放器控制将来作为独立能力与连接器加入，不能借“自主听歌”绕过授权。
