# Work Agent 文档

**一只陪伴宠物，能协助日常办公。**

本目录是项目的唯一依据。所有设计、决策、评审都落在这里；实现必须能追溯到这里的文档。文档和代码冲突时，先改文档并通过评审，再改代码。

## 本地一键启动（macOS 开发版）

在 work-agent 目录运行 `npm start` 或 `bash start.sh`，无需再开三个终端。脚本自动配置 Node.js 24/Rust 路径和精确开发 Origin，依次等后台、Vite 就绪后启动 Tauri 桌面团子；首次编译可能较慢，不打开浏览器，不自动安装依赖。

兼容且健康的既有后台会复用，但不会自动加载后台源码改动。旧后台拒绝开发 Origin，或开发端口已被旧前端占用时，会提示在原终端正常停止后重试，不杀旧进程或删锁。第一次从旧三终端流程切换时，先在旧前端和桌宠终端 Ctrl+C。

此脚本是前台开发会话：Ctrl+C、桌宠进程正常退出或任一新服务失败，都会停止本次启动的进程组（包括 Cargo/桌宠子进程）；复用的后台保留。它不是常驻后台或自启动服务，关闭时本次启动的后台提醒也会停止；数据保留，重新启动继续使用原数据与系统凭证。启动依赖现有系统凭证流程，脚本不读取或输出令牌，不接入公司数据源。

团子现在自由停放：拖到哪里就留在哪里，不自动吸附窗口或屏幕边、不跟随窗口，也不在首次见面时跳到窗沿。按屏幕保存的位置仍在启动时恢复；右键和设置不再提供固定位置开关。源码与无头浏览器桥回归通过，真实 macOS 拖放及多屏位置恢复仍待桌面复验。

养成首轮已加入部位反应、六戳护脸/揉脸和放下自揉，皮肤共37个动作。右键 → 玩一会儿 → 抛接球（等球下落再点接住）/纸箱躲猫猫（点三次探头）；“结束玩耍”或 Esc 可结束，30秒收尾，勿扰/办公/通知/隐藏/断线时停止，不续玩、不扣分。玩法不占气泡、不逐次增长、不移动窗口，菜单不会隐藏正在编辑的聊天/设置。新纸箱白名单属于后台代码，旧后台需正常停止后重启；本机无头验证通过，真实Tauri观感与命中仍待桌面复验。

## 工作流程

| 阶段 | 产出 | 负责 | 通过条件 |
|---|---|---|---|
| 1. 愿景与范围 | `00-vision.md` | 总架构师（主会话） | 用户确认产品目标 |
| 2. 未决问题 | `open-questions.md` | 总架构师 | 影响架构的问题都有答复，并写进 ADR |
| 3. 总体架构 | `architecture/` | 总架构师 | 技术自评通过后冻结 v1（ADR-0016）；用户验收实际体验 |
| 4. 架构决策 | `adr/NNNN-*.md` | 总架构师 | 每个难以回退的决定写一条；已接受的 ADR 只能由新 ADR 取代，不能直接改写 |
| 5. 模块详细设计 | `modules/<编号>-<名称>.md` | 各并行会话 | 遵守 `architecture/` 的接口约定；总架构师检查一致性后标为“已批准” |
| 6. 实现 | 代码 | 各并行会话 | 只能按已批准的模块设计实现；发现设计问题时回到阶段 5 |
| 7. 评审 | `reviews/YYYY-MM-DD-<主题>.md` | 总架构师 | 记录结论、问题和处理结果 |

文档状态统一使用：`草案` → `待评审` → `已批准`；被替代的标为 `已取代`。

## 并行会话规则

见 `architecture/roadmap.md` 第 4 节的启动说明。要点：

- 先读愿景、五份架构/验收文档、体验规格、相关 ADR；
- 只修改自己负责的模块；
- 需要改跨模块接口时写本模块未决问题并回报主会话，由主会话汇总 `open-questions.md`，不能自行修改公共契约；
- 用 `templates/` 里的模板。
