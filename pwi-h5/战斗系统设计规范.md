# 战斗系统设计规范

> 2026-11-19；文档驱动的分阶段建设。本文区分当前执行规则、拟定规则、验收目标和官方缺项。设计目标不等于已上线功能，纯数值夹具不等于自然通关。

## 1. 目标与边界

1. 普通野怪允许同级较差装备、基本技能和少量药品稳定完成；不要求血符、蓝符、秘宝装备或高精炼。
2. 副本普通波要求完整且合理的装备与技能；多人端游副本压缩为单人挑战，不照搬团队总血量。
3. 野外首领、副本首领和传说首领必须分别建预算；输出、防御、生命、技能与续航共同构成门槛，不能仅给同一个怪物增加血量。
4. 顶级首领要求对应职业的顶级合法装备及正确应对。血符延长续航，不能让低配角色无视致命攻击；蓝符提供真气，不替代技能门槛、元气或冷却。
5. 保留来源装备的真实区间、已核词条和未知字段。品阶、星数、名称颜色不参与未说明的伤害乘区；不按装备名称发明属性，不执行来源页面中的公式字符串。
6. 敌人属性由地点、等级、难度和固定内容预算生成，绝不随当前玩家装备自动变强。推荐装备是提示，不是额外的禁止挑战条件。
7. 不把端游秒制、仇恨或团队配置冒充已经完整复刻。正式联机/PVP、完整原版射程/仇恨、地形减伤和长期宠物养成不属于当前基础阶段；实时局部射程与落点判定已接入。

## 4. 分层架构与职责

```text
来源数据/有限装备/职业技能/怪物内容
  → 属性汇总：裸属性 + 合法装备 + 修真 + 当前buff
  → 行动校验：目标/武器/资源/冷却/状态
  → 固定步编排：合法逻辑推进、恢复与持续效果、技能消耗、独立行动与前摇
  → 伤害计算核心：各伤害通道独立计算并返回乘区明细
  → 状态结算：护盾、实际扣血、死亡/复生、护符、吸血和持续状态
  → 一次胜负结算：奖励、掉落、任务、耐久
  → 候选快照校验、事务/CAS/receipt、提交后adopt
```

### 4.1 模块边界

| 模块 | 职责 | 不允许承担的职责 |
| --- | --- | --- |
| `src/data/classes.js`及来源表 | 职业与技能元数据、已核学习/武器要求 | 执行网页公式、操作玩家状态 |
| `src/core/model.js` | 从已持有装备和基础成长产生确定属性快照 | 根据玩家当前战力调整敌人、发奖励、写数据库 |
| `src/core/combat-math.js`（P1已抽离并通过专项、领域、后端与真实浏览器回归） | 统一命中、伤害通道、防御选择和乘区解释；无导入依赖 | RNG、UID、扣血、护盾、护符、日志、时间或数据库 |
| `src/core/combat.js` | 有限行动、随机判定、技能/状态/宠物、回合与胜负 | 直接提交IndexedDB、因查看建议扣费 |
| 固定怪物预算与内容表（后续阶段） | 地点/副本/难度/技能机制和已测量参考预算 | 自适应读取实际玩家装备、凭名称猜元素 |
| `src/core/economy.js`与护符定义 | 拥有物品检查、战斗外装填、储量追加 | 装填即治疗、免费刷新冷却、真实充值 |
| `src/core/game.js` | 内容入口、各波衔接、一次性奖惩 | 让失败/刷新重复结算 |
| `src/core/schema.js`及`src/core/api.js` | 边界校验、失败丢弃、幂等/CAS、事务 | 在GET中推进回合、掷随机或保存 |
| UI | 显示真实区间、危机/意图、护符剩量/冷却和固定步事件反馈及推荐装备 | 自行重算另一套伤害、按隐藏战力禁止进入 |

### 4.2 伤害通道契约

- 类型为`phys`或`magic`，元素为金/木/水/火/土或null。
- 物理读`def`，指定元素法术读对应`elemDef`；没有指定元素的法术读`mdef`。显式0是有效防御，不能误走fallback。
- 混合技能拆分各通道份额，分别走同一内核，再按一次命中合并取整；不能对两通道重复套暴击或特效。
- 攻击者/防御者是当前属性快照，伤害金额是已经确定的区间抽样和技能结果；纯计算核心不再抽随机。
- DOT保持施放时攻击者扩展属性快照，目标当前破甲/防御在跳伤时读取；不能重复套直接攻击的暴击/区间波动。宠物、格挡反击也使用同一内核。
- 明细仅是脱离状态的计算结果，不直接写档。第一阶段先供测试/数值分析使用，不立即增加API或额外UI面板。

### 4.3 实时轻操作基础（2026-11-19基础验收通过，范围见第10节）

玩家界面不再按一次点击结算一整回合。参考本地d2h5的独立行动、攻击前摇和事件驱动反馈，借鉴迷雾大陆的移动优先与自动施放思路；并非照搬两者的数值、地图、商业系统或存档策略。

- 逻辑固定步长200毫秒，渲染独立30帧/秒并插值坐标。前台一次最多提交5个逻辑步；当前UI每200毫秒提交1步，慢请求、切页、失焦和后台不补跑墙钟时间。坐标、前摇、技能冷却、事件与暂停状态随候选快照通过同一schema/CAS/receipt事务。
- 战场范围x为−4至4、z为−2.8至2.8。玩家移速3.5单位/秒；WASD、方向键、地面点击和按住方向按钮走位，对角归一。近战无输入时走近目标，不覆盖手动方向；普攻自动索敌。近战玩家射程1.4、敌人1.25，远程5，属于本作规则，尚非端游射程。
- 玩家普攻基础间隔1.2秒，再按攻速缩短；实时普攻不同时按旧回合多次攻击重复计算攻速。最多四格已学非被动技能固定选择，优先保留可持续输出与治疗/召唤，再按收益补齐；自动策略依据当前资源、已有buff、低血和多目标决定是否施放。缺真气不阻塞普攻，不自动吃药。技能公共冷却0.6秒，原本作cd/状态单位映射为每单位2秒，非官方秒数复刻。
- 每只怪物独立追击、冷却与前摇。普通攻击前摇0.4秒，重击1.2秒；重击开始锁定玩家落点，半径1.4的红圈明确显示。攻击落下重新判定射程/落点，走出范围即落空；眩晕可以中断蓄力。普通敌人攻击后冷却1.8秒，首领1.4秒，不齐步调用旧takeTurn。
- 守御持续3秒、冷却8秒；沿用本作55%普通伤害减免及重击格挡反击。治疗药、真气药真实消耗且共享8秒冷却。手动技能沿同一学习、武器、资源、射程与冷却校验；推荐装备不禁止挑战。
- 事件队列最多64条，具有递增seq、逻辑tick、行为、攻击者、目标和金额；UI增量消费事件作挥击、受击、飘字和红圈反馈，不从动画推算伤害。奖励通过resolved标志只结算一次。
- 野外单场景战斗：野外战斗（指名挑战、走入仇恨圈、被动怪贴身、探索遇敌）始终在同一游历布局与3D场景原地进行，不画战场地面方框，镜头、主线和附近道路保留。`rt.origin`记录相遇处世界坐标（绝对值≤64），本地战场坐标叠加origin渲染；其余野怪以非交战的环境怪显示。主动攻击半径：普通3.2、精英3.6、首领4.2；低于玩家8级以上的被动怪在手动走入1.6单位贴身范围时自动开战，无需点选。自动走近绕开其他怪的主动圈，出生位置优先保持间隔，手动移动仍会真实拉怪。胜利或撤退后约0.9秒、失败后约0.3秒自动leave，不进入独立野外结算页；胜利或阵亡提示在场景内显示约6秒，阵亡回城或复活卷规则不变。被击败的怪本地隐藏约15秒后重生（UI态，不写档，刷新即恢复）；重生时玩家已在触发圈内需出圈再进入才触发。副本、修真试炼和竞技场仍使用独立战斗页。
- 旧无rt战斗仅作为原领域回归/旧档适配路径保留；一旦启用rt，旧turn/auto入口拒绝执行。新界面创建战斗后另一个事务启用rt，两步不是伪称原子的单次请求；启用失败可以继续启用，不重置已启用状态。

## 5. 伤害流水线与系数管理

### 5.1 第一阶段：冻结现行数值，只统一计算核心

先证明结构调整不偷改平衡；以下均为**现行本作系数，不是已论证的最终数值**：

```text
命中率 = clamp(1 − clamp(闪避比例 + 额外闪避, 0, 0.9) / max(0.1,准确倍率), 0.1,1)
区间攻击 = 在已核Min/Max内抽样
原始通道伤害 = 区间攻击 × 技能倍率 × 潜行 × 暴伤 × 单次装备触发 × 意图倍率 × [0.9,1.1]波动 × 通道份额
有效防御 = (当前对应防御 × 当前破甲剩余比例) × (1 − 穿透)
防御乘区 = 100 / (100 + max(0,有效防御) × 0.32)
攻防等级差 g = clamp(攻击等级 − 防御等级,−300,300)
攻防乘区 = g≥0 ? 1+0.01g : 1/(1−0.01g)
五行额外减免乘区 = 1−clamp(对应Res,0,0.8)，非元素攻击为1
物理额外减免乘区 = 1−clamp(physicalReduction,0,0.8)，法术为1
气魄乘区 = (1+0.0005×攻击者气魄)/(1+0.0005×防御者气魄)
猎魔乘区 = PVE ? 1+0.001×攻击者猎魔 : 1
创世乘区 = 1+0.05×攻击者创世
通道结果 = 原始通道伤害 × 各独立乘区
```

纯核心返回未取整的通道结果；实际一次命中在编排层合并、取整和最低1伤害，再抵扣护盾、夹取目标剩余生命。完全被护盾抵消可以是0实际扣血，闪避是0且不触发命中状态。意图暴露/格挡是战斗动作规则，不偷偷写入装备字段。

### 5.2 后续校准原则

1. 当前固定分母造成高等级减伤急剧增加，需要引入攻击者等级相关分母`K(L)`或经装备预算拟合的同等模型。先核官方资料，再在矩阵中比较候选；当前不直接启用一个未经测量的`40L`或类似经验公式。
2. 防御、比例减免、攻防等级、气魄/猎魔/创世必须各有唯一乘区；不能把五防相加，不把物理减免加到物防，不用q额外倍乘。
3. 减伤边际应递减且单调；零防御等于无防御减伤，穿透增加不能反向降低伤害；同级防御改善应对承伤有可测量帮助。
4. 人物等级差和攻防等级是不同概念，不能混用；前者要独立核定高等级压制，后者来自装备与状态。
5. 减伤率上限、命中上下限、暴击上限等属于明确适配的数值政策，不以测试当前代码通过冒充官方证据。
6. 技能原文中的基础物攻、武器攻击百分比和固定伤害不能粗暴全部乘职业攻击；后续逐技能核定为独立分量。未核技能保留显式本作倍率，避免全表一次性猜测。
7. 随机词条先测最小/中位/最大；不能以恰好最高词条作为“普通装备也可打”的依据。

### 5.3 五行克制设计边界

已核历史方向为木克土、土克水、水克火、火克金、金克木；P3按明确内容属性接入，P1尚不改变元素伤害。强弱倍率没有可核官方通用值，须作为本作系数经矩阵测量后确定。官网有领土战五行描述，不能宣称五行只对怪物有效，也不据此给玩家分配单一本命元素；无属性目标不附加固有元素克制。

- 攻击元素、怪物固有元素、对应防御值、额外Res是四个独立概念。
- 已穿装备有五防不等于玩家具有某个固有元素；不能给所有法师贴火属性然后承受额外水伤。
- 没有来源或明确本作元素设定的目标，不猜固有元素；物理攻击不因怪物固有元素自动变成五行伤害。
- 混合通道和DOT逐通道适用；反向减伤只在有明确规则证据时存在。
- 元素策略应让选择技能和换防具有意义，但不能成为未拥有另一职业技能的硬性死锁。

## 6. 用装备预算反推难度

### 6.1 合法装备档位

| 档位 | 具体取样规则 | 用途 |
| --- | --- | --- |
| G0 低配 | 合法普通武器；核心防具落后一个已存在装备档；少量空槽；不精炼/不镶嵌 | 普通怪最低可玩边界，不是全裸保证 |
| G1 普通整装 | 全部适合职业的有限普通/训练装备，最低随机词条、无精炼宝石；已载需求满足 | 成长和野外基准 |
| G2 强装 | 合法神月来源装备或G1合法精炼/同品阶兼容宝石；逐件明确templateId与培养成本 | 副本普通波和首领候选基准 |
| G3 顶装 | 已核高阶来源模板＋其他槽位合法强装/培养；真实武器限制和属性需求通过 | 高难副本、传说首领候选基准 |

每组保存明确的templateId、部位、需求、属性点、词条roll、精炼、宝石、技能阶、修真与消耗额度；不是用“金装/红装/21品”三个词代替装备。预览不生成UID/随机，不伪造获得记录；实例验证用单独的明确初始化夹具。

现有高阶只有5个样本，不能组成所有职业顶装。剑灵等职业没有相应已核顶级武器时，必须先补齐合法获取路线再开放其必需G3的主线门槛；不能强迫换职业或穿不适合技能的斧头。

### 6.2 拟定验收矩阵：目标，不是当前通过结果

比较同级角色，基本战术策略统一；先无护符，再有护符；每组至少200固定种子，报告胜率、中位/95分位逻辑秒数、玩家/敌人各自行动次数、剩血、药耗、HP/MP储量消耗、阵亡原因。下表保留实时改造前拟定的回合预算作为历史目标，不直接把一个旧回合等于一次实时普攻，也不宣称新矩阵已通过；P3需要以实时技能和独立攻击链重新测定秒数目标。长战超过有限步数记失败/超时，不无限补资源。

| 内容层 | 最低目标档位 | 实时改造前的回合预算 | 配套目标 |
| --- | --- | --- | --- |
| 普通野怪 | G0 | 3—6 | 无护符、最多1份同级治疗药，胜率≥90%；G1胜率≥95% |
| 野外精英 | G1 | 6—10 | 有基本控制/防御策略，小量药品；G0不保证稳定 |
| 副本普通波 | G2 | 6—12 | 两怪合计承伤预算；整段有限补给；G2胜率≥85%，G0≤30% |
| 野外首领 | G2或该阶段更强合法配置 | 12—25 | G1≤30%，目标配置≥75%；必须测一次重击和持续压力 |
| 常规副本首领 | G2强化配置 | 15—30 | 前置波已消耗的状态延续，目标配置≥75%；不能靠波间免费回满证明通关 |
| 高阶副本首领 | G3 | 20—35 | 顶装路线可达，护符冷却期间仍有生存窗口；G1≤20% |
| 传说首领 | G3 | 25—40 | 单独内容、至少一种可应对机制；G1≤10%，G3正确策略≥65% |

数值区间先作为设计验收目标，不能为了满足表格偷偷加角色属性、无限护符或修改敌人剩血。初期修真试炼属于成长关卡，独立按G1与已获得技能校准，不统一套顶级boss门槛；主线需要的首领按当时可获取装备设计。

### 6.3 固定敌人预算方法

1. 在各等级段冻结合法职业参考快照。输出参考用攻击区间、真实可用技能的收益与有限真气；生存参考用HP、对应防御、实际可用保护技能，不用`power`汇总值。
2. 以参考配置在固定实时步长下的有效平均每秒输出×目标逻辑秒数作为生命初值，纳入四槽技能、公共/独立冷却、走近射程和有限真气；防御先决定不同武器/穿透与元素的边际，再回算生命，不能重复放大有效血量。
3. 用每逻辑秒承伤预算反推基础攻击，计入敌人独立冷却与前摇；同时限定单次重击对正确守御角色的生命比例。普通两怪波按合计压力分配，不能每只都使用单首领压力。
4. 首领同时验证输出检查、重击窗口、对应防御和有限续航。元素/控抗/技能机制使用明确内容配置；增加HP只能解决时长，不作为唯一装备门槛。
5. 参数拟合在离线脚本中完成，结果冻结为内容预算；运行时只查内容与等级，不读取玩家G档或模板来缩放怪物。
6. 验证获取不自锁：首次通关装备必须能从野外、前置副本、普通生产或已核其他路线获取，不能要求该首领首次掉落才能打该首领；不强制秘宝随机奖或真实付费。

## 7. 血符与蓝符时序设计

### 7.1 历史事实与实际执行边界

装填契约保持：拥有道具、战斗外、实际扣枚数并追加储量，装填不治疗；储量不能是负数或小数。600000/900000总回复额度及严格低于50%/75%、10/5秒来自已核历史证据。P1没有修改旧护符；本次实时路径采用严格HP<50%、MP<75%，恢复缺口，独立冷却。

秒数映射到**逻辑战斗时间**属于本作适配，不采用浏览器墙钟、后台等待、切页或刷新计时；独立冷却、尾次部分恢复及致死顺序同样明确标为本作规则。旧无rt回合测试路径仍保留原有阈值/无冷却，不能当成已升级的实时路径，也不能在已启用rt后调用旧行动绕过冷却。

### 7.2 固定步逻辑时间与保存契约

- 实时战斗每合法步推进200毫秒。玩家持久字段为`charmCooldowns:{hp,mp}`，独立非负剩余tick：血符最大50、蓝符最大25，对应10秒、5秒。替代此前尚未实现的5秒/回合、combatClock和charmReadyAt方案，不同时维护两套时钟。
- 冷却每实际逻辑步减1，暂停、非法动作、GET、查看建议、目标选择、切页、失焦和后台不减。战斗外不计离线恢复，新战斗、换波和追加储量不重置；导出、刷新、导入同一有效快照均保留。
- 老合法档允许缺少charmCooldowns，首次显式启用rt时初始化为0；读取不偷偷迁移或写档。已存在字段需严格校验，实时快照必须带字段，负数、小数和越界值拒绝。
- rt.tick和所有readyAt为有界非负安全整数；技能绝对就绪tick与旧展示单位需一致，坐标、落点、事件数量/序号/目标均由schema校验。失败候选丢弃，保存事务完成后才adopt。

### 7.3 触发与消耗不变量

1. 仅角色存活、储量>0、严格阈值达到且独立冷却为0时自动恢复。恢复量=`min(当前上限−当前资源,剩余储量)`，只扣实际恢复量；尾次不足允许部分恢复。
2. 触发立刻设置该符50/25剩余tick。同一步的连续敌人攻击、技能消耗和其他检查点不能重复触发同类符；血/蓝互不占用冷却。
3. 伤害先抵护盾，再扣HP并判定死亡。血符不能救回已经0HP的角色，不能抵消本次致命伤；被动复生独立结算。宠物承伤不扣玩家血符。
4. 技能消耗真气后立即检查蓝符；元气、技能CD和学习要求不由蓝符补充。手动技能按当下实际真气判断，资源不足拒绝且无符消耗；合法固定步的恢复检查与自动选择使用同一状态，UI不承诺用未来恢复可提前施放。
5. 每步先减冷却、取消仍在眩晕中的前摇，再结算到期持续效果与上限；每2秒维护自然恢复。然后移动、自动技能、独立普攻/宠物和各敌人阶段，各实际伤害后先存活判定再查符，步末再查符。持续效果施放后首次到期设为施放tick+10，不当步提前扣时长。
6. 装填不治疗、不清冷却，战斗内不可追加；耗尽不赠新符。暂停/刷新/换波、连击、同阈值、尾次、致命、复生、资源不足、非法请求、重复receipt与事务失败分别验收。


## 8. 首领机制与内容扩展

统一机制必须让玩家能读取和应对，不能随机无提示秒杀。初选机制范围：明确通道的重击、需要打断的吟唱、可用对应防御应对的元素攻击、小怪阶段和有限持续伤害。机制需要单独字段与行动定义，不通过名字字符串硬编码。

- 普通首领保留现有可见意图作为基础，但先测“正确防御”和“无脑输出”的差异。
- 控制抗性、阶段转换、技能条件和召唤物需要确定数据及日志；全程免控与随机必中秒杀不作为快速提难手段。
- 当前敌人不能向玩家施加完整DOT/异常状态，也没有独立传说首领；这些是后续建设项目，不以已有宠物/玩家DOT测试覆盖代替。
- 主线首领、修真守关、材料副本和终局传说分开配置；可选顶级挑战不能卡死基础成长。
