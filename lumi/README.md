# Lumi · 生活助手

一个 Vite + React 18 + TypeScript 的个人生活助手原型。H5 入口兼容桌面与手机，使用自建组件库、双主题和流式 mock Agent。

## 本地运行

```bash
npm install
npm run dev
```

本地入口：`http://127.0.0.1:5175`。

```bash
npm run typecheck
npm test
npm run test:e2e
npm run build
npm run preview
```

## 本期能力

- 日期、模拟天气、穿搭／吃饭／住宿／出行四类入口；平面双主题界面，无营销横幅和装饰星光。
- 自然语言问题、流式正文、十一类结构化卡片；思考摘要与计划/任务进度默认收起，可手动展开。
- 天气穿搭、餐厅、菜谱、酒店、路线比较、附近设施、居家整理、本地提醒，以及多日预报、一日行程、准备清单。
- 首页 / 对话 / 清单导航与独立新对话；手机／平板顶栏的「L＋圆点」品牌可一键回首页，桌面左栏品牌同样可点击。手机菜单为左侧抽屉，聊天页去掉底栏，首页/清单保留快捷导航；切页不中断生成，草稿按页面/会话本地保存。
- 停止、再试一次、复制正文与卡片要点、系统分享（不支持时隐藏，可用复制替代）；完整回复重新生成失败或停止后保留旧结果，不生成公开链接。
- 收藏、直接填写事项/备注/可选时间、完成与移除；删除后8秒内可撤销，全部保存在当前浏览器。
- 应用打开期间恢复阅读位置、菜谱展开、路线、排序、准备清单勾选；刷新不恢复这些局部状态。准备清单与行程各保存为一个任务，卡片勾选和任务完成相互独立。
- 百度地图 GL 可选真实底图，未配置 AK 时为明确标注的 SVG 路线示意，保留百度地图跳转。

不支持登录、云同步、订餐、订房、支付、实时定位、系统闹钟或后台通知。

浏览器测试使用 Playwright + 本机 Google Chrome，无需下载浏览器。桌面 1440×900 与手机 390×844 会验证主流程，并将截图写入 `docs/screenshots/`；附加检查 320/375/390/768/1024/1440px 及320×430短屏；手机视口并非真机键盘验收。

## 模拟请求

业务代码调用统一 API 客户端。mock transport 使用 Promise + setTimeout 模拟等待，返回 fetch-compatible `Response` 和 `ReadableStream`，按 SSE 事件驱动交互，不是真实 Agent HTTP 服务，也不假装已查询实时信息。

默认不会随机失败。可在「设置」中启用慢网络或下一次请求失败，然后关闭弹窗继续提问，体验停止与重试。

开发调试参数：

- `?mock_latency=slow`：慢网络。
- `?mock_error=once`：一次 chat 请求失败，随后允许重试。
- `?mock_fail=1`：持续强制失败；移除此参数恢复。

## 百度地图 AK

将 `.env.example` 复制为本地 `.env.local`，填入：

```dotenv
VITE_USE_MOCK=true
VITE_BAIDU_MAP_AK=你的百度地图浏览器端AK
```

重启开发服务器，按百度地图开放平台要求配置 JavaScript API 的授权域名/Referer，包含你的本地或部署域名。打开出行或位置卡片，点击「加载百度底图」才会连接百度 SDK，不自动定位。浏览器端 AK 会进入前端代码，不是服务端秘密；不要填写服务端密钥，不要提交 `.env.local`。

底图通过百度地图 JavaScript GL SDK 动态加载。卡片线路、时长、价格仍是本期 mock 示例；「打开百度地图」在第三方地图中重新查询路线。未填写 AK、加载失败或超时会保留示意地图，不会冒充真实底图。

本次未持有 AK，真实 GL 底图、域名授权与移动百度 App 唤起需要配置后另行验收。

## 接入未来服务端

```dotenv
VITE_USE_MOCK=false
VITE_API_BASE_URL=https://你的编程服务API域名
VITE_REQUEST_TIMEOUT_MS=20000
```

重启后原生 fetch 调用 `GET /api/home/overview` 与 `POST /api/chat`。业务代码不直接依赖 mock，服务端需对齐 `src/api/types.ts` 的 SSE 和卡片协议。认证、真实数据来源、校验与隐私策略仍是后续工作，关闭 mock 不代表服务端已实现。

## 目录与过程文档

```text
src/ui/             无业务依赖的基础组件
src/styles/         设计 tokens、主题、全局样式
src/api/            协议、请求客户端、SSE 消费
src/mock/           意图识别、响应数据、模拟网络
src/features/       首页、对话、生活卡片、地图
src/store/          会话、清单、主题本地状态
src/hooks/          可取消的对话生命周期
src/lib/            百度地图加载与链接
```
