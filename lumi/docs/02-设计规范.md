## 1. 设计理念与边界

### 1.1 五个关键词
- **安静**：中性色承载大部分界面，唯一品牌色只用于主要操作、选中态与焦点。
- **清晰**：先给结论，再给依据与行动；每张卡片只有一个视觉中心，避免指标争夺注意力。
- **温暖**：通过问候、圆角与自然措辞传递陪伴，不通过拟人动画或大面积装饰制造亲密感。
- **精确**：4px 间距系统、稳定的文字层级、对齐的数字；请求过程和结果可信、可追溯。
- **轻盈**：卡片靠边框和留白分层，阴影只用于浮层；动效是反馈，不是表演。

### 1.2 明确不做什么
- 不用花哨渐变、玻璃拟态、大面积纯黑、霓虹高亮或过度磨砂；骨架微光仅作加载反馈。
- 不用 emoji 当图标；不混用实心、彩色与不同描边的图标集。
- 不复制参考产品的品牌标识或专属交互；借鉴 Linear 的秩序、Things 的轻巧与 Apple 天气的信息层级。
- 不把 agent 每段文字包进气泡，不展示机器人巨型头像，不逐字播放声音或弹跳动画。
- 不用多种品牌色区分业务；场景色只占小图标底色，不染整张卡片。
- 不默认展开全部详情，不把首页做成信息流，不以横向卡片轮播隐藏主要答案。
- 不将 mock 结果包装成已查询真实数据、已预订、已成功导航或已具备系统级提醒能力。
- 不依赖 hover 暴露唯一入口，不用低对比度文字换取“高级感”，不让动画阻塞操作。

## 2. Design Tokens

### 2.1 命名、主题与使用规则
- 以下表格是可直接映射的 CSS 变量名和值，不是样式实现；长度默认 px，时间默认 ms。
- 按角色引用 `--color-*`，组件不写主题色硬编码；CSS Modules 只负责局部结构与状态。
- 默认跟随 `prefers-color-scheme`；设置提供“跟随系统 / 浅色 / 深色”，显式选择优先于系统。
- 深色不是反色：降低背景亮度，提升品牌色与文字亮度；浮层比底层略亮。
- `text-1~4` 分别用于主要结论、正文、次要说明、时间/占位；正文不可用透明度再减淡。
- `border` 只分隔装饰表面；输入框、未选中控件轮廓等必要识别边界使用 `border-control`。

| Token | 值 / 所属 |
| --- | --- |
| `--z-base` / `--z-sticky` / `--z-composer` | `0` / `10` / `20`；正文、顶栏、输入停靠区 |

### 2.9 动效
| Token | 值 |
| --- | --- |
| `--duration-instant/fast/normal/slow` | `0/120/180/240ms` |
| `--duration-cursor` / `--duration-shimmer` / `--duration-spin` | `1000ms` / `1600ms` / `900ms` |
| `--ease-standard` | `cubic-bezier(0.2,0,0,1)` |
| `--ease-enter` / `--ease-exit` | `cubic-bezier(0.16,1,0.3,1)` / `cubic-bezier(0.4,0,1,1)` |
- 消息/卡片仅首次入场：opacity 0→1、Y 4px→0，180ms enter；已在流式更新的内容不重复入场。
- Sheet 位移不超过自身高度，240ms；Modal 淡入 + Y 8px，180ms；无弹簧回弹。
- 按钮只过渡背景/边框 120ms；active 可 scale 0.98、120ms，disabled/loading 不缩放。
- 流式光标 2×18px，品牌色，1000ms 步进明灭；只在末尾显示，不制造打字机字距跳动。
- Skeleton 基底 surface-secondary，微光 surface-hover，1600ms 线性一次往返；只作用于占位块。
- 不对 height、全局布局、长列表持续做动画；不要逐 token 自动滚动或改变阴影强度。
- `prefers-reduced-motion: reduce`：入场/按压/平滑滚动禁用；光标常亮，骨架静态，Spinner 改静态图标 + 加载文字。
- 后台页面停止循环动效；加载结束立即移除光标/骨架，不用退场动画拖延结果。

## 3. 响应式与布局

### 3.1 断点与区域尺寸
| 范围 | 布局 | 内容宽度 / 侧栏 / 页边距 |
| --- | --- | --- |
| mobile：`0–767px` | 单栏，历史在左抽屉 | 主区流体，左右 16；不常驻侧栏 |
| tablet：`768–1023px` | 单栏，历史在左抽屉 | 主区 max 740，左右至少 24 |
| desktop：`≥1024px` | 左侧栏 + 主区 | 侧栏 240；主区 max 740，左右至少 32 |
| wide：`≥1440px` | 与 desktop 相同 | 侧栏 260；主区仍 max 740，不放大正文 |
- 布局常量：`--layout-content-max: 740px`、`--layout-sidebar: 240px`、`--layout-header-mobile: 56px`、`--layout-header-desktop: 64px`。
- CSS 变量不能直接作为传统媒体查询阈值；前端在媒体查询中使用上述固定 px 值，主题变量不改变断点。
- 320px 为最小验收宽度；200% 缩放后按可用 CSS 宽度自动切换布局，不出现页面横向滚动。
- 移动顶栏高 56 + safe-area-top，左右 12：左 44 菜单、中央名称、右 44 新建；标题 16/24、500。
- PC 顶栏高 64，底部 1px border；左对话名、右主题/更多；不重复显示完整品牌大 Logo。

### 3.2 PC 侧栏与主区
- 侧栏全高、surface-secondary、右侧 1px border；内边距 16，顶部品牌区 40。
- “新建对话”按钮高 44、满宽；与历史组间距 24，历史标题 12/18、text-3。
- 历史按“今天 / 近 7 天 / 更早”分组，行高至少 44、圆角 8、标题单行省略。
- 选中历史用 brand-subtle，前景 brand-subtle-fg；会话更多按钮在选中/focus/hover 时显示，手机始终可见。
- 快捷入口位于侧栏底部，衣/食/住/行/提醒为五个 44px 高的行项；历史区独立滚动。
- 主区按扣除侧栏后的宽度居中；对话列最大 740，顶 padding 24，末尾留白由实际输入停靠区高度决定。
- 主区只保留一个纵向消息滚动容器；内容较少时不强制将消息贴底。

### 3.3 输入停靠、安全区与键盘
- 页面壳占动态视口高度（100dvh），结构为顶栏 / 可滚动主区 / 底部输入停靠区；不把输入框固定在文档最底部。
- 停靠区背景 bg、顶部 1px border；手机左右 16，PC 对齐 740px 对话列。
- 字段容器高 56–176，停靠区上下各 12；手机总高 80–200 + safe-area-bottom。
- PC 字段下增加 16px 高说明，与字段间距 8；总高 104–224，不含必要的底部安全区。
- safe-area 对应 `env(safe-area-inset-top/right/bottom/left, 0px)`；横向边距取基础 gutter 与对应 inset 的较大值。
- 正常状态底部 padding 为 12 + bottom inset；浏览器键盘已占据安全区时避免重复叠加额外键盘高度。
- 键盘打开后输入框停靠在可视视口底边；以动态视口为主，必要时由技术方案统一适配 VisualViewport 偏移/高度。
- 不叠加两套键盘位移补偿；iOS Safari、Android Chrome、横屏分别验收，焦点字段与发送按钮必须同时可见。
- 若停靠区覆盖消息容器，其 scroll-padding-bottom 必须等于实测停靠区高度 + 16；正常网格分区则只留底部 16。
- 用户在距底部 ≤80px 时允许跟随新增内容；离开后显示“回到最新”44px 按钮，不夺取阅读位置。

## 4. 底层组件清单与规格

### 4.1 所有组件的状态契约
- 以下 D/H/A/X/L/F 分别代表 default / hover / active / disabled / loading / focus-visible。
- 交互组件共同 F：2px focus 环、offset 3；同时保持选中/错误信息，不用 border 变化代替焦点环。
- H 只在支持 hover 的精细指针设备启用；A 指按压反馈，持续选中态另用 selected，不能混为一谈。
- 中性 H/A 底色上，原 text-4 的时间/说明提升为 text-3，保证 ≥4.5:1；控件边界使用 border-control，保证 ≥3:1。
- X 仅在不可操作时使用 disabled tokens；不整体 opacity 处理可读说明；L 不改变宽高，禁止重复提交。
- 静态组件 H/A/X/F 为不适用，不添加 tabindex；其内置按钮/链接仍继承相应交互状态。
- 可点击整行/整卡必须由单一真实按钮或链接承载；含内部操作的卡片容器不得再嵌套为按钮。
- 默认触控热区至少 44×44；小尺寸视觉可保留，但通过独立外层扩大热区且不得互相重叠。

### 4.2 Button
- **用途/变体**：主要行动 primary；次要 secondary；轻操作 ghost；危险 danger；文字跳转 link。
- **尺寸**：sm 视觉高 32、左右 12；md 高 44、左右 16；lg 高 48、左右 20；字 14/20、500、圆角 12、图标 18、gap 8。
- **D/H/A**：primary 品牌实底/on-brand→brand-hover→brand-active；secondary surface + border-control→surface-hover→surface-active；ghost/link 无底→hover→active；danger 用语义弱底并强化边界。
- **X/L/F**：X 禁用色；L 前置 16px Spinner + 原文或“处理中”，保持原宽并阻止提交；F 统一焦点环。
- 一张卡片只允许一个 primary；link 的点击热区仍至少 44，不让按钮文字小于 14。

### 4.3 IconButton
- **用途/变体**：发送 filled、停止 neutral、菜单/复制/关闭 ghost、删除 danger；必须有可访问名称。
- **尺寸**：默认热区 44×44、图标 20、圆角 12；compact 图形 32×32，独立热区仍 44；发送/停止均 44。
- **D/H/A**：ghost 透明→surface-hover→surface-active；filled 遵循 primary；active scale 0.98。
- **X/L/F**：X disabled-fg；L 居中 16px Spinner；F 统一环；tooltip PC 延迟 500ms、14/20，不是唯一名称。

### 4.4 Input / Textarea（聊天输入框）
- **用途/变体**：普通单行 Input、搜索 Input、聊天 Textarea；错误、只读单独表现。
- **尺寸**：Input 高 44、左右 12、radius-md；聊天外框 radius-xl、padding 6，surface、1px border-control；文字 16/24。
- Textarea 内上下 10、左右 10，1–6 行自动增高：44–164；达到 164 后内部滚动；外框 56–176，按钮与末行底对齐、gap 8。
- **D/H/A**：D 中性轮廓；H 边框 brand；A/编辑不缩放；error 边框 danger，框外 8px 间距显示 14/20 错误文本。
- **X/L/F**：X disabled-bg 且可读说明保持 text-3；L 生成期间可继续编辑草稿，发送切换为停止，不禁用整个输入；F 外框 focus-within 环 + 按钮自身 focus-visible。
- 空草稿发送禁用；流式期间只显示停止图标（Square 16）且 label“停止生成”；结束后恢复发送（ArrowUp 20）。
- PC Enter 发送、Shift+Enter 换行；中文输入法 composing 时 Enter 不发送；手机 Enter 默认换行，点击发送，提示文案与行为一致。

### 4.5 Chip / Tag
- **用途/变体**：Chip 为追问/筛选/切换入口；Tag 为只读属性，如“步行”“清淡”“可取消”。
- **尺寸**：Chip 视觉高 32、左右 12、radius-full、14/20、gap 6，布局行高/热区 44；Tag 高 24、左右 8、12/18、radius-sm。
- **D/H/A**：Chip surface + border-control→surface-hover→surface-active；selected brand-subtle + brand-subtle-fg，并用 2px 品牌边框；Tag 静态无 H/A。
- **X/L/F**：Chip X 禁用色，L 前置 14px Spinner 且保留文字，F 统一环；Tag X/L/F 不适用。
- 最多三条常用追问直接呈现；长文最多两行，禁止纯横向滚动；可移除 Tag 的关闭动作扩为独立 44px 热区。

### 4.6 Card
- **用途/变体**：基础、业务、紧凑、可跳转；标准结构为头部图标 / 标题 / 副标题 / 内容 / 底部操作。
- **尺寸**：宽度随父级；padding 手机 16、PC 20；radius-lg、1px border、无阴影；header gap 12、内容距头部 16、footer 距内容 16。
- **D/H/A**：静态无 H/A；独立可跳转卡 D 使用 border-control，H surface-hover，A surface-active，无整体抬升。
- **X/L/F**：静态 X/F 不适用；L 用保持结构的 Skeleton；跳转卡 X 保留可读标题，F 环包外边界；局部失败仅替换失败内容区。
- 标题 16/24、600；副标题 12/18、text-3；底部按钮换行 gap 8；正文内容可扩展但不得出现卡中卡三级嵌套。

### 4.7 ListItem
- **用途/变体**：历史会话、餐厅/附近地点、带图片项、可选择项；整行跳转与多操作项互斥。
- **尺寸**：普通行最小高 56；双行 72；图片项至少 96；padding 12、gap 12、radius-sm；标题 14/20、500，说明 12/18。
- **D/H/A**：surface→surface-hover→surface-active；selected 使用品牌弱底 + 选中图标；行间 Divider 不额外双描边。
- **X/L/F**：X 不可点击但信息正常可读；L 同高骨架；F 包行或具体操作，不能重复为容器和内部按钮制造两份焦点。

### 4.8 Avatar
- **用途/变体**：agent 品牌标记、用户首字/头像、多人占位；本期不要求上传头像。
- **尺寸**：24/32/40 三档，radius-full；首字 12/14/16、500；agent 使用单色 Lumi 线性标记，不用 emoji。
- **D/H/A**：D 中性或品牌弱底；展示型 H/A 不适用；若打开用户菜单，外层用 IconButton 状态。
- **X/L/F**：X 不适用；L 静态圆形 Skeleton；F 仅交互外层；图片失败回退首字，旁边已有姓名时图像 alt 为空。

### 4.9 Skeleton
- **用途/变体**：文字行、圆形、缩略图、完整卡片；应与即将出现的实际结构一致。
- **尺寸**：文字条高 12/16，行距 12，宽按 80%/64%/40% 固定组合；图片保持目标比例；圆角 4，图片 8。
- **D/H/A/X/L/F**：组件本身即 L，D 为静态占位；H/A/X/F 不适用，不可点击；微光用 motion token，reduce 时静止。
- `aria-hidden=true`；所在结果区 `aria-busy=true`，提供一条屏幕阅读器加载说明；不把占位文本当真实内容。

### 4.10 Spinner
- **用途/变体**：按钮 inline、工具状态 inline、局部结果 block；避免独立全屏转圈。
- **尺寸**：16/20/24，线宽 1.5、继承当前语义前景，轨道使用 border；900ms 线性旋转。
- **D/H/A/X/L/F**：本身为 L；其余状态不适用；reduce 时静态 Loader 图标，必须配“正在查询…”文字。
- 图形 `aria-hidden=true`，可见加载文字关联 status；不同时展示 Spinner 与同区重复 Skeleton 提示。

### 4.11 Toast
- **用途/变体**：简短确认、提示、警告、失败；失败的核心任务必须另有持久 ErrorState。
- **尺寸**：PC 宽 320–400、距视口顶 24；手机左右 16、顶栏下 12；padding 12×16、radius-md、shadow-md、图标 20、文字 14/20。
- **D/H/A**：容器无 H/A；关闭与操作用 Button/IconButton；最多同时两条，gap 8，不遮输入框。
- **X/L/F**：X/L 不适用；F 仅内部控件；普通 4000ms，含操作/错误不自动消失，hover/focus 时暂停计时。
- 普通用 `role=status`，仅需要立即关注的严重失败用 `role=alert`；不自动聚焦、不播报重复消息。

### 4.12 Sheet / Drawer
- **用途/变体**：手机详情底部 Sheet、历史左 Drawer；PC 详情右侧面板或短内容居中呈现，遵循同一信息结构。
- **当前实现**：≤767px 的 Modal 为底部 Sheet，宽 100%、最高 88dvh；把手可见条 36×4、顶距 8、拖动区域高 44px，标题栏也可触屏拖动。下拉过阈值或快速下滑关闭，否则 240ms 回弹；内容区仅逐层滚动容器均在顶部时接管。地图 ready 区与输入控件不接管；关闭按钮、Esc、遮罩均保留。减少动态效果时无退出／回弹过渡，详见 04 第 7 章与 06 第 11 章。
- PC 右面板宽 420（不超过可用宽 90%）、全高、padding 24；历史 Drawer 宽 280（最多 85vw）、全高；短详情可用宽 480 的 Modal。
- **D/H/A**：容器无 H/A；关闭 44px，主操作底栏最小 72 + safe-area；只滚动内容，不滚动标题与底栏。
- **X/L/F**：X 不适用；L 局部 Skeleton；F 先标题/首个适当控件，内部按统一焦点环；打开遮罩，锁背景滚动，关闭恢复触发焦点。
- Escape/关闭按钮可关闭；点击遮罩在无未保存修改时关闭；下滑不是唯一关闭方式，本期不要求拖拽多档高度。

### 4.13 Modal
- **用途/变体**：确认、短表单、重要解释；不用于完整路线或长餐厅列表，不与 Sheet 叠层。
- **尺寸**：默认宽 440、最大 560；手机左右 16；max-height 可视高度减 32 与安全区；radius-2xl、padding 24、shadow-lg，标题 18/28。
- **D/H/A**：容器无 H/A；操作区距内容 24、gap 8，取消在前、确认在后；手机空间不足纵向满宽。
- **X/L/F**：X 不适用；L 确认按钮 loading，取消是否可用取决于请求可否中断；F 初始落在标题或安全操作，危险确认不默认聚焦。
- `role=dialog`、`aria-modal=true`，命名关联标题；焦点陷阱、背景 inert、Escape 与返回焦点；未保存内容关闭需确认。

### 4.14 Empty
- **用途/变体**：首页无对话、历史为空、结果为空、权限未提供；不能把失败包装成空结果。
- **尺寸**：局部 padding 32×16、图标 32 放入 56 底板，标题 16/24，说明 14/20、max-width 320，操作距说明 16。
- **D/H/A**：静态无 H/A；标题“附近暂未找到合适餐厅”，说明给调整范围/预算等下一步。
- **X/L/F**：容器 X/L/F 不适用；搜索尚未结束应 Skeleton 而非 Empty；操作按钮遵循 Button 状态。

### 4.15 ErrorState
- **用途/变体**：局部工具失败、网络失败、卡片解析失败、地图失败；保留已完成的其他结果。
- **尺寸**：局部 padding 16、radius-md、danger-subtle；图标 20、标题 14/20、500，说明 14/20，重试高 44、上距 12。
- **D/H/A**：容器静态；文案“天气查询暂时失败，请重试”，不用错误堆栈；重试 secondary，用普通 H/A。
- **X/L/F**：X 仅重试确实不可用时给原因；L 原位显示“正在重试…”与 Spinner、不清空卡片；F 在重试按钮且成功后不强制跳焦点。
- `role=alert` 只用于新发生失败的一次播报；保留输入与部分文字，失败详情可展开，不循环弹 Toast。

### 4.16 Tabs / SegmentedControl
- **用途/变体**：Tabs 切换详情视图；SegmentedControl 切换路线方案/当天与明天等小规模互斥选择。
- **尺寸**：Tabs 高 44、gap 16、选中下划线 2；Segment 外壳 padding 4、radius-md、surface-secondary，单项最小高 44、左右 12、14/20、500。
- **D/H/A**：未选 text-3→surface-hover→surface-active；Tabs selected brand + 下划线；Segment selected surface + 1px border-control，无大阴影。
- **X/L/F**：X disabled-fg；L 选项保持可见，内容区局部加载；F 环包当前项；键盘左右/Home/End，异步内容采用 Enter/Space 确认激活。
- Tabs 使用 tablist/tab/tabpanel 及 aria-selected；仅筛选且无对应面板的 Segment 使用 radiogroup/radio，不滥用 tab。

### 4.17 Divider
- **用途/变体**：水平、垂直、带分组文字；降低结构复杂度，不在每段正文之间加线。
- **尺寸**：1px border；水平上下 margin 16，垂直左右 12、高 16；带字 12/18、text-3、两侧 gap 12。
- **D/H/A/X/L/F**：仅 D，其他不适用；纯装饰 aria-hidden；语义分隔使用 hr，不接收焦点。

### 4.18 Badge
- **用途/变体**：未读计数、状态点 + 文本、状态标签；不与评分/业务标签混用。
- **尺寸**：计数高 20、min-width 20、左右 6、radius-full、12/18；点 6×6，距标签 6；数字最多“99+”。
- **D/H/A/X/L/F**：仅 D；计数使用品牌实底/on-brand，状态点使用语义色；若加载，计数暂不更改，不将未知表示为 0；其余不适用。
- 状态不可只靠点颜色识别；点击入口在外层 Button；名称包含完整未读数，装饰点 aria-hidden。

### 4.19 Rating
- **用途/变体**：只读星级、评分数字 + 评价数；本期不实现用户打分控件。
- **尺寸**：星 14、描边 1.5、gap 2，数字 14/20、500、tabular-nums；信息距星组 6。
- **D/H/A/X/L/F**：仅 D；已评分使用 food-fg，空星 border-control；L 用同宽骨架，其余不适用。
- 星级允许半星；可见“4.7 · 128条评价”，整体可访问名称“5分制，4.7分，128条评价”；缺评分写“暂无评分”。

### 4.20 Stat
- **用途/变体**：温度、路线时长、人均价、提醒时间；横向主指标、紧凑次指标。
- **尺寸**：默认值 24/32、500，强调 32/40、天气 40/48；单位 14/20 与数字基线对齐；标签 12/18、上/下 gap 4。
- **D/H/A/X/L/F**：仅 D；值 text-1、标签 text-3；L 同尺寸占位，其余不适用；整个数字组不单独成为焦点。
- 不用四个以上同等强调指标；最多三个并列，窄屏可换行；未知写“暂无”，零只用于真实 0。

## 5. 对话界面规范

### 5.1 消息结构与排版
- 消息组间距 24（手机）/32（PC）；同一 agent 回复内文字段间 12、文字与卡片间 16、卡片间 12。
- 用户消息右对齐，最大宽度列宽 85% 且不超过 560；surface-secondary、radius-lg、padding 12×16、16/24、text-1，无尖角。
- agent 消息左对齐、没有气泡与整块底色；正文 16/24、text-2，重要结论 500；不让整个回答加粗。
- agent 首段上方品牌行：24px Avatar + “Lumi”14/20、500，gap 8，距正文 8；正文和卡片对齐列左边，不为头像额外缩窄整列。
- 用户不显示头像，署名和发送时间收进可访问信息；复制/更多放回复末尾，手机始终可发现，PC hover/focus 可增强。
- 消息支持段落、项目列表、链接；列表缩进 20、条目间 8；链接 brand + 下划线，不渲染未经清理的原始 HTML。
- 时间分隔在间隔超过 30 分钟或日期变化时出现，12/18、text-4、居中、上下 24；同日“14:32”，跨日“11月17日 14:32”。

### 5.2 生成、工具步骤与中断
- 状态顺序：已发送 → 思考中 → 正在查询 → 流式回答/卡片 → 完成；允许工具失败后给部分结果。
- 用户点击发送后立即插入用户气泡；agent 区预留一行 24px 状态，避免先空白再跳动。
- “思考中…”只是过程反馈，不展示推理链；工具反馈使用“正在获取天气…”“正在查找附近餐厅…”“正在规划路线…”。
- 当前步骤为 16px Spinner + 14/20 text-3，gap 8；多个工具只突出当前步骤，已完成步骤折叠为“已完成 2 项查询”。
- mock 中可模拟 300–800ms 初始等待、800–2400ms 工具查询、40–100ms 文字分块；这些是测试配置而非真实服务承诺。
- 流式光标紧接最后一个文字片段；不在每个段落显示；卡片等待完整、校验后的结构再替换骨架，禁止半张 JSON 卡片闪现。
- 回复生成期间输入按钮原位切换“停止生成”；按钮不用危险红色，避免与失败混淆。
- 停止后立即移除光标/Spinner，保留全部已生成文字与完整卡片，尾部显示“已停止生成”12/18 + “重新生成”44px 操作。
- 中断请求的迟到分块不得插入当前消息；切换会话不允许旧请求污染新会话，具体取消机制由技术方案落实。
- 重试复用原用户问题，不新增重复用户气泡；重试单张卡只更新该卡，整轮重新生成则保留原结果直至新结果可替换。
- 网络失败保留部分答案，末尾 ErrorState + 重试；草稿保留；不得把用户主动停止显示为错误。

### 5.3 完成后的操作与追问
- 追问 chips 放在整轮回答（文字和卡片）之后，顶部 gap 12，最多三条，如“明天怎么穿”“换几家清淡的”。
- chips 左对齐、gap 8、按行换行；生成中不显示未确认的追问；点击表示发送该文字，先显示用户消息再执行。
- 手机快捷追问保持每行至少 44px 热区；空间不足换行，不截断“换一家”等行动意图。
- 最终状态不额外展示醒目的“回答完成”；查询来源与更新时间放具体卡片副标题，mock 明确标记“示例数据”。
- 用户滚离底部时，新输出只更新“回到最新”提示；完成、失败与停止都不得强行滚回底部。

## 6. 业务卡片视觉设计

### 6.1 共用信息层级与媒体规则
- 层级顺序：场景/来源（12）→结论标题（16）→核心指标（24–40）→依据（14）→行动（44px 按钮）。
- 卡片默认占满对话列；最多三项首屏结果，更多通过明确“查看全部”展开，不无限铺陈。
- 内容使用 Card 的手机 16 / PC 20 padding；媒体允许满内容宽，但不突破卡片圆角。
- 图片仅用于餐厅、菜谱、酒店；object-fit cover、radius-sm，不加浓重滤镜；失败用同尺寸图标 + 中性底板。
- 无图片时不保留无意义大空框；加载时保持预计媒体尺寸以避免布局位移。
- 价格注明“人均/每晚/起价”及币种；距离/时间写单位；所有 mock 卡片保留“示例数据”，真实模式才显示真实来源/更新时间。

### 6.2 天气穿搭卡
```text
[天气图标] 今日天气与穿搭              [杭州 · 示例数据]
  22°        多云            18° / 25°
  体感 21°   降雨概率 20%   风速 3m/s
  一件薄外套，早晚更舒服
  [薄外套] [长裤] [带伞备用]
  提醒：晚间降温，外出可加一层
  [看明天天气]                         [调整穿搭偏好]
```
- 温度 40/48 为视觉中心；天气状态 18/28；高低温与三项指标 14/20，间距 16，手机自动换行。
- 穿搭结论 16/24、500，距指标 16；最多三个 Tag + 两行建议；提醒只有确有必要时显示 warning 图标与文字。
- 天气符号沿用同一线性图标集，最多 32px；不使用写实大天气插画、整卡蓝色背景或动态雨滴。
- 城市未知先给“选择城市”入口；不能把定位失败猜测为真实位置。

### 6.3 餐厅列表卡
```text
[餐具] 附近适合晚餐的餐厅
```

## 7. 图标规范
- 统一推荐 `lucide-react`，24×24 网格、stroke-width 1.5、圆端点/圆连接，默认不填充。
- 应用尺寸 16/18/20/24/32；不为了视觉醒目加粗到 2.5 或混入彩色 emoji；星级半填充是唯一受控例外。
- 场景建议：衣 Shirt / CloudSun；食 Utensils / CookingPot；住 BedDouble；行 Route / MapPin；提醒 Bell / CalendarClock。
- 基础建议：发送 ArrowUp，停止 Square，关闭 X，返回 ArrowLeft，历史 History，重试 RotateCcw，更多 Ellipsis。
- 独立可操作图标最小视觉 20，热区 44；文字旁图标 16/18；图标与文字间距 8。
- 装饰图标 `aria-hidden=true`；纯图标按钮提供中文 aria-label；Tooltip 不代替可访问名称。
- 品牌标记仅允许单色几何光点/线性符号，不新增一套与界面描边冲突的插画语言。

## 9. 无障碍与交互可用性
- 达到 WCAG 2.2 AA：普通文字 ≥4.5:1；大文字（≥24px 常规或约 18.7px 粗体）≥3:1；必要图标/控件边界/焦点 ≥3:1。
- 已核验：浅色品牌 #35695C / 白色约 6.31:1；深色品牌 #8AB9A7 / #10241C 约 7.42:1；禁用色不得用于有效信息。
- 所有主题/hover/active/错误底色组合均需逐一检查；装饰 border 可低对比，但功能性边界必须用 border-control。
- focus-visible 使用统一 2px 环 + 3px offset，不移除 outline；避免 overflow 裁掉环；焦点不得被输入框/固定栏完全遮挡。
- 热区 ≥44×44 CSS px，相邻点击热区至少留 8px 的视觉间距；拖拽、地图手势、滑动都必须有非手势替代。
- 页面有 header/nav/main 等地标与“跳到对话”链接；对话标题层级连续，卡片标题不因字号大小随意跳级。
- 消息流用有序的消息列表与发送者标识；单独建立 `aria-live=polite` 状态区，播报过程状态与完成通知，不逐 token 朗读整个回答。
- 完成时播报“Lumi 已回复，可在对话区域阅读”；回答正文保留在可导航列表内；避免同时用 role=log 与第二 live 区重复播报。
- 工具更新只播报步骤变化，局部卡片加载用 aria-busy；流式光标、骨架、Spinner 图形对读屏隐藏。
- Input 有真实 label（可视觉隐藏），placeholder 只是示例；错误用 aria-invalid + aria-describedby 关联，必要说明不只存在 Tooltip。
- Button 使用原生按钮语义，导航使用链接；disabled 与 aria-disabled 不能混用后仍允许触发；按压切换用 aria-pressed。
- 图片按信息性提供 alt；重复名称的缩略图使用空 alt；地图提供起终点/路线步骤文字替代，评分提供完整数值说明。
- Sheet/Modal 提供标题、关闭按钮、焦点管理、背景 inert；不只依赖遮罩/手势关闭，系统返回行为由技术方案统一约定。
- 200% 字体缩放与 400% 页面缩放检查重排；不禁止用户缩放，表单字号不低于 16，长内容可滚动且不截断操作。
- 尊重 reduced-motion；深浅主题都验收中文长句、无图片、定位拒绝、未知评分、长地址与大数字。

## 10. 本期交付与验收边界
- 前端将表格映射为共享 design tokens，组件只引用角色；主题、断点、键盘适配由架构方案集中维护。
- 无需引入 antd 等大型库；底层组件先验证一致状态，再用组合方式承载七类业务卡片。
- 必验视口：320/375/390/768/1024/1440px；必验浅色、深色、键盘打开、横屏、reduced-motion 与键盘导航。
- 必验 mock：首次等待、工具查询、流式、卡片加载、部分成功、无结果、失败重试、停止、迟到响应、图片/地图失败。
- 必验连续对话中的布局稳定性：骨架替换不显著跳动、按钮 loading 不变宽、阅读旧消息时不自动吸底。
- 本文不新增业务能力与真实服务承诺；若产品字段变化，优先维持结论→依据→操作的信息层级和既定 token。
