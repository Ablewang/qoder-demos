# 接入、交易、死亡与退出

## 一、接入对象与现实前提

澄岚是有真实居民和物质生态的地方，蓝星来访者通过意识通道形成临时物质身体。现实肉身保留，需要供能、饮食、医疗照料和安全终端；投射不是把身体无条件留在任何地点都不会出事。

凝体由目的端合法节点按适配要求，从当地已验的真实原料或库存分配材料，不复制源端身体物质。原料按质量、组分出入账；组成改变须消耗工艺能源，不能凭空造元素。进食所用食物来自当地采购，代谢与组织改造须计入摄入、留存和排出，脱落物、损伤组织也有实际去向。

正常退出与普通投射死亡均回收可回收部分，身体瓦解不等于物质消失；残留、污染及不可回收组织由当地处理，真实损耗以库存补足。分配给投射体的材料及其脱落物不是个人可出售的新财产；合法采集、购入的独立物品另行保管，身体回收不吞掉财产。异地回收须由当地设备处理或实际运送，不随断线瞬移，也不改变连接冷却与意识创伤规则。

以一次70千克的凝体为例，若退出当次得到68千克合格回收料、1.5千克待处理残料和0.5千克现场残留，质量账仍为70千克，而可立即再配的库存只有68千克；下一次同规格凝体须另拨2千克合格料，待处理料经实际收集、净化和验收后才回账。额外进食、排出与组织增减单列，不能借样例将代谢物删去；补足库存是从真实其他库存调入，不是宣布2千克物质永久消失或凭能量无限生成。

蓝星2029年起公开使用接入设施，本部2047年，普通活动时间与现实1:1。长时间接入不会免费得到数倍学习年月。终端按身体状态、同步稳定和现有调度容量开放，不把所有未达高天赋者永久排除。

## 二、新人与旧用户

| 阶段 | 条件与职能 | 权限上限 |
|---|---|---|
| 年度成年认证 | 本年度达到成年条件、完成训练与现实登记 | 不要求十八岁生日与年度窗口同日 |
| 当期三日窗口 | 常规认证完成后三日内首次进入初渡台 | 错过等下一批，不永久失去资格 |
| 接引使测试 | 年度授权界面记录体质、同步与防护需求 | 不私下赠送高阶或全部规则权限 |
| 村长基础任务 | 本地管理员安排采样、校验和安全撤回 | 不改年度规则，不许杀居民换通关 |
| 离开初渡台 | 体质测试与基础任务均完成 | 先取得公开道路通行，危区需另验资格 |
| 旧用户再次接入 | 当前身体复核、通道与终端配额满足 | 不重复新人三日窗口，仍可因伤或限流暂停 |

木苏16岁，只在现实侧受监督训练与共鸣研究；特殊体质、哥哥认证或奖励材料都不能替她取得常规成年登录资格。其每次参与需本人同意、正常监护和可立即中止条件。

## 三、可以回去的东西

归墟普通装备、矿石、食品、材料不能随意识直接带回现实。当地财产留在当地，结束投射不让它们消失或自动入现实仓库。能够延续的是知识、经允许的技术记录，以及能量回传已经形成的身体和训练改变。

太平洋通天塔奖励是独立登记的现实具现渠道，有来源、额度、用途及负荷记录。每次具现均占用现实物质和能量预算，不能重复申领同一奖励、将背包全部改名奖励搬出，也不能凭苏木特殊认证取消额度。

木苏使用的激活材料通过登记奖励渠道取得、现实验收后使用，不是直接捡取澄岚矿石带回。现实锚阵与澄岚锚件分别采购和制造，两地只在授权范围交换规格、测量与工艺。

## 四、交易与合同

当地交付可以由现实货币支付约定对价，须经双方认可的中介与凭证核验；这不等于衡票、现实货币和奖励配额统一兑付。知识出售须区分个人经验、公共研究和受限维护数据。

走私涉及当地受限物品交付、奖励额度冒用或知识非法转移，不使用普通矿石直接出现在现实的设定。非法市场可存在，但有实体仓库、转运、付款和可追踪参与者，不是无成本黑洞。

危区合同列出损伤、撤回条件、现实照料、财产保管和争议处理。角色投射体死亡不注销债务，机构也不能以培养费用无限绑定人员。居民的土地、身体和工艺不自动成为外来者任务素材。

## 五、死亡的明确后果

| 对象或状态 | 后果与恢复条件 |
|---|---|
| 外来者首次投射体普通死亡 | 临时身体瓦解、未完成回传的积累损失、连接冷却和意识创伤；至少七个现实日冷却并经医疗复核后才可重接 |
| 三十个现实日内再次投射死亡 | 未恢复的连接与创伤叠加，可能造成不可逆认知或人格损伤；没有连续刷死的安全机制 |
| 直接严重意识攻击 | 即使没有先毁临时身体也可能伤及现实意识；首次遭遇不保证可恢复 |
| 原住民死亡 | 通常不可逆，没有另一具现实肉身和新人复活机制 |
| 现实肉身死亡 | 不因通道、记录或临时身体自动延续原人格；不提供无条件复活 |

已经安全回传的身体改造仍在；现实创伤、控制能力下降和未回传能量损失则会削弱实际战力。恢复依靠医疗、休整和重新训练。记忆损伤须有相应的意识受损原因，其范围与其他伤情一起记录。

首次死亡的缓冲来自正常通道与终端的保护，不能对已经失稳的危区保证同样效果。系统可以重建投射身体，不能凭一份人格备份宣称原人无损复生。

## 六、三种退出不能混同

**普通安全退出**：先完成当前交付、可用状态回传与临时身体可回收部分的回收，再断开通道，现实肉身恢复日常活动。安全区有常规服务，退出不抹掉疲劳和已受伤害。

**危险状态退出**：通道正在失稳或遭严重攻击时，先隔离、减载并稳定连接。强断可用于必要紧急救命，但可能产生反馈损伤，不能保证无代价；保护设备和他人协作因此有实际意义。

**长期异常绑定**：人体接口已承担持续结构负荷，普通登出不能解除。必须先建材料冗余、转移承载、保留必要回传，再按段解除。母亲早期自愿参加研究不代表后来仍可自由退出，正常新人规则也不能解决这一问题。

## 七、人员退出的技术保证

有限协作者离开时由非人体材料备用接替，不计任何人自愿反馈为备用，更不能把木苏或苏木永久当替补。两侧分别核验人员撤回后维生、隔离等不可停存量的最低负荷B与设备可用备用容量R；预定安全交接时长T不得超过备用维持B并供给冷却的实测持续时间H。按B的实测上界及留有不确定余量的R、H可用下界验收，须同时满足B≤R、T≤H。

任一不满足，不得开始人员值守或解绑；先补建材料备用，或安全迁移已有实际负荷并复验，不能只停新增、把不可停负荷留给人体。限流与降低需求只能减少可停部分，不能抹去B。

资格到期、个人撤回同意与设备报警均能触发停止程序。停止可以有必要交接时长，但不得利用不断新增需求拖成无限值守。详见[镜井工程](../02-澄岚大陆/04-镜井维护夹层与撤离工程.md)和[共同执行标准](04-证据权限与共同维护执行标准.md)。
