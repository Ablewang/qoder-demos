# 蓝星福凶地名册与当前可知规则

## 一、2047年的观测名册

本部将福地定义为能持续汇聚可修炼能量的地点，将凶地定义为存在载体失稳、感知干扰、意识侵蚀或有害能量结构的地点。同一片区可以二者并存。调查资格与能量品质不代表善恶，军事控制外围也不代表核心已经开放。

等级只用于当前管理：重点稳定区拥有显著富集及重要设施；研究区有可重复观测但需限制；高危区按扩散、不可逆损伤和能否撤离单独分级。资格会因监测和事故变化，不将一个永久数量当成自然定律。

以下所在地均按蓝星地理记录。国外片区由所在国及约定项目管理，研究联盟不是该国的领土拥有者；宗教、居民和遗产管理主体保留相关意见。

## 二、华夏及周边重点片区

| 片区 | 当前可核验的功能或现象 | 进入与管理条件 |
|---|---|---|
| 昆仑 | 稳定、缓冲与回传结构，人体接口和旧锚阵可核查 | 外围公域、研究驻区、家族边界、技术核心分层；母亲退出须专门维护 |
| 冈仁波齐 | 坐标参照与意识清噪，重复检测可比较 | 朝圣与核心研究分开，不把清噪当万能治疗或复活 |
| 峨眉 | 稳定富集与低风险承载训练 | 公共训练、门派与研究者共享有限区域 |
| 武当 | 可记录的节点共鸣与保护区 | 学府、地方行政和门派协作，不以传承身份垄断公众安全 |
| 蓬莱海域 | 水下富集与可重复探测的结构异常 | 需水下设备和救援保障，不能凭能飞或能接入直接抵达深处 |
| 神农架 | 表层富集，核心长时暴露会扰乱自我感知 | 表层观察与核心禁入严格分开，短期稳定不证明长期安全 |
| 大兴安岭 | 分散林地富集和不连续电磁干扰 | 林地监测、边境协作与生态保护，不推定已有可开采大矿 |
| 长白山 | 湖下富集和火山环境叠加风险 | 地方及跨境协定，水下与火山安全并行 |
| 三星堆 | 可检测残片与材料结构样本 | 考古与样本许可，不因物品异常就取得完整秘密知识 |
| 终南山 | 小范围稳定修炼环境、隐士社区 | 居民生活与开放研究有边界，不能征用全部私人传承 |
| 罗布泊 | 地下富集、表面镜像干扰和可测回路 | 表层保护结构与事故触发状态并存；不得用炸毁表层换取矿藏定位 |

## 三、海外和公共片区

| 片区 | 本部可用的当地记录 | 主要管理边界 |
|---|---|---|
| 马丘比丘 | 身份匹配、承载阈值和意识状态记录 | 当地居民与保护主体参与；本部不把记录等同于复活资格 |
| 奇琴伊察 | 地下传导结构和祭仪空间中的共鸣 | 地方保护、研究许可和旅游层分开 |
| 百慕大海域 | 规则装置、信息层与防御反应 | 航行安全及有限海下研究，异常不等于整个海区随时吞人 |
| 复活节岛 | 岛屿节点与材料排列对照 | 所在国与居民共同许可，不自动成为太平洋军事争夺目标 |
| 亚马逊片区 | 分散富集与不同居民聚落的节点经验 | 拒绝外来接触的居民保有选择，不得以研究名义征用生活区 |
| 巨石阵 | 周期性共鸣与材料方位校验 | 本国管理与跨校合同，合作联盟不代替主权 |
| 纽格兰奇 | 有条件重复的内室声学和清噪样本 | 文保进入额度与研究公开协调 |
| 辛格维利尔 | 地热释放与节点能量流动 | 地质风险、公众访问与实验强度分开 |
| 耶路撒冷片区 | 多方关注的地下旧结构与共鸣记录 | 本地复杂管理、宗教权利与理事会有限协调，不默认国际机构吞并行政权 |
| 恒河研究段 | 可采样的传导介质与局部节点响应 | 本国监管、居民用水和宗教活动优先于无限取样 |
| 吉萨 | 知识记录的有限读取条件与结构观测 | 当地文保、跨方研究共管和技术读取资格分别成立 |
| 麦加研究外围 | 清噪与水介质样本记录 | 宗教与本地管理许可，科研不享有无条件进入权 |
| 乌鲁鲁 | 岩体节点与本地仪式中的材料维护经验 | 原住民管理意见，不能用资本投入置换全部进入权 |
| 富士山 | 火山节点与林地感知干扰 | 地方生态、防灾与研究许可并行 |
| 纳斯卡 | 外围阵列响应、内部共鸣噪音 | 外围研究不证明内部安全，维护须先降低共振强度 |
| 埃塞俄比亚高地 | 方尖碑材料与分散节点样本 | 本国与当地社区协作，研究收益需说明 |
| 亚特兰蒂斯水下片区 | 封闭结构与少量信息层响应，位置资料受限 | 不将未进入的结构自动解释为服从某方的文明，也不借它解决本部全部问题 |
| 南极塔体驻区 | 全蓝星最强的受控回传枢纽及高密度环境 | 超常稳定区兼高危区，专业人员进入，公众由远程终端使用 |

这些地点的日常仍由当地居民、游客、维护者和研究者组成。峨眉的公共训练名额要预约，终南山的居民保留安静住处；有些人终身在一个节点工作，有些只去过外围，并不关心更远处的同类现象。研究站之间交换带有采样条件和权限的对照资料，昆仑与澄岚的行动则须在本地重新验证。

## 四、高危片区的现象与禁令

| 片区 | 当前风险分类 | 应对边界 |
|---|---|---|
| 哀牢山 | 意识残片干扰、方向感异常和长时束缚 | 外围监测，人员不以主动暴露追求修炼收益 |
| 罗布泊 | 镜像回路、方向与索引失配 | 按已验证路径短时工作，不把幻象作为司法证词 |
| 神农架核心 | 弥散意识污染与自我边界下降 | 时长监测与双人校验，核心样本不能随意带入居民生活区 |
| 贵州麻山 | 强烈情绪污染与受限载体结构 | 不拆除未知约束装置，不因能量精纯就判定对人格无害 |
| 象雄遗址 | 定向信号翻转与载体连接被牵引 | 最高风险封控，不能作为离开蓝星的捷径 |
| 霍亚森林 | 持续旋转共鸣、眩晕与认知干扰 | 可测外围，避免长时同步暴露 |
| 埃尔德加裂缝 | 认知复杂度下降与边界渗漏 | 地热和意识风险分别监测，不靠常规防毒设备宣称安全 |
| 达纳基尔 | 高热、腐蚀及不可控意识剥离 | 不把受害者记忆情感称为该烧掉的杂质 |
| 奥卡皮禁区 | 稳定结构快速退化，现阶段无安全人员回收路线 | 绝对禁入、远距监测；本部不安排靠主角血脉免疫穿越 |
| 纳斯卡内部 | 持续错误共振与意识磨损 | 外围采样，正确限流在先、接近阵列在后 |
| 索诺拉片区 | 异常依附与多重人格信号 | 区分原人格和附着异常，救治先于一律清除 |

## 五、第一部使用的记录范围

第一部真正深入的旧节点是昆仑，其余多作为记录、材料结构对照和风险边界存在。名册不包含这些地点的隐秘建造者、诸神真实身份、死亡世界结构或更广大战场；对本部行动有影响的可观测规则已在此记录。

居民权利、研究许可、现实防灾和技术认证分别计算。外部样本可以校验方法，不能代替母亲的同意、镜井认证、实际调度窗口或冗余承载。
