# 家庭案件时间线、责任与证据链

## 一、案件范围与三个不同事实

案件发生在蓝星华夏临江市苏家、研究试验站及昆仑实际维护驻区，与蓝星—澄岚连接工程有关。宁川市华夏学府承担复核，西宁是昆仑交通中转，太平洋通天塔人工岛用于受控测试，南极连接塔承担核心调度。镜井本地维护夹层只处理连接记录、回传与调度。

调查沿三个事实推进：苏正淮确实遇害；木向岚失踪后被错误推定死亡；她存活，并从主动研究逐渐转为不可退出的接口。父亲死亡检验、母亲失踪登记与昆仑绑定各有材料来源。苏木没有亲眼确认父母两具完整遗体。

澄岚居民生命、载体和旧居是真实利益，调查中的地方负荷与安置资料也来自实际损害。苏木的局部认证提供技术线索，司法认定由材料互证与正常程序完成。

## 二、从研究到遇害的七步

1. **资助与资料来源。**苏正淮以普通商人身份资助公开能量环境研究，提供资金、组织、材料和运输；木向岚提供昆仑旧节点资料及异常样本。样本来自苏木童年融体晶体一次微量析出，非可随时取出的本体。核心推导由专业团队完成。
2. **研究触及工程利益。**团队结合现代监测和昆仑资料，判断持续扩大回传会推动蓝星结构同化，准备公开风险、限制试验规模。公司会议、运输及资助记录留下研究活动、公开意图和交接痕迹。
3. **顾衡事前授权。**顾衡批准封存完整终点模型，要求强制控制研究人员与样本，接受守门人执行网络非法协助。授权原件确认控制安排，对现场后果的知情时间另查。
4. **郑崇落实非法控制。**2034年郑崇任试验站安全负责人，兼守门人执行成员，掌握团队出入、家庭位置和样本登记。他夺取材料、阻断撤离，以安全职务控制现场。
5. **父亲遇害、母亲被救。**郑崇为夺资料，对拒绝移交研究材料的苏正淮直接实施致命暴力，造成胸部创伤、失血性休克，又以现场控制阻断及时救治，苏正淮死亡。死亡检验和原始急救确定损伤及致死机制，站区独立安防备份片段识别郑崇直接施害，值守与交接确认身份、时段和救治阻断；片段只保有其记录到的现场。木向岚启动昆仑接应，被救走，没有获确认的本人完整遗体。苏正淮确死，晶体修复、意识记录或替代身体均不能令原人格复生。
6. **记录遭污染。**郑崇操纵现场及交接，把父亲创伤归作试验站事故伤害，以样本来源消失解释目标已处理。原始医疗证明创伤，施害人和时序则需影像、值守互证；事故保全副本与家庭旧案的关联被封存口径遮蔽。官方确认父亲死亡、母亲失踪，后据污染材料形成母亲推定死亡的程序结论。
7. **顾衡事后知情与延续。**顾衡收到明确载有父亲死亡的后续报告，仍批准封存、续批和延续工程，没有移交正常调查。事前授权、收到报告后隐瞒、继续利用分别形成责任链。

2034年已有资源牟利与非法协作的前身网络，2035年后利用派稳定成型。前身提供当年的执行协助，规模仍按当年记录确定。守门人仅指本案材料控制、人员阻截和非法交接网络，外围联系人知情到何处逐人核查。

## 三、从救走到被绑定的六步

1. **自愿参加。**木向岚回昆仑后，为压住局部异常主动参与稳定节点研究，有真实研究意愿与旧节点知识。
2. **集中承载形成。**守成派认为现成人体接口最可靠，接受顾衡现代调度设备与资源，建立由她承担基础稳定的结构。
3. **负荷上升、出口受限。**回传持续扩大，母亲负荷增加，对外联系、解除程序和替代载体建设逐渐受限。
4. **失去实际退出条件。**项目以保护节点、接口为名维持她运行，掌权者阻断解除所需资源和技术保障。早期自愿与后来无法退出是两个不同阶段。
5. **小姨获得生命线索。**木向晚通过命牌知道姐姐可能存活，命牌只确认生命联系，不提供位置、损伤、完整绑定或解除方法。
6. **进入调查体系。**2041年小姨取得部分节点档案，仍无核心接口解除权。留下的昆仑钥匙证明家族身份和接近家族边界的资格，非太初晶认证。

接应者提供救援经历和旧记录，守成派中的具体人员留下持续绑定、封锁联系及冗余建设的操作记录，改革者提供原始绑定和分段接替材料。救援与后来限制分别查证，改革者的解除方案仍须实测。

## 四、苏木未被继续追查的原因

2029年苏木被收养时佩戴晶体，随后融体；童年只有一次微量样本进入母亲研究及封存项目。郑崇等人掌握的旧检测特征被误判为特殊能量晶体，没有准确追踪融体本体的技术。

2034年后，本体隐匿，样本封存，家庭人员由不同机构接管。郑崇把来源消失写成目标已处理，错误检测、污染记录和项目保密共同使执行层失去针对苏木的有效判断及材料通道。

2047年成年认证与旧样本发生可复核同源响应，原误判才被推翻，调查和现实阻截重新启动。对手仍只能观察局部特征，不掌握晶体全部功能或人物全部经历。

## 五、六类证据及证明范围

| 证据与独立来源 | 能证明 | 单独尚不能确认 |
|---|---|---|
| 成年认证与旧样本同源响应：新认证记录对照封存样本 | 关联仍活跃、非静态残留，与家庭研究有关 | 回应者就是完好的母亲；现场凶手与晶体全部功能 |
| 试验站原始负荷记录：运行原件 | 行动前有人压缩安全间隔、提高回传 | 下令者、现场加害人和完整动机 |
| 父亲公司资助、运输及会议材料：独立业务留存 | 团队研究与准备公开风险，资料交接和官方口径不一致 | 现场加害身份，或全部技术结论的正确性 |
| 周卫明保全旧案与交接、医院原始急救与死亡检验、独立站区安防备份 | 创伤与失血致死，郑崇直接施害和阻断救治，结案修改、交接异常 | 仅凭职务认定致死，或顾衡知道全部现场后果 |
| 项目授权和事后封存报告：异地审批原件、具名批注、续批与实际拨款 | 顾衡批准强制处置，本人知晓死亡后隐瞒、延续 | 顾衡亲手加害，或归航技术完全无效 |
| 昆仑原始绑定与母亲有限自主回应：运行记录加本人意见 | 本人存活，早期参与与后来退出受限的两个阶段 | 立即拔除安全、全部外部动机与全网稳定 |

认证、运行、业务、医疗安防、异地审批与昆仑六条渠道各有材料缺口。央央、墨墨仅有零散生活印象，无完整录像或遥察；回忆提示核查，不填补现场与授权。

## 六、材料怎样逐段互证

**研究与人为加速。**公司资料确认公开意图和工作背景，原始负荷确定加速回传的时间及变化；授权与交接再连接下令者。技术异常和人员动机分别核验。

**现场与死亡。**原始急救、死亡检验确定胸部创伤、失血性休克与救治延误，安防片段识别直接施害者，值守和签收核身份、时序及控制范围。月三至四，周卫明依未替换交接的事故保全编号，依法取得站区独立备份，受托人和律师协助兄妹取得医院原件副本。安防片段当年作为事故、赔付档案由第三方长期封存，非普通摄像循环保存十三年；只覆盖片段内行为。医疗、影像与交接对上，现场控制才连到郑崇致死责任。

**收到死亡报告后的决定。**月七双侧异常、已证现场和事前授权触发隐瞒调查及独立项目审计。周卫明依法调宁川异地审批留存库的2034事故报告、顾衡具名批注、续批和实际拨款。报告明确载有父亲死亡，批注、续批由专业鉴定核验，再与签收、拨款和实际工程负荷交叉对时，证明顾衡本人知情后封存、继续批准。小队保护调档交接与见证人。原件当年按项目代号封存，未与家庭旧案关联，业务访问控制未销毁这些依法留存副本；重建关联、取得调查授权使材料可被调取。

**存活与不自由。**同源响应提示活跃关联，命牌提示生命可能；月四昆仑原始绑定与母亲有限自主回应确认本人、实际承载及退出受限。她确认现状、表达退出意愿，拒绝未经苏木同意的替换；耐力和接触范围限制了可提供的信息。

**工程评价。**归航局部迁移、真实救援及强断风险分别由运行与救援记录评价。犯罪调查处理强制授权、隐瞒和退出限制，不以犯罪成立推定所有模型无效。

**安全救援。**活跃意识辨认、分散材料实测、双侧联合模型、旧认证、实际窗口及监督资源协议共同形成条件。镜井内侧处理旧绑定，现实团队合法接管调度、切外部干扰；先转承载、保必要回传，再分段解除。木苏不作为替代永久接口。

## 八、保全与程序

材料注明取得地点、接触者、原件或原始版本、时间标识、签收交接与复核，复制件标来源，污染版与未替换版比较。技术异常、人员责任和司法认定各循相应程序。

公司业务、试验站运行、警方旧案、工程审批与昆仑绑定分别取得。苏木读局部方向及修改痕迹，沈遥独立同步记录，梁知秋和跨团队复核技术，周卫明、律师与受托人依法保交接，母亲回应与运行资料互证。

共同材料由多方保全，证人、家人、居民个人信息与技术数据分开，公开经合法程序处理。解职和拘捕后，授权、后续隐瞒、获利及限制退出的调查继续。

## 九、责任与结果

| 对象 | 查明的责任 | 结果及调查范围 |
|---|---|---|
| 郑崇 | 现场加害、材料控制、阻断撤离救治、修改记录 | 证据保全、拘捕并移交刑事追责 |
| 顾衡 | 强制授权、事后知情隐瞒、工程延续、接口利用与人为加速 | 解除工程职务和调度权，分别进入正式责任调查 |
| 利用派相关执行及获利者 | 非法协助、转资料、阻截证人、岗位牟利 | 按实际参与与知情分别调查 |
| 昆仑具体绑定参与者 | 封锁联系、解除与替代建设，维持不可退出接口 | 救援、改革与持续限制的行为分别核验追责 |
| 公共机构具体人员 | 批准、污染记录、隐瞒、非法执行 | 按行为调查纠错，保留正常救援和研究 |

父亲死亡与执行、决策责任查清。母亲月九恢复自由，身体、意识耐力及家庭疏离进入长期康复，不恢复接口或家庭劳力。小姨交还可公开信息，隐瞒造成的信任损伤仍需相处；妹妹回学校与治疗生活。

苏木交出本地独占和高效收益，晶体及双分身保留，没有更大同类独占补偿。当前临界片区稳定、强迁被阻，部分城区与旧居永久改变，审判、康复、安置和长期维护接续。
