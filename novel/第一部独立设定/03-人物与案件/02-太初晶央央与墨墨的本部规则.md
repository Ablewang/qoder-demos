# 太初晶央央与墨墨的本部规则

## 一、名称、可知范围与状态史

太初晶是苏家及当地研究者对黑紫色晶体吊坠的约定名称，不等于已经确认其类别和来历。其起源不明，不构成独立追查任务；本部只按实际观察、样本检测及旧维护认证定义能力。晶体本体、辅助意识央央与墨墨、现实中的显现不是同一对象，不相互借用未获验证的能力。

| 时点 | 可确认状态 | 信息与权限边界 |
|---|---|---|
| 2029年收养 | 苏木在收养时佩戴晶体，随后融入身体 | 家庭照片仅支持当时外观，童年不长期外戴 |
| 童年一次析出 | 融体后出现一次微量样本，木向岚保存用于节点比对 | 不能重复索取本体，不产生无限样本 |
| 2034年案后 | 样本进入封存项目，本体隐匿于苏木体内 | 旧检测误判来源消失，不能准确定位本体 |
| 成年认证以前 | 双分身的能量种子随苏木长期留存 | 只有零散生活印象，没有两个清醒的完整旁观者 |
| 2047年成年认证 | 首次完成当前身体、意识状态与旧协议的主动匹配 | 同源响应可验证，只解锁本地认证，不等于知晓全部案件 |
| 认证第二天 | 黑紫晶吊坠重新显现，主要作为连接媒介；央央、墨墨激活并形成独立意识 | 不倒写童年一直外露、分身一直在线 |
| 本部维护过程 | 有限调用局部痕迹读取与本地维护权限 | 调用有真实负荷，不能扩展为整座大陆管理权 |
| 本部终局 | 放弃本地维护夹层个人独占授权及附属收益 | 晶体、基础增益和双分身保留，不以毁坏结算 |

样本同源只说明有关联的局部能量结构。木向岚用于研究，郑崇等人误判为特殊能量晶体，均不能据此识别全部功能。成年重新匹配推翻材料来源已消失的判断，而不是让检测者获得全知。

## 二、四项能力与共同负荷

| 能力 | 本部用途 | 实际边界 |
|---|---|---|
| 天赋放大与能量精炼 | 提高训练效率和已有资源的可用程度 | 不消除身体、意识、材料和训练门槛，不任意改写他人天赋 |
| 意识稳定 | 抵抗部分污染、干扰与短时失稳 | 严重过载仍损伤意识，不能替代所有人的防护与救治 |
| 局部规则痕迹读取 | 检查连接、修改及异常方向 | 需实际接触节点或同源样本；信息有缺口，不自动解释人员和动机 |
| 有限维护权限 | 通过旧协议进入认证夹层，执行局部连接维护 | 权限受任务、区域和负荷限制，不是全局控制 |

四项共同耗费苏木的身体与意识耐力，占用节点运行余量。须保留调用时长、能量投入、负荷变化、休整及失败记录；疲劳不能凭意志清零，过载时应限流、撤回或转移承载。苏木稳定自身，不代表其行动不会把压力转给居民或现实接口。

父亲不可复活；复制记录或恢复能量不能变成原人格复生。晶体不能无限生成资源，不能凭触碰赐予所有人适应能力，不能代替专业研究、司法复核、现实设施执行及当事人同意。长期绑定仍须先转移承载、保留必要回传、分段解除，一次调用不安全解决所有接口。

本部约九个月，苏木由一阶至六阶成熟，终局触及七阶条件；澄岚最高常态记录九阶，晶体增益不使他成为最强者。成长效率不等于行政资格，木苏16岁不能借晶体获得常规成人登录例外。

## 三、世界与承接区不提供额外特权

澄岚大陆陆地约3.2万亿平方公里，面向蓝星所在银河系全部生命谱系，八方承接不同源地区域，中央是大陆自身的繁华腹地。主线活动的初渡六区仅为东南万岬域约12万平方公里、150万居民的片区；初渡台位于片区南部初渡岸，是规则凝聚临时物质的新人承接区。临时不等于没有物质，原住民生命不按新人测试重置；晶体不因大陆广大而扩大读取、资源或权限范围。

接引使是年度授权的规则界面，只办理当前承接事项；村长是合同驻守的原住民管理员。两者不能赠送大陆权限、替晶体完成旧协议认证或取消负荷。首次成人认证三天仅是新人窗口，离开承接区后的培养、交易、死亡及退出另受当地运行标准约束。

## 四、镜井本地维护夹层

本地维护夹层位于初渡六区北部镜井台地的镜井，处理与蓝星连接有关的记录、回传路径和调度结构。其作用限于这套连接网络，不统辖其他地点的全部规则，不是全局控制室。苏木凭太初晶旧协议认证进入，资格不由战力、家族钥匙或现实工程职务替代。

顾衡不能进入这一认证夹层，但可通过尚未交接的现实调度端调整回传时序、干扰负荷和运行条件。内侧维护与现实调度接管是两项必要工作：苏木处理旧认证关系，秦岳等人保护设施、切除干扰，梁知秋等人复核两侧负荷。控制一座塔或取得内侧认证均不能自动完成另一侧任务。

苏木可开放范围明确的协作窗口，须列出对象、时限、操作和中止条件；不是复制整个晶体权限，也不绕过接入资格、防护或居民同意。窗口内的成功仍需外侧持续执行，不能只写一次授权就永久安全。

## 五、种子记忆的证据边界

种子长期接触苏木留下零散生活印象，激活后两分身以不同侧重理解这些印象。可熟悉习惯、情感倾向与家庭联系，但没有连续录像、逐秒时间轴或完整现场回放。

不包含离开苏木感知范围后的监控，不知道小姨离开后的全部调查，也不能远观母亲承载生活。熟悉情绪不是读心，无法据童年印象认定谁授权、谁加害、谁修改记录。印象与材料不符只能提示核查；新判断必须来自可接触节点、样本、独立记录和现实协作，不能在空缺中补出答案。

分身回忆不代替证据链宣判。两者都觉得某人可疑，也不足以成为拘捕或公开指控的依据。

## 六、非实体显现与现实操作

央央、墨墨在蓝星显现为苏木可感知的非实体意识投影，没有自由活动的物质身体。不触物、不搬证物、不递文件、不打开门、不操作现实设备，也不以实体治疗或挡伤制造例外。

它们不能任意远程看人、独立外出侦察或侵入现实系统。苏木感知到投影，不等于第三方看见或记录同样内容，公共见证必须有现实记录和他人实际接触。节点辅助判断也受苏木当下信息范围及本地权限限制。

## 七、央央与墨墨怎样亲近苏木

央央认得一些日常感觉：苏木专注修东西时会忽略休息，旧饭桌的印象让他安心。激活后，她喜欢陪他看手绘图，尤其偏爱被涂改过的岔路，对画得整齐的成图反而没那么有兴趣；苏木说不清这来自旧印象还是她自己的选择。她亲近人靠陪着，不急着把沉默变成答案。月五母亲回应变长，她也留恋这段接触，替苏木找过继续试验的理由；看到他疲劳时却会不告而别，撤掉自己的辅助，令他恼火。她能察觉熟悉动作的变化，不能读出苏木没说出口的心事。

墨墨较擅长比较局部协议与响应顺序，喜欢把被打断的核对做完，却不喜欢别人替他整理已做的标记。他记得的修器具印象比家庭面孔清楚；苏木认真研究一处旧接缝时，他会主动留下来陪着，对称赞则往往避开。他偏爱平稳、重复的低量试接，有时要求苏木重做一项已经够用的核对，只为弄清细小差别，耗掉休整时间。月一他也被熟悉回声误导过；新扰动和沈遥的独立记录才使他改判。他能说明永久置换的局部暂稳条件，对苏木为什么愿意留下并没有一个完整答案。

两者的零散印象不完全相同，激活后也在积累自己的偏好。它们会为陪伴、未完成的事和辅助方式争执，不固定代表亲情与公共利益。月七央央不愿苏木失去出门勘路的生活，墨墨仍想查清置换后的维护顺序；两种反应都不足以决定交易。高负荷操作靠实际数据、限流与接替条件推进，苏木和其他当事人各自作决定。

它们可以拒绝继续辅助，但没有能力替母亲、妹妹或居民答应任务。终局两位独立意识都留下，不合并，也不以牺牲其中一个补材料余量。

## 八、终局放弃的准确对象

月四起，苏木在实际维护合同与原始认证核验后，取得一条规模有限的高效精炼收益支路及相应优先调用，有上限、锁能与维护账。他用收益改善训练恢复、支付器具修理，短时优先调用支持母亲减载；合同和初步退出设计也记录其配套材料与锁能可转作接替冗余。月七修订模型将转换列入母亲退出计划，居民维修储备不计入可用容量。月八施工先暂停个人调用，月九才永久关闭、转换用途。最优新人配额仍未补回。

终局交出本地维护夹层的个人独占授权，停止该高效收益支路，将已配置的材料与锁能转为公共退出冗余，再把长期授权改为共同作业。苏木以后按普通配额安排训练，恢复更慢、要自行排班和付费；不能从旧认证绕回优先调用。晶体本体、四项基础增益、央央和墨墨保留，不毁神器、不牺牲分身。

终局没有另发更大的同类独占，苏木继续按普通合同接活与排班。共同维护落实于现实调度、替代载体、联合模型、居民参与、公共投入和监督；退出靠材料冗余接替，容量不足的段补建或安全迁移后复验，并限流停止新增。
