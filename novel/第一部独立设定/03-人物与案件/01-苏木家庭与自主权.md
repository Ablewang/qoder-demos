# 苏木家庭与自主权

## 一、家庭、年龄与舞台

本部从2047年起跨约九个月，现实家庭居于蓝星华夏联盟临江市。苏木在宁川市华夏学府培养，调查经西宁中转抵达昆仑实际维护驻区；太平洋通天塔人工岛与南极连接塔分别承担受控测试和连接调度。苏木登录的澄岚大陆是接入者实质投射、原住民真正居住的世界，不是可以重置居民生命的游戏。

| 人物 | 2047年身份与年龄 | 家庭关系及工作边界 |
|---|---|---|
| 苏木 | 18岁，成年认证者 | 收养家庭的儿子；调查者，不是全知裁决者 |
| 苏正淮 | 2034年遇害 | 养父、普通商人，资助研究与组织协作 |
| 木向岚 | 存活，年龄不另定 | 养母、昆仑节点研究参与者，后来被限制退出 |
| 木向晚 | 29岁 | 母亲的妹妹、兄妹的小姨，连接家庭与调查体系 |
| 木苏 | 16岁 | 妹妹，与苏木无生物血缘，家庭关系不因此降格 |
| 周卫明 | 成年警察，年龄不另定 | 正常接案的程序性盟友，不是预先派来的监视者 |

2029年苏木以婴儿身份被收养，2031年木苏出生。2034年兄妹约5岁、3岁，小姨16岁；2041年约12岁、10岁，小姨23岁。年份年龄取约数，不另设生日制造冲突；小姨离开时妹妹不是5岁。镜像名字体现亲情，收养事实不取消已经成立的父母子女关系。

## 二、苏木的目标、缺陷与责任

苏木慢热、护短，喜欢修器具、踏勘和收藏手绘路线，也享受队友先问他怎么办。他记着幼年一家四口周末同桌、母亲分碗筷的习惯，想让母亲回来、妹妹重新依赖自己，以为恢复饭桌就能补回十三年。照料常被他做成别人必须遵守的安排。最难承认的是：父亲的位置永远空着，母妹也已经有不由他安排的生活。

月五他在栖衡中转，把已承诺先做民用旧驮道备用配置的首批锚件东送母亲配对试验。木向岚真实减载、回应更久，他明知矿工还得等，却觉得值得。工序延期暴露后，他先赔钱、催工，以正常资产同意和合法医疗审批自辩，期待多付加工费能追回；旧路仍错过季节，矿工运费误工持续，程野的担保信用受损。月六另一次模型过载造成母妹损伤，两项责任分开记录。程野完签约护送后退出私人队，赫安不再信口头优先承诺。现实件另采购，材料与履约边界见[执行标准](../05-运行规则/04-证据权限与共同维护执行标准.md)。

他的贡献是调查同源连接、读取局部痕迹、取得旧维护认证；18岁不意味着懂全部工程、司法和资产管理。善意维护也会改变负荷、把危险转向另一侧，调用与失败须接受独立记录和复核。本部从一阶成长至六阶成熟，终局触及七阶条件；澄岚最高常态记录九阶，他不是最强者，研究者与高阶执行者仍不可替代。首次成人认证三天只限定新人承接窗口，不赋予所有后续行动豁免。

他担心木苏受伤，起初先替她排好训练和休息，再给必要信息，妹妹对此不满。月四有限参与、月六停止和月七拒绝，使他逐渐改为说明实际风险、保留知情和中止，不再用停任务连带停掉消息。月七他曾愿意永久接替母亲，最后拒交认证；母亲的拒绝与他的决定分别成立。

## 三、苏正淮：商人、公开意图与真死

苏正淮个人控股约20亿，变现及相关处置后为两兄妹留下约15亿资产；两者不是可相加的35亿现金。他提供资助、材料、运输与组织支持，能理解研究意义并选择公开风险，核心推导由专业团队完成，不另添特殊修炼身份。

团队把现代监测与昆仑旧节点资料对照，判断持续扩大回传会推动蓝星同化，准备公开结论并限制试验规模。2034年强制控制行动造成他死亡，父亲真死且不可复活。公司留有资助、运输和会议材料，可证明研究活动、公开意图与交接异常，不能单独证明现场凶手，也不是解释全部问题的万能遗书。顾衡的授权、事后知情与封存，同郑崇的现场加害、记录修改分别追责。

## 四、木向岚：参与研究不等于永久同意

木向岚出身昆仑隐士家族，有修炼能力与旧节点知识。她使用苏木童年融体晶体一次微量析出的样本比对节点；样本不等于可随时取出的本体，她没有太初晶维护认证，也不能由此判断苏木全部能力。

| 阶段 | 状态与权利 |
|---|---|
| 2034年现场 | 父亲遇害后启动昆仑接应，被救走；没有确认其本人完整遗体 |
| 返回昆仑初期 | 为压住局部异常，自愿参与稳定节点研究，有真实主动意愿 |
| 长期运行 | 回传扩张、负荷上升，联系、替代载体建设与解除程序受限 |
| 中期重新联系 | 在有限耐力内确认现状、表达退出意愿，拒绝未经苏木同意的接口替换 |
| 交接救援 | 本人参与有限交接，先转移承载、维持必要回传，再逐段脱离 |
| 恢复自由后 | 身体损伤、意识耐力下降与十三年关系缺席仍需康复 |

守成派接受现代设备和资源，将现成人体接口视为可靠缓冲。后来以保护节点为名封锁退出，使她成为不可退出的稳定部件；早期同意不能替代后续持续同意。她的中期回应是本人意见，不是供别人解读的生命噪声，但不连续、不完整，须与节点记录互证。她知道自身承载和接触过的研究，不能证明所有外部决策动机，也不能保证全网安全。

木向岚说起损伤与退出时很冷静，常把苏木问到的十三年缺席改答成某段负荷、某次试验。她不是没有愧疚，而是不知怎样面对已经长大的孩子，也怕一旦承诺回家，就再度被期待接管所有人的生活。研究仍是她认得自己的地方；她后悔退出被封锁，却不愿把当年的主动研究全说成骗局。月四确认本人后，她先追问原始研究笔记有没有保存，要求了解绑定与地方承载，没答应苏木回旧居、接管妹妹的打算。她记得孩子的旧习惯，对他们现在的学校、朋友和脾气却需要重新认识。

月七苏木愿意接替，她仍拒绝配合永久置换，自主交接路径中断。顾衡可依原绑定记录强制绕过她，技术条件没有因此全部失效；苏木面对的仍是一个能很快救母、却要接受母亲被强制交接的办法。他最后拒绝交出旧认证。

终局她同意分段解除，由独立医疗团队安排康复，先不回临江旧居。她进入康复后先想取回旧研究笔记，在耐力允许时核对曾被搁置的问题，不急着搬回旧家物件。第一次短聚，她照自己能承受的时长与孩子见面，认真听木苏说学校里的事，也会在话题触到十三年缺席时转向笔记。苏木仍觉得不回旧餐桌像又一次失去，两人的理解没有立刻一致。她爱孩子，却不想回到从前的生活，也尚无能力恢复家庭劳力。分碗筷的习惯留在共同记忆里，父亲的空位仍空着。

## 五、木向晚与周卫明：照料、隐瞒和程序

木向晚在2034年只有16岁，深度承担情感照料，但不能独自合法负责幼童、巨额财产与全部调查。她与周卫明、律师、受托人建立正式成年监护及生活安排；成年责任人保障日常事务，小姨作为亲属参与，不省略制度责任。

命牌使她知道姐姐可能存活，只能确认生命联系，不能定位、评估损伤或给出解除办法。2041年她主动进入官方调查体系，换取档案与接近节点的机会，仍无核心接口解除权。昆仑钥匙只是家族身份与接近家族边界的资格，不是维护网络万能钥匙。深夜离开、留下钥匙属于欠缺解释的告别；离开前已完成照料交接，任务联络有限但持续保有必要生活信息、安全关注和亲属联系，兄妹不是六年无人监管。

木向晚长期养家，记得兄妹各自的学费、看病和换住处，遇事习惯先找稳妥的去处再告诉他们。她怕姐姐救不回来，也怕一旦说清命牌与调查，兄妹会跟着离开自己能照看的生活。保护因而常变成抢先安排：月四联络恢复后，她已替兄妹问好康复期间的住处和学习安排，才发现木苏想留原校、苏木还要跑地方任务。木苏能自己同学校和医生约时间以后，她仍重复确认接送，把已经不用她办理的事项留在自己的日程里；有时兄妹只是晚回消息，她便另找联系人核问。她不只怕他们遇险，也不知道不再替他们安排以后，自己该在这个家里做什么。月七她倾向先救姐姐，对永久置换的退出条件问得太晚，与苏木发生分歧。终局她交还可公开信息，仍会照料，却要处理兄妹对旧隐瞒的怨意；他们没有立刻按她订好的安排生活。

周卫明有军方家庭背景，但不是因此自动进入军方编制。他早年正常接案，后来参加协调，只掌握实际接触的材料。最初信任制度保护，后来发现制度也可能以保护限制家人。他保存旧案与未经替换的交接记录，协调监护和资产受托，保护证据与公共见证，推动合法调查，不利用家庭关系无限越权。他不能凭郑崇职务推定顾衡知情，职业信誉不能替代原证；与小姨限于调查、照料和信任协作。

## 六、木苏：自主参与与未成年人保护同时成立

木苏继承昆仑体质，激活后擅长意识与节点共鸣，能提供活跃意识、异常载体和节点回应的局部反馈，与苏木的规则痕迹读取不同。她保留现实学校、同伴和求学安排，喜欢自己记训练进步，不爱哥哥替她向别人解释。有时她明明没想好下一步，也先顶回苏木的提醒，免得又被当作小孩。

城区事件后她接受受监督训练，不进入常规成人登录流程。月四主动同意有限共鸣，既想认出母亲，也想让哥哥看见自己已经能参与；准备时把最顺利的一次训练当作代表，过于乐观地估计了自己的耐力，完整数据仍由专业人员记录。月六双侧模型过载后，她停止共鸣并治疗，原先证明自己能做的兴奋消失，学校与同伴反而成为她想先保住的生活。月七她拒绝为追回救母进度再次共鸣，连以后靠接口证明有用的打算也放下。医生是否允许恢复不改变当期拒绝。研究改用成年测员、材料模拟和更小批次，月八至九她不承担关键接口或只有她能做的操作；家人继续让她知情，不以重新上岗换取亲近。

每项参与均须本人知情、正常监护、专业评估及可执行中止；替代载体不足，先补建或安全迁移已有负荷，复验后交接。共鸣只提供与原始记录和模型互证的局部反馈，不万能治疗、读取全部记忆或成为备用接口。

## 七、监护与资产持续安排

2034年即落实成年监护和照料，2035—2040年安排建立并持续稳定，涵盖生活、教育、医疗、紧急联系人、资产管理及亲属联络；2041年是既有安排中的正式交接。周卫明协调见证，不同时兼任全部监护、投资与调查职责。

2047年苏木成年可处分依法属于自己的部分，木苏仍有正常监护；哥哥成年不自动取得妹妹人格或财产支配权，母亲康复也不要求立即接管全部照料。约15亿为兄妹利益保全，不默认全归苏木，不另定分配比例；律师与受托人承担处置管理，涉及妹妹和共同资产须保护其权益并履行合规程序。可支持首批救援、安置和独立研究，长期维护由国家、理事会及公共研究承担，不是无限科研、赔偿或迁移资金池。
