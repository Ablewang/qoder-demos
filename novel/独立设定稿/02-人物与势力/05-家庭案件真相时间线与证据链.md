# 家庭案件真相时间线与证据链

> 独立发散设定方案，不覆盖原知识库。
> 本文独立保存家庭案件的完整因果链、责任链与2028—2047年时间表。前五节完整保留本套采用的案件设计，不用摘要替代；绑定机制、具体执行责任及证据组织属于独立发散补全，不假称原知识库已经具备。不写小说正文、对白场面或逐章细纲。

## 一、从研究到遇害

1. 苏正淮资助公开的能量环境研究，木向岚提供旧节点资料与异常样本。
2. 团队判断持续扩大回传会使蓝星结构逐渐同化，准备公开风险并要求限制试验规模。
3. 顾衡批准封存终点模型，要求控制研究人员和样本，接受守门人执行层的非法协助。
4. 郑崇作为当时的试验站安全负责人，掌握团队出入、家庭位置和样本登记。他同时是守门人执行层成员，把控制知情者的命令转化为夺取材料、阻断撤离和清理现场。
5. 苏正淮在这一行动中遇害。木向岚启动昆仑接应，被救走而非被杀死；苏木未亲见两具完整遗体。
6. 郑崇操纵现场与交接记录，将样本来源的消失解释为目标已处理。官方确认父亲死亡，母亲失踪，后续依据被污染材料形成推定死亡结论。
7. 顾衡掌握处置造成死亡的后续报告，仍然批准封存和延续工程，没有将犯罪移交正常调查，因此同时承担授权、隐瞒和继续利用的责任。

利用派在2034年已存在资源牟利与非法协作的前身网络，2035年以后才发展为稳定派系。不能用后来成型的组织年份否定早期执行者的活动。

## 二、从救走到被绑定

1. 木向岚返回昆仑后，为压住局部异常，自愿参加稳定节点研究。
2. 昆仑守望者中的守成派认为现成的人体接口最可靠，接受顾衡提供的现代调度设施与资源。
3. 随着回传扩大，母亲承担的负荷上升。解除程序、替代载体建设与对外联系逐渐受到限制。
4. 项目以保护节点和接口为名，将她维持为不可退出的稳定部件；早期自愿不能替代后续持续同意。
5. 小姨通过命牌知道姐姐存在存活可能，但命牌只能确认某种生命联系，不能提供位置、损伤状况或解除方法。
6. 小姨进入官方体系后取得部分节点档案，仍无权直接解除核心接口；昆仑钥匙代表家族身份，不等于网络维护权限。

昆仑不是统一加害者。有人救过母亲，有人接受了持续绑定，也有人反对把她永久工具化。家庭救援需要争取内部盟友，而不是把整个上古势力当作一个可以打败的敌人。

## 三、为什么苏木和神器没有被继续追杀

研究样本来自神器融体后一次微量析出，木向岚把它当作特殊材料保存，不意味着吊坠在童年长期外露。

郑崇等人误判它为特殊界晶，只掌握旧检测特征。案件后本体重新隐匿，样本被纳入封存项目，家庭相关人员又被不同机构接管，执行者错误确认材料来源已经消失。

因此，苏木不是仅凭不在家而逃过一个能够准确追踪神器的组织。漏网由错误技术判断、被修改的结案记录和项目保密共同形成；成年重新匹配则推翻了这一错误判断。

## 四、必须逐步形成的证据链

| 证据 | 能证明什么 | 不能单独证明什么 |
|---|---|---|
| 成年认证与旧样本的同源响应 | 封存连接不是静态残留，确实与家庭研究相关 | 不能证明回应者就是完好的母亲 |
| 试验站原始负荷记录 | 事故之前有人主动压缩安全间隔、提高回传 | 不能自动确认是谁下令 |
| 父亲公司保留的资助、运输与会议材料 | 父母团队准备公开结论，资料交接与官方口径不一致 | 不能独立代替现场加害证据 |
| 周卫明保全的旧案材料与未经替换的交接记录 | 郑崇参与现场控制，结案过程存在修改 | 不能单凭其职务推定顾衡知道全部后果 |
| 项目授权与事后封存报告 | 顾衡批准强制处置，事后知晓死亡并继续隐瞒 | 不能证明其迁移方案在技术上完全无效 |
| 昆仑节点原始绑定记录和母亲的有限自主回应 | 母亲仍存活，早期参与与后来被限制退出是两个阶段 | 不能证明立即拔除绑定就是安全救援 |

案情调查依靠相互独立的材料交叉印证，不靠对手自白、神器自动播放全部真相或最后突然出现一份万能档案。

## 六、责任链：决策、执行、封存与长期利用

前五节已经给出全部案件主干。以下按责任对象展开，避免把责任模糊成一个幕后势力，也避免以执行者落网替代决策者追责。

| 对象 | 具体行为与责任 | 不允许的推定或免责 |
|---|---|---|
| 顾衡：事前授权 | 批准封存完整终点模型，要求控制研究人员和样本，接受执行层非法协助 | 不能把批准强制控制写成完全不知情的普通学术争论 |
| 郑崇：现场执行 | 利用试验站安全负责人身份控制出入和登记，夺取材料、阻断撤离、清理现场；对苏正淮遇害负责 | 不能只因其职务便省略现场证据，也不能把实际加害改成无名组织背景 |
| 郑崇：污染记录 | 修改现场和交接记录，以目标已处理解释样本来源消失 | 修改的结案口径不能继续作为母亲真死或神器消失的可靠证明 |
| 顾衡：事后知情 | 掌握死亡后续报告，仍批准封存、延续工程，未将犯罪移交正常调查 | 未亲手杀人不免除授权、知情后隐瞒和继续利用责任 |
| 利用派前身及后来派系 | 提供非法执行协助、材料和资源牟利网络，后来继续与工程执行体系协作 | 2035年成型不抹去2034年前身活动；保护文明的远期目标不抵消本部犯罪 |
| 昆仑具体绑定参与者 | 接受持续绑定、封锁退出、限制替代载体与联系者，按各自行为承担责任 | 昆仑不是统一加害者；救援者、反对者和接受长期绑定者需区分 |
| 相关机构具体参与者 | 对批准、记录污染、隐瞒和执行中的具体行为分别调查 | 正规机构身份不能自动免责，也不能把所有国家、军方、理事会成员推定为同谋 |

父亲的死亡、母亲的失踪与推定死亡、后来不可退出的绑定，是相关但不同的事实链。证明父亲遇害不自动证明母亲被同一批人杀死；证明母亲曾自愿参与不自动证明她后来能够退出。

## 七、证据如何互证而不越界

### 1. 家庭研究与人为加速

公司资助、运输、会议材料证明团队的工作和公开意图；原始负荷记录证明事故前有人压缩安全间隔并提高回传。两类材料互证研究结论为何触及项目利益，但仍需要授权与执行记录明确下令者及现场行为。

归航计划可能具有真实的局部受控迁移能力。犯罪责任与工程技术评价分别成立：证明顾衡授权和隐瞒，不等于证明所有模型都假；证明模型局部有效，也不能取消其犯罪责任。

### 2. 现场控制与事后知情

周卫明保全的旧案材料和未经替换的交接记录，连接郑崇的现场控制与结案修改。项目授权证明顾衡批准强制处置；事后封存报告进一步证明他获知死亡后的选择。

不能单凭两人工作关系证明顾衡知道每一项现场细节，也不能因没有证据显示顾衡亲手杀人就取消已经证明的决策责任。责任由不同来源的记录逐段连接，不靠同一人的最后自白补齐。

### 3. 母亲存活与不自由

成年认证和旧样本同源响应只证明封存连接仍活跃且与家庭研究相关，不能证明活跃回应者就是完好的母亲。

昆仑原始绑定记录与母亲有限自主回应，才能共同确认她仍存活，并区分早期自愿与后来退出受限。命牌提供的是生命联系的可能，不具备定位、损伤评估或解除方法。

母亲的自主回应不是单纯供苏木解读的节点噪声。她必须能够确认现状、表达退出意愿，拒绝未经苏木同意的接口替换；回应受负荷与接触范围限制，不是全部旧案和工程的万能证词。

### 4. 真相确认与安全救援

证明绑定不自由，不能直接推导立即拔除就安全。救援还需要分散载体、两侧联合负荷模型、旧维护资格、实际调度窗口与监督资源协议。

先转移承载、维持必要回传、逐段解除，才能让退出不是把风险转给另一个人。母亲的同意不能省略，木苏也不能被安排成新的永久替代接口。

## 八、材料保全与调查程序

此处补足的是证据如何成立的设定约束，不新增一份能解决所有问题的档案。

- 每类材料保留来源、原始版本和交接关系，明确取得者实际接触了什么。
- 被污染的现场记录要与未替换材料比较，不能先假设所有官方记录都真，也不能先假设所有记录都假。
- 父亲公司的独立材料、试验站负荷、旧案交接、工程授权与昆仑绑定记录来自不同环节，不能全由神器读取同一个节点替代。
- 苏木的痕迹读取用于发现修改和连接方向，不能自动给出人员动机或司法结论。
- 沈遥提供独立同步记录和公开见证，梁知秋负责技术复核，周卫明和受托人参与合法保全与交接。
- 保护证人和相关家人的安全，技术原始记录与个人信息分开处理；共同证据既不能被苏木私藏，也不能毫无保护地公开。
- 案件材料由多方与司法程序保全，不因顾衡失去职务或郑崇被拘捕而终止完整责任调查。

## 九、时间线必须同时满足的补充口径

1. 2034年小姨16岁，她也是未成年人。她深度参与亲属照料，但需由正式成年监护和照料责任人保障日常事务，不能独自承担全部法定责任。
2. 2035—2040年监护、信托或受托资产安排建立并持续稳定；这不意味着2034年到安排稳定前儿童无人照料。
3. 2041年小姨离开时苏木约12岁、妹妹约10岁，已经正式交接照料；任务联络有限，不是六年无人监管或毫无关注。
4. 苏正淮个人控股约20亿，处置后为兄妹留下约15亿资产。资产为兄妹共同利益保全，不自动全归成年苏木，不承担全球治理财政。
5. 2047年木苏16岁，现实侧受监督训练、研究和救援协作，与常规成年归墟接入资格分开。她不提前常规登录，也保留本人同意和拒绝权。
6. 十三年指2034年到2047年的母亲承载与家庭缺席，获救不能使损伤和关系疏离同时消失。
7. 利用派2034年前身和2035年稳定成型必须并存，不倒写组织规模，也不因名称出现较晚取消犯罪。
8. 第一部混沌族不能追踪苏木。旧样本误判与局部认证不能给人类反派提供凡、极、主宰等宇宙身份的全知信息。

## 十、第一部案件交付与不可逆结果

苏正淮的死亡原因、执行责任与决策责任在本部查清，不复活父亲。郑崇的现场加害和记录修改得到确认并受到拘捕；顾衡被解除工程职务和调度权，其授权、事后知情、隐瞒及继续利用受到正式追责。

木向岚脱离绑定、恢复自由，仍需修复身体、意识耐力和十三年家庭关系。她不是获救后立即完好，也不是一直沉默直到被搬走。木向晚承认隐瞒与替人选择的后果，重建信任不自动完成。木苏取得自主参与未来道路的权利，并继续受到正常未成年人保护。

审判、康复和制度改革可以延续，真相本身不能被推到下一部。打击利用派加害链不等于所有派别目标消失；顾衡失败也不使连接风险从此消失。
