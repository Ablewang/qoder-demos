# 核心术语与硬边界

> 独立发散设定方案，不覆盖原知识库。本文件负责统一全套文档的术语与适用边界，不代替各专题的完整设定。

## 一、宇宙与能量术语

| 术语 | 本套方案含义 | 不得混用为 |
|---|---|---|
| 宇宙层级 | 第一层、第二层及以上的存在结构差异 | 国家实力、文明技术或修炼阶位 |
| 高等／中等／低等宇宙 | 第一层内部规模、储能与承载条件的分类 | 第一层、第二层、第三层 |
| 文明等级 | 文明利用资源、技术与能量的程度 | 个体血脉或宇宙层级 |
| 总能量 | 载体或世界拥有的能量总量 | 当前全部可用的能量 |
| 密度 | 局部能量集中程度 | 自动跨越层级的证明 |
| 精纯度 | 能量结构的稳定和可控制程度 | 人格善恶 |
| 可用比例 | 能参与当前循环的能量部分 | 封闭体系凭空增能 |
| 界晶 | 第一层内部能量交换的固态通道结构 | 太初晶碎片或独立跨层钥匙 |
| 太初晶 | 具有跨层背景与旧协议认证能力的独立遗物 | 普通界晶、器灵制造物或无限许愿器 |

完整说明见[宇宙能量与意识](01-世界规则/01-宇宙能量与意识.md)。

## 二、修炼与意识术语

| 术语 | 本套方案含义 | 硬边界 |
|---|---|---|
| 血脉 | 生命先天的能量通道形态与潜在条件 | 不直接等于当前体魄、国籍或全部人格 |
| 主宰血脉 | 需要适配能量和神器承载的跨层潜力 | 蓝星人物不能从普通成长异常知道其完整身份 |
| 神 | 感知、控制、吸收及连接稳定 | 神强不等于体容量无限 |
| 体 | 当前容量、承载强度和恢复条件 | 不只是先天天赋的被动结果 |
| 气 | 积累、精纯度及可释放力量 | 增加气不能省略承载训练 |
| 三重九阶 | 本套基础修炼的阶段结构 | 九阶不是整个低等宇宙的绝对顶点 |
| 意识 | 必须依附稳定载体的生命与人格状态 | 不等于所有算法输出，也不能无限脱离介质 |
| 投射体 | 归墟为外来者凝聚的临时物质载体 | 纯粹无载体的意识或无后果的游戏角色 |
| 原住民 | 归墟的真实居民 | 可重复消耗、可随意复活的NPC |

完整说明见[血脉修炼与成长边界](01-世界规则/04-血脉修炼与成长边界.md)和[归墟结构接入与死亡规则](01-世界规则/03-归墟结构接入与死亡规则.md)。

## 三、连接与危机术语

| 术语 | 本套方案含义 | 硬边界 |
|---|---|---|
| 同步程度 | 现实与归墟的空间、载体和连接状态耦合程度 | 不等于单纯修炼能量的多少 |
| 回传负荷 | 当前通道必须处理的交换量 | 目的善良也可能使它超限 |
| 节点余量 | 旧网络还能隔离、储存和疏导的异常量 | 不是永久恢复、不可耗尽的保护 |
| 同化 | 蓝星结构逐步转为归墟附属世界 | 不等于全部人立即死亡，也不等于无损搬家 |
| 失序体 | 过载生物、投射泄漏或污染意识占据载体形成的异常 | 不一定全部邪恶或全部可救 |
| 人体接口 | 用人的持续连接承担稳定负荷的结构 | 早期同意不能授权后来永久限制退出 |
| 归航计划 | 顾衡主导的提前受控同化与集中调度路线 | 技术无效的骗局或纯粹灭世方案 |
| 第三方案 | 限流、材料冗余、联合模型及有限自愿参与的分区重构 | 把更多人永久绑进网络，或一句口号解决全球问题 |
| 历史注销 | 清理旧连接索引和身份关联 | 按一下按钮立即杀死母亲 |
| 边缘维护子世界 | 蓝星接入片区的旧维护空间 | 中心大陆地底的巨型界晶小世界 |

完整说明见[同化机制与三种应对方案](01-世界规则/06-同化机制与三种应对方案.md)。

## 四、信息层级

| 信息 | 作者设定层 | 蓝星人物可知层 | 第一部应兑现的程度 |
|---|---|---|---|
| 家庭案件 | 完整事实与责任链 | 随取证逐步确认 | 必须查清，不推迟到宇宙篇 |
| 母亲的绑定 | 自愿参与转为限制退出的完整过程 | 中期原始认证与自主回应确认 | 必须解释并在终局解除 |
| 同化风险 | 规模、回传和节点条件共同作用 | 现代测量与旧模型交叉证明 | 必须说明原因及处理条件 |
| 苏木异常 | 主宰潜力、神器适配与本地权限 | 天赋异常、有限读取与维护认证 | 不正式揭开全部宇宙身份 |
| 器灵动机 | 善意与利用诸文明并存 | 能观察帮助、协议与解释差异 | 留两条远期入口，不取消蓝星收束 |
| 混沌族与第二层 | 远期背景与存在问题 | 蓝星人物没有完整证据 | 不把追猎或跨层战争变成第一部直接冲突 |

## 五、不得任意改变的十五条边界

1. 第一部是蓝星篇，不在尾部突然改为宇宙大战。
2. 父亲确实死亡，不能靠后续意识复制等同原本人复活。
3. 母亲存活但受损；解除绑定不等于立即恢复全部健康与关系。
4. 小姨长期隐瞒与真实照料同时存在，不能把儿童无人监管当作故事基础。
5. 木苏16岁，主要进行受监督的现实侧训练与研究，不跳过成人接入资格。
6. 苏木成长至六阶成熟、触及七阶条件，不成为整个宇宙最强。
7. 高阶盟友有真实能力，不能为了主角高光集体失去行动力。
8. 第一部的主角危险来自当地势力与连接副作用，混沌族仍不能定位他。
9. 三日限制只属于当期新人确认，不是全篇所有事件的时长。
10. 普通物品不能随意识带回，现实奖励另有具现来源与额度。
11. 危险状态不能无代价强退，原住民没有第二个现实身体。
12. 杀死失序体与解除同化机制分别处理。
13. 第三方案必须有冗余、限流、实证、调度窗口与可退出保证。
14. 终局放弃的是本地独占配额、调度与收益，不毁掉太初晶本体和双分身。
15. 后续新秘密不得取消本部已交付的真相、胜利和不可逆损失。

## 六、术语发生冲突时的处理

先判断是否描述不同尺度、不同时间或不同权利；确实互斥的说法不能同时保留为事实。

本套方案的保留、统一与新增清单见[已有设定的保留统一与新增](04-取舍与审查/01-已有设定的保留统一与新增.md)。未定项不应在其他文件里被悄悄写成已确定事实。
