# 矛盾与合理性审查结论

> 独立发散设定方案，不覆盖原知识库。记录可交付的审查依据、结论与设计处理，不提供逐步内部推演。

## 一、资料的主要问题不是缺少名词，而是版本和因果未收束

既有资料已经具有宇宙、血脉、神器、蓝星、归墟、上古遗产与家庭关系等丰富主干。

主要风险有三类：

- 同一事实在不同版本或同一文档内同时采用互斥说法。
- 机制名称已存在，但没有解释限制、成本与行动后果。
- 主线提出世界危机，却缺少从调查到实际解决的连续条件。

本套方案不是再添一层更大秘密，而是先让家庭案件、第一部范围和危机处置形成闭环。

## 二、必须选择口径的硬冲突

### 1. 父母命运

原资料同时存在明确死亡、二人被救走、母亲在昆仑、最新讨论重新未定等说法。它们不能全部作为作者事实。

处理：父亲真死，母亲存活后被绑定；苏木未亲见双尸。父亲案件、母亲救援和家庭创伤分别兑现，不用假死消除所有代价。

### 2. 年龄与监护

妹妹与哥哥两岁差，与某些小姨离开时妹妹只有五岁的表述不兼容。长时间无人监管又不符合现有财富、警察照料和正式社会背景。

处理：2034年约5岁与3岁，2041年约12岁与10岁，2047年18岁与16岁；小姨16、23、29岁。有正式监护和有限联络，冲突是知情与决定权。

### 3. 神器状态与分身

长期外戴、成年首次出体、分身在吊坠居住、吊坠只是通信渠道等说法未区分时间阶段。

处理：婴儿佩戴后融体，成年重新显现；封印期为带零散印象的种子，成年后形成独立意识。现实投影不触物，不能提供完整现场监控。

### 4. 封印与高层能量

成长停滞、远距离屏蔽、器灵恢复与主动认主原本被混用，造成同一封印两次解除、第一次高能量接触时间矛盾。

处理：四件事分开。幼儿解封后正常长大，特征仍受屏蔽；神器可被动储能，苏木成年才满足主动匹配。第一部没有混沌族追猎。

### 5. 地图与力量上限

第一部边缘局部舞台、中心地底小世界、宇宙最强、九阶可继续超越，原口径互相挤占。

处理：蓝星篇只到边缘维护子世界，苏木六阶成熟并触及七阶条件；九阶是基础大陆一般上限，中心资源后置，高阶盟友保留真实行动能力。

### 6. 古代网络与现代归墟

上古遗产不能在归墟建设之前连接同一个现代系统。

处理：古代使用旧能量网络与通用协议，归墟后来接入复用。罗布泊的预置保护与后续事故分层，吉萨选择知识读取口径。

完整选择清单见[保留统一与新增](01-已有设定的保留统一与新增.md)。

## 三、不应误判成矛盾的内容

| 并列表述 | 为什么可以同时成立 | 必须补充的界线 |
|---|---|---|
| 神农架表层福地、核心凶地 | 空间层次不同 | 深入核心的危险来源明确 |
| 归墟物品不能带回、通天塔奖励在现实出现 | 渠道不同 | 奖励须有来源、额度与登记 |
| 修炼有收益也有痛苦 | 使用规模、承载和阶段不同 | 不凭情节随意改变身体后果 |
| 能观察主角异常、不能知道主宰身份 | 信息层级不同 | 不把成长数据自动等同血脉识别 |
| 陆离公开承诺重生、隐瞒人格风险 | 宣传和真实认知不同 | 不能把隐瞒内容直接确认为宇宙终极真相 |
| 地理管辖、福地核心不认可来访者 | 权利层次不同 | 军事控制外围不等于拥有核心认证 |
| 母亲早期自愿、后来失去退出权 | 时间与持续同意不同 | 不能以一次同意合法化永久绑定 |
| 器灵善意与利用文明并存 | 动机可以复杂 | 帮助主角不能自动证明全部安排正当 |
| 不同神话描绘不同制度 | 文化与主体不同 | 不应强行把所有神话改成同一数值模板 |

## 四、机制合理性的关键审查

### 1. 能量不能因精炼而凭空增加

总量、密度、精纯度、可用比例和层级分开。反哺改善循环，不提供无限能源；主宰跨层有输入、耦合、承载与损耗。

界晶是同层通道，不独自完成第二层突破。普通地区缺少可直接修炼的高品质能量，不意味着常规物理能源归零。

### 2. 成长不能只有战力收益

苏木成长后能执行更大规模的维护，因而影响更多回传。第四高潮的负荷失算使家人受伤，这是局部机制造成的后果，不借混沌族突然发现主角制造威胁。

体容量、控制与训练是真实限制，神器不能把它们抹去。

### 3. 杀怪与治因必须分开

失序体是症状，生成原因是回传与同步失稳。清除污染仍需要维护，杀死顾衡也不能安全解除已经运行的旧绑定。

第三方案逐区转移承载，处理风险原因；终局不是以关闭一座塔恢复全世界。

### 4. 为什么不能立刻关塔

新增接入与已有绑定不同，局部重叠不会因断电自动消失。强断可能使意识损伤和节点反馈扩大。

应急停止新增使用可以合理，突然切断全部旧连接则需要证明后果。秦岳的保守方案有专业动机，不是愚蠢反派。

### 5. 为什么不是十三年前就能解决

当时缺少联合模型、经验证的分散载体和可用维护认证；集中人体接口既快又省，项目控制者也不愿投资能使接口退出的冗余。

现在取得的条件来自城区救援、档案、原住民撤离、失败数据、研究复核与南极窗口。主角不突然成为全球工程专家。

### 6. 为什么主角重要但不是唯一能做事的人

苏木提供旧认证与局部读取，研究者提供模型，原住民提供载体和路径，木苏与昆仑提供校验，高阶力量保护现实设施。

不可替代的权限与不可替代的其他贡献并存。不能把机构写成全知而不行动，也不能把强者写成等主角来救。

### 7. 退出权不能只有道德承诺

人员退出由材料冗余接替，冗余不足则限流停止新增。不能把母亲一个人的永久绑定改成更多人的轮流永久牺牲，再声称已经获得自由。

共同认证不要求苏木终身守在节点，也不复制太初晶的全部宇宙权限。

## 五、社会与调查合理性

- 个体天赋不由国籍决定；大国优势来自数量、训练、资源和组织。
- 南极为核心枢纽，普通参与者通过受控终端接入，不要求全民进入高能量危险区。
- 国家在归墟的执行受条约、成本与其他文明主体限制，不是完全无能力。
- 地下势力有灰色交易与非登记网络，但仍受现实登记、利益和执法约束。
- 十八年没有全面失控，源于节点缓冲和风险增长阶段，不是全世界无人发现异常。
- 调查依赖分散材料交叉印证；单一熟人、命牌或神器不能给出全部答案。
- 索引清理毁掉当前可追查入口，不被写成正常制度直接处决一个已知活人。
- 15亿资产能支持首批救援和独立研究，不能解决全球财政、国际协作与权限问题。

## 六、结构风险与本方案约束

| 结构风险 | 本方案采取的限制 |
|---|---|
| 七个高潮只是换场景重复升级 | 分别改变规则资格、救灾选择、真相与信任、能力代价、公开处境、执行窗口和长期权利 |
| 前期谜团无限延期 | 每阶段必须交付明确事实，第三高潮确认母亲本人存活和父亲执行责任 |
| 开篇有天赋但没有行动 | 最优通关与保线索冲突，三日确认有可验证目标 |
| 顾衡只是错误恶人 | 受控迁移真实有效，错误在风险隐瞒、永久接口和权力垄断 |
| 第三方案临时出现 | 六项必要条件分别来自前期实际成果 |
| 木苏只是人质、小姨只负责解释 | 保留自主训练、共同判断、信任债和母亲自己的退出意愿 |
| 终局牺牲被更大礼包抵消 | 不立即授予更大独占特权，不抹掉区域与身体损失 |
| 第一部胜利被宇宙篇取消 | 后续仅扩大问题，不推翻蓝星已交付事实 |

这些约束是对完整方案的检查标准，不是要求进一步写小说场景。
