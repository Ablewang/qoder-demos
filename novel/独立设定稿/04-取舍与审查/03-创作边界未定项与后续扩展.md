# 创作边界、未定项与后续扩展

> 独立发散设定方案，不覆盖原知识库。本套文档以完整设定和主要剧情结构为交付，不继续扩展为小说正文。

## 一、当前完整到什么程度

以下项目已按一套口径组织，不能被归为等待后续讨论的核心空白：

- 系列命题、蓝星篇名称、舞台与力量边界。
- 宇宙尺度、能量指标、意识载体、血脉和基础修炼。
- 归墟建设、地图、接入、物质收益、死亡与退出。
- 蓝星社会、三方路线、机构职责和灰色网络。
- 同化形成条件、十八年缓冲、失序体来源与关塔风险。
- 父亲真死、母亲存活被绑、小姨监护和长期隐瞒。
- 郑崇现场责任、顾衡授权与事后隐瞒责任，以及证据能证明的范围。
- 主角、家人、分身、同期伙伴、研究者、军方和原住民的独立目标。
- 开篇的异常、三日期限、默认成功反转及保全成果。
- 五幕主线、七个大型高潮、高潮之间的必要推进。
- 主角行为弧光、第三方案的前期验证和实际执行条件。
- 结局的家庭、蓝星、归墟、责任收束及不可逆损失。

完整性不要求提前确定全部宇宙地图和每一章事件。只要主线依赖的事实、能力、资源、代价与结果都存在，远期未定项就不应阻止第一部成立。

## 二、明确不写的内容

1. 不写小说正文、人物对白、试读章节或详细场面。
2. 不写逐章细纲、每章字数、全部动作顺序或战斗招式。
3. 不以一串新术语代替关键因果。
4. 不默认新增恋爱主线、隐藏顶级养父、全知警察或突然复活。
5. 不默认同步、覆盖、移动或重命名知识库内任何资料。
6. 不把本套独立方案说成所有原文件早已具备的最终正典。

## 三、远期未定项及边界

| 未定项 | 当前无需确定的原因 | 以后确定时不可突破的约束 |
|---|---|---|
| 全部非核心国家归属 | 第一部只依赖三方核心与实际共管关系 | 国籍不直接决定个体天赋，地理权与核心权分开 |
| 九阶正式名称与层内称谓 | 一至九阶已经能稳定描述成长和任务能力 | 三重结构、承载限制、基础大陆一般上限不能被名字改变 |
| 生父生母全部细节 | 蓝星篇不以血缘真相解决家庭案件 | 生父送走婴儿不等于知道全部主宰价值；养育关系不能被血缘否定 |
| 十二祭司名单与完整派系史 | 本部只需明确利用派前身与执行责任 | 守门人的远期保护目标不能取消杀人与强制处置的责任 |
| 中心大陆与巨型界晶地图 | 本部只进入边缘维护空间 | 两个小世界不得混同，局部授权不等于全局管理权 |
| 第二层宇宙完整结构 | 蓝星角色没有完整证据，本部不真正跨层战争 | 高低等同层、跨层有输入和承载，不能凭空无限增能 |
| 陆离重生理论的终极真相 | 是远期立场与认知问题，不应提前判定唯一答案 | 人格延续风险真实，不能用重生抹掉第一部所有死亡 |
| 所有福凶地的独立故事 | 蓝星篇只需要与家庭和维护有关的节点 | 保留文明差异、载体与具体危险原因，不统称邪恶副本 |
| 亚特兰蒂斯等待条件 | 可以成为后期主体，不参与解决本部全部问题 | 不以苏木在蓝星长大自动证明具有本土遗传血脉 |

未定项不是内容遗漏的借口。凡是七个高潮必须使用的条件，不能被放进未定表里等到终局才临时补充。

## 四、后续扩展方向

### 1. 其他接入文明

蓝星不是唯一接入文明。其他文明可能采用不同的缓冲、迁移与权利安排，使苏木面对不适合复制蓝星答案的问题。

扩展重点应是不同主体的生存诉求、制度和资源选择，不是把蓝星七个高潮换名称再演一遍。

### 2. 器灵与归墟的伦理债

器灵对苏木有真实帮助，也利用文明精炼能量。后续可以追问其建设与迁移的代价、原住民的资格以及神器权限的真实来源。

不能把帮助者写成全善或忽然全恶，不能用布局必然正确取消主角的选择意义。

### 3. 混沌族与跨层

更远期再处理正统派等待、陆离改变存在形式、生父的选择及主宰潜力。

这一层应提高问题难度，而不是把顾衡换成陆离、把蓝星换成宇宙后重复同一个接口交易。

### 4. 上古文明的多样性

可以分别展开公共维护、祭司资格、人格继承、集体意识、污染禁忌与记忆保存。

共同能量规则不意味着每种文明只有同一种宗教、同一种社会组织或同一种修炼最优解。

## 五、参考资料的可信度边界

本套设计基于本地资料审读，未对全部神话、古籍、科学说法与市场数据进行外部逐条核验。

- “典籍原文”目录包含选段、译编、摘要和现代解释，不能全部当作经核实的完整原文。
- 遗址地磁、抗菌、飞行失灵、建造精度、神秘失踪等断言，可以作为架空素材，不能直接当作现实科学证据。
- 神话之间的差异可能来自文化、版本与翻译，不自动构成世界设定矛盾。
- 市场研究中的2025年资料不能代表2026年实时市场结论。
- 游戏调研与小说调研应区分来源，不能因为名称相近而把两者机制混在一起。
- 与小说无关的随手资料不应自动成为设定约束。

现实事实若以后要在正文或对外说明中当作准确知识使用，需要另行核验；当前不靠这些断言证明架空机制正确。

## 六、独立目录后续维护规则

本目录各文件构成同一套方案。改变一个事实时，应检查它在人物、规则、主线和结局中的依赖，而不是只改一处名词。

建议检查顺序：

1. 核心术语与硬边界。
2. 家庭时间线和证据链。
3. 同化机制与第三方案条件。
4. 七个高潮的成果和下一步行动依据。
5. 人物独立目标与可拒绝、退出的权利。
6. 结局已兑现事实和不可逆代价。
7. 本套文档之间的导航链接与新旧口径。

这些维护仅针对独立设定稿，不自动授权修改原知识库。若需要将方案采纳回既有资料，应另行明确范围。

## 七、交付验收

- 可以从总纲进入全部世界、人物、主线与审查文档。
- 七个高潮不是七条概念，每个有前提、对象、阻碍、反转、选择、结果和损失。
- 主角弧光有可观察的行为变化，而非只有终点口号。
- 开篇有异常、期限、主动选择和第一次实质回答。
- 核心答案在第一部交付，远期入口不会取消本部胜利。
- 材料是独立设定而非小说正文，存放于知识库同级目录。
