# 守门人传承与非首部组织

## 一、传承起源与分层

守门人源于外来采矿组织撤离时留下的驻守者及本土协作人员。上古任务是保管节点、监测界晶信号、接待返航者，报酬包括残缺技术及提升地位的承诺。洪灾切断通信后，各地保管群体分散成仪式传统，再于近代重新结成秘密组织。“伊吉吉后裔”是其中一条身份传承，不把现实祭司团、骑士团或共济组织全体判定为本小说同谋。

外圈约数千人，经营捐助、研究人脉与圣物仪式，多数不知道界晶实质；外圈身份不是无限政治权限。中圈约数百人，负责近距探测、样本收购、运输和封存，掌握有限能流技术；行动须有具体授权，个人不能以保护文明为名无限处置证人。内圈为十二席祭司议会，掌握分段档案与旧接口资格，仍不完整理解太初晶自然来历、器灵布局或苏木身世。

## 二、十二席的完整权限

十二席是职责和分段授权，不要求每席恰有某一种纯血。传承标记通过体内兼容通道与外置遗物保存，DNA和梦境最多帮助索引匹配，不编码一本可以脱离载体自动读取的完整宇宙书。

| 席位 | 可批准和执行的职责 | 禁止单独决定的事项 |
|---|---|---|
| 守门席 | 召集议会、代表已通过决议、紧急暂停危险仪式 | 不独享全部十二段授权，不可永久废席 |
| 典藏席 | 保存原始档案、登记版本与访问日志 | 不得销毁犯罪材料或独占历史结论 |
| 觅晶席 | 分配近距勘测、核验样本来源 | 不能凭异常认定主宰身份或无限追踪 |
| 镇讯席 | 维护抑制信号的封装与屏蔽设施 | 不得把所有外部通信列为敌意 |
| 返航席 | 保管旧信标与返航协议 | 不得自行启动邀请或承诺他族效忠 |
| 运储席 | 安排运输、仓储、实体交接与保险 | 不绕过当地边境和归墟物质额度 |
| 医载席 | 检验承载安全、治疗受损成员 | 不强制实验、不以净化抹除人格 |
| 遗产席 | 协调六遗产外围接触与保管合同 | 不替核心主体授予读取资格 |
| 传习席 | 分段授课、训练及兼容资格认证 | 不把学员永久绑定为私产 |
| 外交席 | 与节点研究团和地方机构订约 | 不自行出让居民主权及公共设施 |
| 算储席 | 预算、缴费、用途审计与赔付准备金 | 不以账面收益冒充实际能量 |
| 察责席 | 调查越权、受理申诉、申请暂停涉事执行者 | 不代替司法判罪，不封禁独立证人 |

常规事项七席同意；启动信标、危险遗产联合读取或大额征用须九席同意，并取得被影响主体授权。医载、察责任一席可短期暂停高危项目，后续由独立复核决定续停，避免少数席无限否决。十二段授权拼合只是旧记录读取条件，不是更改器灵基础协议的权限，更不保证自动发出“宇宙独立宣言”。

## 三、三种政治立场与跨派传承

灭灯派主张压制界晶信号，防止旧采掠者再次定位蓝星，资源来自镇讯、运储等岗位及保管家族。其家系把世代沉默当作保护后人的功绩，也因此舍不得承认自己守护的旧敌已经解体。定位风险仍真实存在，保护诉求却曾被用于夺取、杀人和封锁，须按行为追责。

莫洛克派为返航信标充能，希望换回技术和政治提升。它掌握仪式供能及旧协议译本，将祖辈万年的守候、捐献和未获报偿的劳动解释为忠诚积累；许多供献者期待的不是一份新合同，而是终于被旧主人记得。信标只能发送记录，派系并不能确认接收方还会承认自己，更不能把上古组织、当代接入文明、混沌族和器灵统称一批神。

信标实际收件端是载体层高等宇宙中的烁环返航站，原烁环采掠联合体的航线登记设施。联合体已经解体，返航站由独立遗址清算团接管，只核验遗产债权和回收危险设备，不再兑现旧雇佣的技术提升与政治地位承诺。守门人译本遗漏了组织存续及授权有效的条件。清算团既无蓝星主权，也不将守门人自动收为属民；世代效忠不会换来他们等候的身份。

一次短讯使返航站确认旧节点仍在运行，精确定位仍须后续多段测距，往返有延迟和供能成本。站方实际回送署名清算通知，要求停止自动供能；设备回收须先取得本地主体授权并独立核验。返航席中的莫洛克支持者先藏下原函，只散发有关核债的节译，宣称旧赏赐将以补偿归来，试图续收供献。灭灯派夺得副本后强调拒绝雇佣的部分，却压住可核债条款，以证明多年封锁仍有必要；利用派则抢先接触清算渠道，想把旧效忠改作只有自己能代理的回收生意。各派争夺原函和译本的控制权，迟迟不愿向供献者交出完整解释。

典藏、察责及跨派托特传承者保存的副本与协议缺页互相校核，有限核验确认函件来源，也揭露了藏函与删译。有人退出仪式、停止捐助，有人坚持祖辈忠诚不可能毫无意义，转而支持私下续供；莫洛克派因而失去部分信徒和供能来源，却没有整派接受清算。灭灯家系也遭到质问：既然回来的只是清算者，为何仍要求后人把人生用在永久封锁上。

旧自动邀请最终靠本地授权下的信标隔离、自动提取回路停用和供献者撤回供能才停止，不是收到合法通知便自行停转。完整协议与回函开放，在隔离带宽下开展有限债权核验；可核实的遗产债务不等于恢复旧待遇。清算团只在当地授权及独立核验后回收设备，未授权部分继续封存，坐标泄漏风险仍须防护。藏函、非法强征与其他侵权分别调查。失去信徒的家系继续争执祖辈守候的意义，有限偿付也买不回那些被耗掉的人生。

利用派是灭灯内部的务实利用支系：2034年已有资源牟利与非法协作前身，2035年后稳定成型。它将归墟视为新的资源与调度渠道，争取现实岗位、合同和信息优先；即使渗透理事会，也只能影响现实终端、研究和调度，不能更改接入基础协议。

托特传承跨越三种立场，是知识线而非第四政治派。携带者可支持信标、反对信标或要求退出组织；技术相同不意味着价值观相同。赫尔墨斯保留互相校验以防独占，不是预先编程所有后人互斗，更没有把地方刑案设计为主角成长的必要仪式。

## 四、独立组织及交换关系

“外国节点研究联合团”由吉萨、百慕大等外围研究站和各国学术团队签订项目章程。它提供现代计量、冷却设备与证据保全，收益是经过授权的技术数据、训练和风险预警；拥有复核、退出及发表非敏感结果的权利，不得擅自占领遗产核心、公开人格隐私或以资助控制继承者。

“遗产继承者议约”由昆仑维护者、太阳祭司后人、亚特兰蒂斯授权代表和其他地方保管群组成。它提供兼容经验、旧日志与合法接触，换取维护基金、安置及文化资料保管权。成员可拒绝读取，必须区分祖名、遗物所有权与活人格权；议约不能替所有遗产签字，也不能因传承历史豁免当代侵权。

“子界自治网”由穗庭迁民局、母界子界联席及归墟根籍代表互设联络站。它交换迁民名额、载体维护和锁能审计，收益是回流上限、互助储备和不受孕界家族转卖的公民身份。网络尊重地方制度，只有经同意的运输与数据权，无强制征兵、统一统治或全面关断母界的权力。

三组织可与守门人交换知识，却均设独立预算、授权和证据副本，不是同一个幕后机构。私人组织影响不等于国家机器整体同谋；对地方杀人、非法拘禁、证据污染和持续工具化按具体行为追责。保护宇宙的目的、取得传承及后来的合作，都不能取消已经成立的刑事责任。
