# 混沌族社会九脉与存续危机

## 一、族群位置与九脉

混沌族居于第一载体层高等母宇宙。载体层、织律层、源序层各分低中高，合成九格；母界之高与蓝星所在宇宙之低只是同层承载差，不能据此声称已跨层。混沌九脉是族内通道结构分类，不等于九格宇宙，也不替代神、体、气三元及三重九阶的实际修炼。

| 血脉 | 能力与社会位置 | 成本和边界 |
|---|---|---|
| 凡脉 | 感知宇宙能流，承担农业、制造、地方记录与日常维护，是人口主体 | 无法独立稳定高密度流；劳动权益不低于孕界者 |
| 灵脉 | 持续吸收并调节能流，可任医师、输能匠和基层护界者 | 需公共稳流设施，不能开辟子宇宙 |
| 玄脉 | 通道首次形成孕界闭环，可孕育第一层低等子宇宙 | 一生只有一次正式孕育机会，失败也消耗该机会；维护需长期配额 |
| 地脉 | 闭环承载与反馈增强，可孕育第一层中等子宇宙，是迁民与地方治理中坚 | 不能在既有宇宙之外补生第二个；广域管理不等于读心 |
| 天脉 | 可孕育第一层高等子宇宙，具多节点协调能力 | 锁能最大，审议最严；高等子宇宙仍非第二层 |
| 圣脉 | 宇宙维持与个人通道形成稳定联动，能修补既有子宇宙的大尺度失衡 | 只升级或维护自己既有宇宙，不增加孕育次数；修补消耗储备 |
| 皇脉 | 能重排既有宇宙内部供能分区，支撑多族群长期共居 | 不能抹掉居民既有权利，改造须经当地共同批准 |
| 帝脉 | 能稳定既有宇宙的多重界面，应对边界收缩与大规模迁民 | 不能凭空扩张封闭体系总量；界面迁移会永久改变部分生态 |
| 极脉 | 第一层常规血脉上限，能协调母子节点并推进既有宇宙极限升级 | 仍受载体、输入和损耗限制，不能直接取得织律层规则 |

孕育权从玄脉开启，玄低、地中、天高对应初生承载档位。升至圣皇帝极只能沿原有宇宙改造，未孕育者也仍只有一次机会。遗传不保证高脉复现，低脉并非劣等人格；九脉同享法律人格，现实资源分配却长期偏向高脉家族。主宰是罕见的跨层耦合结构，不是排在极脉后的第十常规阶。它还须太初晶稳定、合格载体及真实上层输入；有候选者不保证文明获救。

## 二、家族与公共能量治理

族人以亲缘家族组织照料、训练和宇宙维护，但孕界者是初始建设责任人，不是宇宙居民的主人。子宇宙形成社会后，其居民享有定居、迁移、拒绝实验和独立代表权，不能随孕界者死亡、继承或婚姻转手。家族可继承维护合同与债务，不能继承居民人格。

家族以自己孕成的界景争名：保留祖辈河季、建造高密度庭城、维持可见星带，是不同家系舍不得削去的生活。一次孕育失败会耗尽终身机会，有人因此嫉妒成功的手足，不肯在对方子界做被照料的亲属；有人把未完成的新城押给下一代，要求子女以唯一一次孕育延续宗族声望。婚姻联结维护合同与私人储备，年轻伴侣想共同生活，却会被两家争取孕育归属的要求拆开。家系想留住继承者，既有子界居民则可能只想保住自己的河季和自治。

凡脉粮能匠也会眷恋家系中曾照料自己的长辈，明知配额偏斜仍替旧庭说话；地脉家族为了不再依附母界配给，支持贸易子界并与宗族分家。天脉建设者可能宁愿延后个人晋升完成新城，也可能在失去建设窗口后投向越界同盟。暂停孕育使年轻家系的愿望落空，强迁又毁掉已经形成的地方生活，支持哪一派常由这些依恋、羞耻和利益共同决定。

公共机构“衡储院”登记母界可用储备、子界锁能及反哺时滞；“界籍议庭”审理孕育许可、维护欠债和迁民争议。家族缴付维持税，保留合法私人储备；紧急征用须说明用途、上限和补偿，低脉生活配额不可先于高脉私人训练被削减。子界代表拥有查账权，但涉个人载体和防御节点的资料分级公开。

母子宇宙合计能量有限。精炼改善结构、纯度与可用比例，不增加总量；新生宇宙将大量能量锁入膨胀、物质与生命，回流通常迟于母界支出。老化母界又需更多能量维持结构，遂出现繁荣与短期存续相冲突的危机。压缩训练和减少浪费能争取时间，不能彻底消除这项结构账。

## 三、实际派系

正统“续衡议盟”控制议庭与大部分公共档案，维护渐进节流、旧宇宙修补及主宰研究。旧界修补曾保住人口与运输口，居民记得获救的亲人，愿意继续出工；掌权宗族却借这份感激把祖庭维护列为长期优先，封存失败记录，将弱脉生活配额挪去保全高脉旧庭。危机中先撤外围、先保核心城的主张既保护公共设施，也保护宗族居所和继承合同。受庇护的弱脉家系因而与自己的子界代表争吵，有人宁愿失去自治席位也不愿指责曾救过家人的旧盟。

陆离领导“越界同盟”，核心为皇脉以上研究者与护界武装，外围包含被债务挤压的地方家族。它开放被正统封存的试验设施、减免参与家族的维护欠债，以集中军需守住收缩区运输口；失去正统职位的研究者在这里得到作品署名和门生，负债宗族得到延续家业的希望。这些人将陆离的个人成功当作自己的翻身，排斥批评者，也争抢候选筛查和遗物适配的席次。强征与封锁使另一些家系失去亲人和船位，同盟的恩惠与伤害落在不同人身上。

断链死亡被证实后，部分支持者撤离，另一些主动接受原人死亡，押注保有记忆、力量与宗族名义的“继承者”。他们愿让自己的下一代认继承者为家长，却也要求不愿断链的住民一起投入，好保住试验规模。还有人只是相信只有陆离能守住运输口，继续供给军需。知晓代价并未消除强制项目的支持，反而使同盟内部对“究竟要保谁”分裂得更深。

“减生保全会”由医师、低脉工匠和部分天脉孕界者组成，要求暂停新增孕育、降低私人军备并优先维护已有人口。它争的是维生材料、粮能与工匠工时；减生指自愿延后孕育，不是处死已存在生命。冻结新界也会使建设工坊失去订单、年轻家系错过建设窗口，保全会须承受这些人的反对，不能宣称节流无人受损。

“子界自治联席”以居民而非孕界家族为席位基础，要求回流上限、迁民保障与实验否决权。部分子界要保本地冬储和贸易口，宁愿不参加苏木的跨层项目；另一些要迁出已失稳故乡，愿承担较高回流换船位。它与正统共同反对强制坍缩，又与保全会争论冻结孕育是否封死安置新居的可能。四方围绕母界库存、旧子界回流及民用维生三组接口交换供给，迁民航道决定交换能否兑现；停战必须同时维持这些依赖，不能以统一宣言替代。

## 四、减半杀戮遗迹的结论

陆离发现的先辈遗迹记录了一次以杀死半数族人节能的灾难。尸体能量不会立即变成可用储备，死者维持的节点崩坏反而增加修复支出；子宇宙锁能也不随孕界者死亡自动解除。人口、知识和协作网络损失使反哺进一步下降，短期储备回升未阻止后续收缩。

遗迹只保存损失账、证言与失效结论，不作为执行指南。已消散人格、灭绝生态与断裂传承不可由后来的丰裕补回。陆离拒绝重演该路线，却从中错误地确信唯有整体转生才值得押注。远期能争得的是暂停新锁能、冻结部分旧界升级及撤离外围住区换来的存续窗口；保住现在的人也会使一批建设愿望无法完成，主宰候选者不能把这项取舍变成免费获救。
