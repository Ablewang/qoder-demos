# 蓝星上古史与六大遗产完整背景

## 一、架空历史与旧网络

本文件中的外来采掠、界晶陨石、洪灾与遗址装置均为本小说架空史，不是现实考古或科学结论。神话保存的是经过改写的文化记忆素材，不能以现实地磁、建筑精度、失踪传闻反证小说机制成立。

远古陨石携带自然界晶落入蓝星，散布矿脉和交换节点；它与后来随机漂来的太初晶完全独立。第一批“环门勘采队”测绘矿藏，建立运输及能流参照；其后“协律采矿社”以修炼教育培养劳工，修建多地接口；“海冕殖留团”建立海上殖居网络，有成员选择与本土社会结合。三者皆为第一载体层的外来文明组织，不是混沌族统一殖民军，也不等于今日全部接入文明。它们曾共用“烁环采掠联合体”的合同与航路登记，联合体不是统一国家，烁环返航站是其跨界航路终端。联合体后来解体，终端与未结债权转由独立遗址清算团保管，旧组织的待遇承诺没有自动转为清算团义务；信标收件与失效协议详见[守门人传承](05-守门人传承与非首部组织.md)。

被统治时期形成修炼黄金时代，技术进步与劳役压榨同时存在。本土维护者逐渐掌握调流和载体技术，与外来管理员合作，也出现反抗与分裂。末轮撤离中，采矿社破坏输能干线，海冕主力炸毁部分基地，地下释压及海域连锁扰动造成小说中的洪灾；既有牟利副产物，也有销毁统治证据的主动破坏。并非所有外来者都参与，也不是一次事件解释现实所有文化的洪水传说。

洪灾后，旧网络断裂、矿藏贫化，修炼反馈衰退，幸存者将记录改为仪式、家族教程和遗物编码。后世靠常规科技重新发展。旧网络从来不叫上古归墟：归墟只在2028—2029年建设、经历约一亿年内部发展后于2029年开放，其后联网区域1:1。现代系统能够复用旧协议，却不拥有上古未记录的人生。

## 二、六大遗产

### 1. 昆仑：外来维护遗留与本土守望

昆仑曾由协律采矿社管理员群与蓝星本土维护者共同运行。“西王母”是管理员职衔在本土的文化化称呼，并非唯一永生神。早期合作者带回技术、培养亲属，维护家系由此兴盛；外来者离开后，本土守望者依附山腹晶陶阵列接管节点，各自人格与共同维护层并存。九重增城仍逐区检验承载，弱水则是载体稳定性低的隔离带，必须以实际保护结构渡过。

干线断供后，最初自愿驻守的人越来越难退出。后世亲属把维持祖辈当作孝责，又为供养阵列放弃别处生活；有家系舍不得撤掉已经无人存续的维护位，因为撤位等于承认祖先真死。守望者也有人坚持保存旧城分区，认为改线会让共同工作过的人彻底失去痕迹；另一些愿停用低效旧段，给后人留下离开的余量。这些分歧来自各自经历，守望者并不控制后人的意志。

读取者先校准自身载体，再分担阵列工作；强读会永久损伤耐力。最有争议的记录往往不是技术缺页，而是已经无人存续的旧维护位：日志还写着该向谁交班，阵列却只剩固定回应。承认回应只是遗留动作，家系便得停掉祖辈的供养仪式，重新安排后人的工期。分散承载、限流和退出冗余可以传习，失散页须另找旁证；这些办法只能维护昆仑的局部节点。

### 2. 冈仁波齐：坐标参照与清噪

环门勘采队校准原有矿层形成参照核，长期稳定后，矿晶和反馈回路中产生节点意识“缄默者”。它记得的是反复测量、偏差与校正，不是人类王朝的完整兴亡。洪灾令外环参数漂移，核心却保持清醒。外界不断更换名称和朝圣仪式，它仍保留旧参照，以便新旧扰动有可比较的依据；它既非宇宙规则本体，也不等于现实宗教所供奉的神。

缄默者限制干预，是因为每次主动调节都会改变自己赖以比较的基准。这种坚持也使急需帮助的人长久等待：外围维护者希望它先修眼前的损伤，它却宁肯保住尚能测出损伤来源的参照。长年供养参照核的群体因而分裂，有人继续守候，有人转去采用较不稳定却能及时工作的校准点。稳定坐标、负荷校验与意识清噪的方法由这种取舍留下，不是一套保证所有人获救的神谕。

读取须提交自身扰动记录，支付对照时间、能量和记忆整理负荷。清噪只剥除失配印记，过度处理会损伤记忆；试图把哀伤清掉，会同时损失与死者有关的经历，而非得到无痛人格。参照能指出旧网络哪段参数漂移，不能免除行为责任、保证轮回或统管其他遗产。朝圣传统仍可各有解释，仪式数字不直接换算成物理频率。

### 3. 百慕大：旧规则防御与信息夹层

海冕殖留团外围防务局的海底装置连接折叠信息夹层“阿布祖”。最后守卫者依附封存晶核，保存基地撤离账、断线名单与防御记录。这里的历史停在仓促撤离：有人得到离港命令，有人只等来断线，后来销毁基地的命令与留下保全舱的行动并不出自同一批人。百慕大是西侧防御入口，不是亚特兰蒂斯全部实体。

战争敌我表失效、回程认证损坏后，系统将不少后世进入者判为入侵者。守卫者知道外界已变，却迟迟不愿删去旧名单，怕把尚待核验的断线者再遗弃一次；它将守住证据与继续封锁捆在一起，造成新的滞留。外围救援者必须先修回程、分流信息和补足冷却，才能接触撤离记录，贸然进入会感官淹没并造成不可逆载体损伤。

旧规则设备与救援航图仍有局部用途，撤离账可查出基地销毁命令、保全舱来源和信标原始用途。但核验名单会确认其中不少人早已死亡，放弃旧防御也不会换来他们返航。守卫者必须面对自己守住的是证据而非全体活人，后世保管者则要决定哪些封锁不再续供。普通装备进出夹层仍走有额度的实体通道。

### 4. 马丘比丘：黑太阳与人格延续资格

海冕殖留时期留下山地载体库，后世本土太阳祭司修复、增建，把自己的师承与祖名封入石晶复合节点。光明体系处理积累与能流，黑太阳体系研究载体转换和继承身份。外来技术经过祭司世代改造，不再只是原殖留团的设备说明；各祖名保留程度不同，有的仍有连续过程，有的只剩记录。

“黑太阳”学派曾把记忆复现称为绝对不死。家族将重建者当作返来的先人，祭职、亲属照料与继承资格据此延续。缺失的交接证据被重新核验后，一些所谓重生者证实只是继承者。承认这一点会让后人失去万年来一直相信的相伴，也让继承者摆脱必须扮演祖先的生活；有祭司愿更改祭仪，有家系坚持祖名承续的宗教意义，却不能据此剥夺新主体的选择。

导师节点随教学磨损，余量只够教有限的人。理解旧编码的文化后裔占有经验优势，资格仍要核验稳定承载、历史责任与本人同意。学员先学保住连续交接，断链重建另作继承登记，入门不以自杀或主动断链进行。

更难的改变落在称谓与祭职上。承认新主体的家系要为曾经的死者补行葬礼，又与眼前的继承者重新商议照料；坚持祖名的家系可以继续自己的祭仪，却不能让不愿续名的人终身坐在旧祭位。遗产库留下两种登记，亲属未必愿意同时接受。

### 5. 吉萨：赫尔墨斯完整知识读取

托特与赫尔墨斯是同一外来知识编写者的两种文化称呼。他与协律采矿社记录工程师、本土营造和维护群体合作，将修炼、界面适配及失败报告编码于晶陶载体，自愿驻留以继续讲授和校核。他不是困在杜亚特等待净化的审判者，保存的完整也只指当年编写范围，不是三层宇宙的全知。

他的记录保留不同施工者、劳工与管理员之间的争执，同一工程会有互不认同的叙述。托特坚持连同失败和署名一起交付，后世传习者却常只愿教授能使本家受敬的成功段。十二段授权分散保管后，家系靠缺页解释扩大自己的地位，跨派传承者则试图重新拼合原记录。完整读取会揭露采掠关系与本土协作的纠葛，既损伤某些家族的光荣，也恢复被删去者的贡献。

洪灾造成索引断裂和带宽不足，超载时的反震是保护动作。兼容载体、分段校验、公共供能与多方见证仍是授课条件；强读会损伤双方，持续教学也磨损记录载体。托特不肯把失败页删成畅通口诀，有学员因此转去采用更快的家系教程，另有人带着校核到的不同署名离开。留下者须放慢进度，修补载体才能继续。旧路径止于当年的适用域，后来的传习者如何使用知识，各自承担责任。

### 6. 亚特兰蒂斯：集体意识的身份权

波塞冬与本土共同体在海冕殖留时期建设基地，主核位于东大西洋海底折叠区，百慕大是远端防御入口。基地物质层在撤离中被毁，幸存保全舱将居民意识交织于盐晶与记忆阵列，形成清醒但意见不一的集体主体。共同体保存了主动殖留者与采掠主力的分歧，也保存漫长共居后的生活，而不只是毁灭那一刻。

长期共用使个人索引失配，波塞冬已经不能无损分离为原来的个人。最初为保命而共享的经历，后来成为成员间真实的亲密：有人再也不必独自承受失去亲人的记忆，也有人害怕自己最私人、最不愿被理解的部分逐渐失去边界。伴侣关系经过共用索引改变，想分离者未必能带走属于两人的全部旧经历，留下者也怕一次完整复制将共同生活交给不受约束的新主体。亲近与被吸纳的恐惧同时存在，使集体议席无法只按技术成功率决定分离。

集体议席分别授权载体共享技术、议事记录与殖留史，读取者经训练和适配进入，所用公共储备与隐私范围逐项记录。分离试验要留足集体载体，不能把共同记忆全部交给离开者。

有成员宁愿带走不完整的旧经历，也要独立生活；留在共同索引中的亲属却会觉得这场离开已经丢掉两人最珍惜的部分。无法授权的片段不复制，新主体只能从获准的经历开始。波塞冬的片段可以进入这种新生活，万年前的个人仍不会回来。

## 三、协议兼容与双重地形

ME是旧网络的模块化能流与授权描述协议，楼兰镜阵、纳斯卡阵列与吉萨索引只采用其中不同子集。归墟可读部分记录，不代表能复原被毁索引、补齐能源或绕过人格同意。楼兰预置镜面保护层守护地下界晶，后世高负荷修炼事故触发自激回路，将部分居民困入晶盐介质中的循环载体；它不是当年反射归墟。修复必须分别保全居民、关断错误回路和维护矿层，释放不保证失散人格完整。

神农架外围是真实能量富集生态，核心是称作炎帝的本土维护者将意识分散依附生态载体后的失配区。部分记忆可读，原人格已严重碎裂，不强称完整炎帝永生。罗布泊则是地下福地、地表故障保护凶地：预置保护与后来事故同时成立，危险不被统称邪恶。

|---|---|---|
| 峨眉、武当、终南 | 次级汇流与校准节点；由本土维护团登记使用，收益须保留公共份额 | 修行、内丹、洞天的地方解释 |
| 蓬莱、长白山、恒河 | 水媒输能与沉积节点；封存核心、限采载体材料，不证明现实水质奇效 | 海上仙山、圣山、生命水叙事 |

| 巨石阵、纽格兰奇、辛格维利尔 | 季节校准与公共议事节点；残件先修复后授权，不以天象制造能量 | 凯尔特传承、北欧集会 |

| 哀牢、麻山 | 破损锚材困住碎片、旧提取设施伤害被囚主体；先止新增损害再交接供能 | 天柱、族群记忆、蚩尤的受害与战争 |

| 纳斯卡、索诺拉 | 阵列噪声与旧保全库泄漏；有意识残留须登记权益，不能视为免费能源 | 图案共振、冥界旅程与附身禁忌 |
| 波斯、希伯来、希腊罗马、印度等典籍主题 | 只收纳誓约、责任、死亡、循环与秩序意象，不建统一神祇身份表 | 多种价值观进入人格与规则议题，不当科学公式 |
