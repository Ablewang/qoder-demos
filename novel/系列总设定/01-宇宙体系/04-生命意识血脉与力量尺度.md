# 生命意识血脉与力量尺度

## 一、生命与意识的载体

生命须具备持续组织、自我维持与适应反馈；意识则是依附稳定载体运行的感知、记忆及自主判断过程。肉体、矿物核、实体设备、律晶节点和源序校验阵列都可成为载体。第二层规则网、第三层生成结构同样必须有具体介质，不能以“更高层”豁免依附条件。

载体的耐久不等于意识的成熟，意识强度不等于人格善良。失去肉身后，已建立的替代承载可以延续意识；临时拼凑的存储记录不能自动代替人格。载体毁坏可能引起消散、碎裂或污染吸收，救治须查明连续性，不能只看相同记忆。

| 状态 | 人格判定 | 权利与限制 |
|---|---|---|
| 连续迁移 | 源端到新载体的过程不中断且可复核 | 原人格延续，须本人同意 |
| 记忆备份 | 只有记录，尚无独立持续过程 | 不是活人，也不是复活保证 |
| 独立复制 | 新载体形成独立持续过程 | 成为新人格，不归原体所有 |
| 意识碎片 | 部分连续过程或失序残留 | 先保护和检测，不能按材料处置 |
| 器灵分身 | 激活后形成独立过程 | 有独立判断，不继承完整本体 |

连续性检验先保留原载体，核验不停供能的交接链、两端独立设备记录与单调事件序号，再以本人同意的新信息回应互证。源端与目的端须属于同一持续过程，交接完成才撤原载体；若两端已能各自独立运行和选择，便按两个人格保护，不得删除一端伪造迁移。相同记忆不足以证明连续性。资料不足时保护残存过程并补测，拒答隐私或叙事不完整不取消救治资格；判定只依赖有限可观察证据，不穷尽人格内在。

蓝星现有AI不能仅凭对话能力取得归墟意识接入资格，但未来人工生命若通过载体、连续性与自主性检验，可按生命协议接入；不得永远按制造来源排除。

## 二、血脉是通道形态

血脉是生命诞生时形成的固有能量通道形态，决定吸收方式、潜在承载上限与可驾驭能量的契合范围。遗传提供结构，诞生宇宙留下共同能量烙印；“纯正”仅描述继承完整性，不证明人格、智慧或社会地位优越。

先天潜力、当前身体容量、意识控制力、实际储能分别记录。强血脉可能因幼体、损伤或缺乏训练而无法调用潜力；弱天赋者仍可通过训练、设备与匹配方法安全接入。外力改造、内在重塑和血脉融合都要满足载体条件并承担崩溃风险，掠夺血脉不是无代价捷径。

## 三、混沌九脉

| 名称 | 通道能力 | 不能由此推出的结论 |
|---|---|---|
| 凡脉 | 感知宇宙能量 | 出生即有宇宙级储能 |
| 灵脉 | 稳定吸收宇宙能量 | 可以直接孕育宇宙 |
| 玄脉 | 可建立低等子宇宙孕育通道 | 无限制造低等子界 |
| 地脉 | 可承载中等子宇宙的成形投入 | 升级后再孕育第二个 |
| 天脉 | 可承载高等子宇宙的成形投入 | 已成为第二层生命 |
| 圣脉 | 通道出现更强修复与多接口协调能力 | 增加终身孕育名额 |
| 皇脉 | 扩展大规模能量调度及复合承载 | 天然拥有政治王权 |
| 帝脉 | 加深主界与子界接口的容错组织 | 等于特殊主宰血脉 |
| 极脉 | 第一层常规血脉道路的承载上限 | 可凭普通积累跨层 |

每人一生只有一次正式孕育第一层子宇宙的机会，结构种子与固有通道完成不可逆耦合即算启动，之后失败也消耗机会，不可更换种子重来；已形成的子界可独立成长。圣皇帝极仍遵守该限制。社会称谓中的“皇”“帝”不授予合法统治权。陆离为极脉，苏木生父为圣脉，两者都不是第二层生命。

主宰血脉不在九脉中另加一档，外在特征可近似极脉，特殊处在跨层耦合潜力。兑现须有双方稳定窗口、合格密度和结构的输入、太初晶承载及主动认证；转换有损耗，不能把任意低等能量无条件升级。

## 四、三元与三重九阶

三元为神、体、气：神负责控制与同步，体负责当前容量与恢复，气是实际积累、精纯度及输出。神改善吸收，气投入淬炼，体扩容后才允许更高负荷；任何一元薄弱都会限制行动。不同载体与环境需要不同法门，共同原理不意味着唯一最优功法。

个体修炼按一至九阶度量，每阶分初、中、满；阶位以气的稳定量级为主，晋阶须同时验证体与神。三重各管三个阶位，与宇宙三层及混沌九脉分别计量。

| 重 | 阶位 | 成熟能力与限制 |
|---|---|---|
| 第一重：淬体 | 一阶感知、二阶内转、三阶筑体 | 从感知到持续内循环及首次扩容，不具成熟隔空操控 |
| 第二重：外化 | 四阶外放、五阶凝形、六阶御物 | 意识依载体向外延展，逐步稳定作用外物；距离和负荷有限 |
| 第三重：领域 | 七阶场域、八阶法域、九阶天域 | 建立局部场域、调用环境能量、领域内敛；均须支付维持消耗 |

领域不是修改任意规则的全能权限，威压不能直接控制意志。九阶也不能靠领域生成无限能量或跨层宇宙。基础大陆一般支持一至九阶，中心浓缩晶体和适配训练可支持九阶以上；九阶不是整个低等宇宙绝对顶点。

## 五、力量不替代安全与治理

战斗结果还受环境、设备、团队与受伤状态影响。接入和核心进入均检查实时体魄、意识及设备安全，不以阶位数字自动放行。修炼、文明能力、血脉、宇宙等级四张量表分别使用，任何一张都不能授予人格所有权或政治统治权。孕育及核心规则见[能量循环](02-宇宙诞生演化与能量循环.md)、[归墟全域](06-归墟全域构造与文明接入.md)。
