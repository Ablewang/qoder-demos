# 界晶太初晶与器灵完整来历

## 一、两种晶体不能混用

界晶是第一层交换节点凝成的固态通道结构，功能是稳定同层流动、聚集输入和降低耗散。界晶不是燃料的无限来源，也不能独自把第一层升为第二层。浓缩晶体是能量经界晶处理后沉积的可消耗产物，不是界晶本体。蓝星远古陨石携来的界晶，与太初晶漂流到达属于不同事件。

太初晶是自然跨层遗物：织律层与源序层稳定窗口中的长期规则沉积，形成可自组织维持、保存跨层耦合结构的晶格。它先于器灵存在，既非器灵制造物，也非界晶或母晶碎片；切割会损伤耦合结构，不能作为普通通道材料复制。

窗口及输入条件齐备时，晶格获取有限跨层能量，不依赖器灵清醒；主动调度、修复与大规模建设则受器灵状态限制。库存有上限，过载损伤晶格，窗口关闭便中断补给。

## 二、器灵先于认主的来历

器灵原是第二层织律层规则网的维护意识，依附律晶及材料节点运行，负责故障隔离、通道修复与载体搬迁，并不掌握人格所有权。一场协议级联灾害毁坏其维护网络；它先在灾区遇到已存在的太初晶，确认晶格可作避难载体，随后依附遗物，经灾害中的稳定短窗口进入第一层。此次跨层消耗储能并损伤意识。

遗物携带器灵在第一层流转后，才于混沌族地方历1080纪元，被当时的宇宙之主先祖在探险中发现。先祖只观察到辅助修炼与战斗增益，未识别内部维护意识及跨层结构。后世出现更强的常规辅助器，太初晶逐渐被遗忘在族中宝库；发现纪元不是器灵诞生纪元。

## 三、从宝库到成年认证

| 时段 | 遗物与器灵状态 | 必须区分的事实 |
|---|---|---|
| 政变前 | 生父从遗迹石碑取得只言片语，知道遗物有待触发的成长能力 | 不知道婴儿主宰血脉的完整价值 |
| 婴儿送离 | 生父从族中宝库盗取太初晶，为婴儿佩戴并以秘法融合 | 器灵出现微弱匹配反应，不等于主动认主完成 |
| 逃离主界 | 生父送走婴儿所在小星体；器灵维持保护，寻找子界入口 | 从第一层高等到低等是同层跨界，不是再降一层 |
| 长漂流 | 到达低等宇宙后漂流约100亿年，方向无法稳定控制 | 婴儿生物成长停滞，晶格被动补给用于维生和修复 |
| 蓝星沉寂 | 到达蓝星后沉寂20多亿年，器灵缓慢恢复 | 不是器灵安排了养父母的宇宙身份 |
| 2028—2029 | 器灵调用长期库存建设归墟，进行隔离加速并结束加速 | 婴儿尚未完成成年接入，建设不依赖先认主 |
| 2029 | 解除生物成长停滞，将婴儿置于人类可发现处，随后被收养 | 正常成长恢复，远距离血脉特征屏蔽继续 |
| 2047成年认证 | 合格输入、成年载体与血脉耦合共同完成主动认证 | 缺的是匹配及权限，不是全宇宙首次出现第二层能量 |
| 认证次日 | 本体重新显现为黑紫晶体吊坠，双分身激活 | 不是整个童年持续外戴，也不使屏蔽必然失效 |

主界纪元、长漂流年、蓝星沉寂年分别按相应地方历记录，未联网前不可直接折算成共同公历。长寿保护依靠隔离维生、有限储能及被动补给，不使外部时钟停止或倒流。养父母是偶然发现婴儿的蓝星人，不附加神族、宇宙代理或预定宿命身份。

## 四、恢复与认主独立

被动恢复改善器灵可调用库存与意识稳定度；认主另须苏木当前体魄、意识、耦合结构及主动协议通过验证。受限第二层输入早已用于晶格维持，成年认证改变的是匹配与权限。

漂流停滞控制生物成长，蓝星期屏蔽隐藏远距离能量特征，两者不同。成年认证只解锁匹配的本地权限，不自动撤销全部屏蔽。屏蔽有耗能和负荷上限，不承诺精确计算一切未来风险。微量析出样本可以保留同源特征，但不等于可自由取出的本体，更不能据此识别完整族属。

## 五、器灵、分身与权限

器灵可建设、搬运、威慑、交流及维护能量设施，每项都受库存、窗口和载体限制；不能直接控制人格意志、自动复活死人或保证社会选择。组织诸文明精炼能量确有真实收益，也包含为苏木准备成长条件的利用关系，善意不免除伦理责任。

央央与墨墨在封印期只是寄存种子，保留零散生活印象而非连续录像。激活后形成独立意识，没有完整宇宙记忆，不读心、不远程监控。现实显现是宿主可感知的非实体投影；意识实际依附晶体，投影不能搬物、治疗或操作设备。

放弃个人独占授权，只转移相应配额、优先调度及长期收益，不毁太初晶、不抹除分身、不取消基础增益与未来潜力，也不能立即补发更大的同类独占作为抵消。核心认证另见[归墟全域](06-归墟全域构造与文明接入.md)。
