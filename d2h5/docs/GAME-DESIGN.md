## 1. 项目定位与版本边界

### 1.1 我们要还原什么

- **设定**：职业、技能树、底材、词缀、符文、宝石、任务、地图和怪物的原版含义。
- **规则**：等级经验、属性成长、技能门槛、命中/格挡、抗性、装备限制、镶嵌顺序、合成条件、任务奖励。
- **玩法**：探索地图、选技能和配装、打怪、拾取鉴定、升级加点、完成任务、进入更高难度、反复收集装备。
- **界面**：等距场景、红蓝球、腰带、格子背包、装备纸娃娃、三系技能树、任务日志、地图和 NPC 服务；相似组织方式，而非复制原版素材。

不是只把职业名字和装备列表贴进一个通用动作游戏，也不能用同一种范围攻击代替所有技能。

### 1.2 本项目采用的基线

| 项目 | 约定 |
|---|---|
| 规则版本 | LoD 1.14d 扩展模式 |
| 平台 | H5 浏览器，桌面鼠标键盘与触屏 |
| 游戏模式 | 离线单人，当前掉落按 players1 |
| 最大等级 | 99 |
| 难度目标 | 普通、噩梦、地狱 |
| 存档 | 当前浏览器 IndexedDB，多角色独立存档；自动导入旧 localStorage 存档，无云同步 |
| 画面 | 锁定斜视角 three.js、程序化骨骼角色/怪物、第一幕局部连续地表、原创地面/物品与石雕/皮革 UI；不是原版完整动画 |
| 当前交付范围 | 第一幕可玩纵切，第二幕部分地图可探索，但完整通关链未完成 |

不包含 D2R 2.4+ 技能平衡、新符文之语、恐怖地带、破免符、共享仓库或现代雇佣兵改动；不采用 PlugY 或非资料片 Classic 规则。明确的局部改编为当前 10×8 背包、便利商店及 20.4 的 D2R 风格赌博交互／Edge 单项离线覆盖；其他离线与天梯/服务器专用内容分别判断，不能默认全部开放。

### 1.3 状态词的含义

- **原版目标**：最终需要复刻的规则，不保证首版已经执行。
- **已实现**：当前代码存在可达的执行路径；若有数值/碰撞限制，另行注明。
- **近似**：可操作，但公式阶段、随机过程、动画或行为未达到原版等价。
- **仅数据**：目录或参数存在，尚无完整运行行为。
- **未实现**：不能通过正常流程使用；不提供免费跳关或无条件奖励来伪装完成。
- **待验证**：研究来源有分歧或涉及原版硬编码，须对照合法原版客户端。

## 2. 世界背景与五幕结构

背景摘要用于理解玩法，不是对原版对白和剧情影片的逐句复制。人类世界庇护之地受到恶魔侵扰；冒险者追踪黑暗流浪者，逐步面对憎恨、恐惧和毁灭的势力。城镇提供补给与任务，野外和地下城承担战斗、探索和掉落。

| 幕 | 中心城镇 | 场景主题 | 原版主要推进 | 终幕首领 |
|---|---|---|---|---|
| 第一幕 | 罗格营地 | 草原、洞穴、墓地、修道院 | 清理营地周边、救凯恩、穿过修道院 | 安达利尔 |
| 第二幕 | 鲁高因 | 沙漠、古墓、王宫、神秘避难所 | 收集并合成赫拉迪克法杖，识别真墓 | 都瑞尔 |
| 第三幕 | 库拉斯特海港 | 丛林、废墟、神殿、囚牢 | 收集克林姆遗物，击破强制宝珠 | 墨菲斯托 |
| 第四幕 | 群魔堡垒 | 地狱荒原、熔炉、混沌避难所 | 衣卒尔、熔炉、五封印 | 迪亚波罗 |

本版保留五幕的目录与目标，但没有完整重演这些剧情。画面中的“庇护之地”“在余烬之中，重拾你的命运。”是项目命名与原创界面文案，不是新添加的数值规则。

## 3. 核心玩法循环

```text
城镇准备
  → 购买药水/卷轴、整理背包、鉴定维修、选择技能
  → 出城探索、寻找入口和传送点
  → 与怪物战斗、控制距离与资源
  → 拾取装备/金币、升级并获得自由点
  → 评估底材/属性/套装/镶嵌/符文之语，调整配装
  → 完成任务目标并回 NPC 交付
  → 解锁后续区域/幕/难度
  → 更高等级与装备目标，再次探索和战斗
```

核心决策不是“装备评分越高越好”：武器基础类型、孔数、需求属性、抗性、施法/攻击断点、技能加成、腰带容量和背包空间都影响选择。白色或灰色底材可能比一件魔法装备更适合符文之语；MF 不会提高符文掉率。

原版后期还包括高等级区域、Boss/符文/底材专项收集、配装和不同职业构筑。当前只建立这些系统的基础与部分目录，不宣称后期玩法已完整实现。

## 4. 快速开始

### 4.1 启动

在项目目录运行：

```sh
npm install
npm run dev -- --port 5173
```

打开 [本地游戏](http://127.0.0.1:5173)。检验命令为 `npm test` 和 `npm run build`。当前是本地项目，不需要注册云端账户或数据库，也未公开部署。

### 4.2 推荐第一轮体验

1. 观看约 7 秒的原创开场动画（可点“跳过动画”；减弱动态效果设置会直接显示开始按钮），点击“开始游戏”进入游戏人物列表，再点“新建角色”，选**法师**，输入 1–24 字符名字，点击“开启旅程”。
2. 开局在罗格营地：40 生命、35 法力，未分配属性点/技能点均为 0；初始法杖授予 1 级火弹。
3. 点击阿卡拉，走近并与她交谈会免费回满当前生命和法力，不必再点“治疗”；商店和任务对话照常打开。了解任务后沿道路步行进入鲜血荒地；点击“鲜血荒地”路标只会寻路，不会直接转场。
4. WASD 或方向键移动，鼠标瞄准怪物，单击右键施放一次火弹，按住连续施放；留意蓝球和距离。法力自然恢复，但并非瞬间回满。
5. 击杀后查看经验、地面装备与金币，点击拾取或靠近后按 E。Shift+1–4 使用对应腰带列；Q/F 快取当前可取用的生命/法力药水。
6. 寻找邪恶洞窟入口，清除**所有**怪物；沉沦魔被萨满复活后仍需要重新击杀。
7. 回营地找阿卡拉领取 +1 技能点和本难度一次洗点额度。
8. 达到累计 500 经验升到 2 级，获得 5 属性点、1 技能点；打开 C/T 面板分配。
9. 缺补给时使用回城卷轴并点击传送门，再与商人交谈。
10. 点击保存并等待“已保存”；刷新后点击“开始游戏”，在左侧纵向人物列表选中角色，再点右侧人物下方的“进入”。游戏中按 Esc，点“保存并返回角色菜单”；成功写入当前角色并更新列表后才返回，可切换或新建角色。保存失败会留在暂停菜单提示重试，不丢弃当前进度。

**新建角色不会覆盖已有角色，允许同名角色。** 每个角色使用独立 ID，装备、仓库、金币、技能和任务进度互不共享。角色选择页铺满浏览器视口，不再限制为居中 980px 或固定比例高度；左侧列表显示名字、等级、职业和难度，右侧显示选中角色的原创立绘与信息，底部为“进入／删除”，“新建角色”在左栏底部。桌面和触屏均保留左右分栏，长名单只在左栏独立纵向滚动，选中角色后保持列表位置，操作按钮持续可见。低高度横屏将右栏人物与文字并排，避免长名字挤掉立绘；这是页面布局适配，不会请求浏览器全屏权限。

删除需先确认，取消不写存档；只删除选中的 ID，同名角色不受影响。删除与既有保存队列串行，删除活动角色后清除活动 ID，防止本页离开时重新保存。删除失败保留人物并提示重试。旧版迁移角色删除后只留下不含人物数据的内部删除标记，保留的 localStorage 备份不会再次导入，旧标签页也不能覆盖该标记。没有修改 IndexedDB v1 schema；暂未提供导入/导出 UI、云备份、跨浏览器同步或普通角色多窗口冲突管理。

开场采用原创写实哥特石门、火盆、兜帽旅人与远山背景，配合 7 秒镜头推进、火光、余烬和字幕动画；不是视频或原版过场，不使用原版素材与音轨。动画结束不会直接进入角色列表，仍需要点击“开始游戏”。

## 5. 操作与界面

### 5.1 桌面操作

| 操作 | 当前效果 |
|---|---|
| WASD / 方向键 | 按屏幕方向连续移动，松开停止；斜向速度归一化，可边移动边瞄准 |
| 左键地面 | 野外单击向鼠标方向攻击一次，按住连续攻击；营地内点击寻路移动 |
| 左键敌人 | 单击用左键绑定技能攻击一次，按住连续攻击；近战可自动靠近，方向输入优先 |
| 左键 NPC、设施、地牢入口 | 自动靠近后交互；地牢入口执行真实转场 |
| 左键地表跨界路标 | 只寻路，沿连通道路自然步行跨界，不瞬移 |
| 左键地面掉落 | 自动靠近并拾取；明确点击已显示的物品名称优先于附近怪物轮廓，放不下则保留在地面 |
| 右键 | 单击施放右键绑定的已获得、已支持技能一次；按住连续施放，仍受冷却和法力限制 |
| 1–8 | 切换已在技能详情分配的右键技能；仅当前会话有效，不解锁未获得技能 |
| Shift+1–4 | 使用腰带对应列的药水；点击腰带瓶也可使用 |
| Q / F | 使用当前可取用的生命/法力药水；无对应药水时尝试紫药，不跨过列首 |
| E | 交互或拾取三格内最近的目标，超过范围须先靠近 |
| I / C / T / J | 背包 / 角色 / 技能树 / 任务 |
| L 或顶部“图鉴” | 打开只读装备库，分类/搜索/翻页并查看原始定义 |
| X（物理按键） | 切换两套手部装备；面板打开时也有效，中文输入法下无需切换英文；输入框、暂停、死亡和物品拖动时不触发 |
| R | 切换行走/奔跑 |
| Tab | 切换探索地图显示 |
| 按住 Alt | 显示掉落名称 |
| H | 打开当前操作指南 |
| 营地仓库 | 靠近并点击仓库设施，不提供远程仓库快捷键 |
| Escape | 有面板时先关闭面板；无面板时暂停/继续 |
| 保存 | 写入当前浏览器存档 |
| 回城按钮 | 消耗卷轴并开启传送门；不是直接瞬移回城 |

城镇禁止攻击与施法攻击，桌面显式按下右键会提示前往野外。右键不能绕过未获得或未实现技能的限制；失去装备授予的技能时会说明当前未获得，并提示学习或切回提供技能的武器组。输入角色名时，不触发游戏快捷键。

### 5.2 触屏操作

- 轻触设施或掉落可自动靠近后交互/拾取；营地可点地面移动，野外用摇杆移动。
- 左下摇杆按屏幕方向连续移动；松开停止，可与战斗按钮多指同时操作。
- 轻点“攻击”“施法”尝试释放一次，按住连续释放，自动瞄准九格内视线未被墙挡住的最近活怪，松开停止；不让隔墙敌人占住瞄准。这是 H5 输入适配，不是原版锁定系统。
- “攻击”“施法”显示当前绑定技能名；“交互”“拾取”显示最近设施或掉落名称，无目标时给出提示；超过范围须先靠近。
- 点击腰带喝药，点击底部按钮开面板。窄屏面板内容可纵向滚动，背包格区独立横向滚动，保留当前 10×8 布局与格子点击尺寸，不把十列压小或折成其他列数。

### 5.3 HUD 与面板

- 上方短栏：当前区域与目标；角色摘要只显示 `Lv.等级 · 难度`，名字、职业与金币放在该摘要的 `title` 提示中，不占用常驻长栏。保存、图鉴、指南与暂停另列为工具入口。
- 底栏：桌面高 112 px、手机高 114 px；左红球与右蓝球显示当前/最大生命、法力，中部保留耐力、经验、技能选择、腰带及面板入口。
- 腰带四列：每列只显示下一瓶可用药水和剩余瓶数，不展开全部行；实际容量仍为 4/8/12/16 瓶，点击或 Shift+1–4 使用对应列。
- 左右技能槽：显示绑定技能，点击进入技能树设置相应鼠标键技能；点击技能卡只查看详情，已获得且支持的主动技能可点“绑定左键/右键”，成功后面板自动关闭。失去装备授予或绑定技能不受支持时，右键槽标红并显示“（不可用）”，仍可点击重新选择；触屏施法按钮标红显示“不可用 · 技能名”并保持禁用。法力不足仍由实际施法检查提示，不冒充未获得技能。1–8 只切换预先分配的右键技能，不直接施放。底部另有角色、背包、技能、任务及行走/奔跑、回城、地图入口。
- 人物头顶：上红下蓝两条细条分别显示当前/最大生命、法力比例，随人物平滑位置移动，受伤、施法、喝药和装备上限变化实时更新；暂停时保留、死亡时隐藏，不拦截场景鼠标或触屏操作。底部血蓝球与数值仍保留。
- 敌人栏：选中怪物的名字、等级、生命条与标签；场景叠层另为近处普通怪显示小生命条。
- 掉落叠层：物品品质色条与稀有品质的细光提示；探索地图以箭头区分地表跨界路标，以方框标识真实入口，视觉提示不改变掉落或入口条件。
- 地图提示：进入游戏、步行跨区或真实转场到不同区域时，画面上方中央浮现红色地图名，约 3.2 秒淡入、停留、上飘淡出；按动画结束隐藏，避免首次地形加载提前耗掉显示时间。同区移动、普通消息与打开面板不重复触发，不拦截鼠标/触屏操作；减弱动态效果时改为静态红字后隐藏。
- 消息日志：只展示最新 3 条，8 秒没有新消息便隐藏；这是 HUD 展示收拢，不删除引擎中保留的消息历史。
- 面板：统一标题/关闭区（header）、分类导航（nav，按面板提供）、内容区（body）；人物列表仍为左侧纵向名单、右侧选中人物与进入/删除。
- 背包：装备槽、当前 10×8 格、金币、详情和操作；手机格区独立横滚，保留格子点击尺寸。选择物品只更新详情与选中状态，不重建整个格区或重置其滚动位置。
- 技能树：三个分页、等级门槛、前置线、硬点/有效等级、可执行/未实现标识；仍只有 11 个职业技能可执行。
- 任务：按幕、难度查看状态，目录奖励不等于已经领取；传送点保留五幕页签，激活、幕解锁与难度门槛不因面板返工放宽。

**开面板不会自动暂停模拟。** 野外看装备时敌人仍可能攻击；面板打开时 Q/F、Shift+1–4 与点击腰带仍可用，但移动和持续攻击会释放。建议回城整理，或关闭面板再按 Escape 暂停。真正暂停时不推进战斗，也禁止移动、攻击、拾取、喝药、开门和旅行输入。

暂停菜单提供“保存并返回角色菜单”，并说明保存到本机、再次进入从营地出发且怪物刷新。点击后保持暂停，显示“正在保存，请稍候…”，等待已有保存队列与此次 IndexedDB 写入/角色列表更新完成后才返回；期间禁用菜单按钮和重复操作。失败则保留当前角色进度，留在暂停菜单显示错误并允许重试；“保存旅程”只保存，不退出。

## 7. 经验、升级与加点

- 初始 1 级、0 经验、0 自由属性点、0 自由技能点；不是开局赠送技能点。
- 每提升一级获得 **5 属性点、1 技能点**；升级补满生命、法力和耐力。
- 进入 2 级需累计 500 经验，进入 3 级需累计 1,500；99 级需累计 3,520,485,254。
- 经验条显示累计经验与下一等级阈值；完整 1–99 阈值见规则目录。
- 杀怪经验还受人物/怪物等级差及高等级 `ExpRatio/1024` 影响，不能把怪物面板经验直接等同实际获得量。
- 极大等级差的系数使用原始整数分数，例如 `/256`；25 级前后，高级怪经验处理也不同。详细分段见职业及战斗研究。

原版完整三难度任务还会提供额外技能/属性点、生命与抗性。99 级仅升级可获得 490 属性点、98 技能点；原版全部相关任务完成后可达 505 属性点、110 技能点，并有永久生命 +60、四抗 +30。**首版不赠送这些未完成任务的奖励**；当前只有邪恶洞窟技能点奖励链执行。

## 8. 技能树、硬点与软点

### 8.1 学习条件

七职业各 30 技能、3 技能树，共 210 技能。首点门槛主要为 1、6、12、18、24、30 级，直接前置从原始表读取。

投入硬点必须：属于本职业、有剩余技能点、达到门槛、所有直接前置至少 1 硬点；硬点上限 20，且满足：

`硬点 ≤ min(20, 人物等级−技能首点门槛+1)`

例如 30 级技能在 30 级最多 1 硬点，到 49 级才可投入 20 硬点。装备 +技能不能替代前置的硬点。

### 8.2 硬点、软点与授予

- **硬点**：人物投入的技能点，通常是协同来源。
- **软点**：装备 +全部技能/+本职业技能/+技能树/+火焰技能/+某技能等增加的有效等级。
- 本职业单技能属性可以授予零硬点技能，但不能给其他职业授予该技能；oskill 是独立属性，目前未实现。
- +全部技能、职业、技能树及火焰技能只提高已有硬点或本职业单技能授予的技能，不能独立解锁。技能树仅作用于指定职业／页；火焰技能按原始 EType=fire 生效，不限法师，也包括暖气。
- 护符必须已鉴定、达到需求等级且在背包中，仓库／方块内不计入。技能树超大型护符的需求等级由原始前缀给定为 42。
- 软点可以让有效等级超过 20，但不提高硬点上限。
- 初始法杖的 +1 火弹是授予，不会把人物硬点写成 1。
- 备用手部装备不为当前技能提供加成；破损/未鉴定物品的当前处理也有限制。

### 8.3 协同与预览

通常协同只读硬点 `.blvl`，不是所有软点。伤害分段对应技能等级 2–8、9–16、17–22、23–28、29+，再应用 HitShift、协同与支配等阶段。

当前未实现技能仍可在界面中以“学习规则数据（不可施放）”投入硬点。这能用于前置和已经接入公式的协同，但该技能本身不能绑定施放。**不确定效果时不要把珍贵点数投入未实现技能。** 当前支配火焰等有部分数值计算；暖气已按有效等级接入自然回蓝。不能按名称推断其他被动都已生效。

零级技能也可能显示 1 级预览；预览不是已学会。某些复杂技能计算依赖未实现函数，有限/零数值不等于原版最终效果。

### 8.4 洗点

完成邪恶洞窟并向阿卡拉领取奖励后，每个难度可洗点一次。需在城镇与阿卡拉交谈后使用“任务奖励洗点”。返还已分配属性和硬技能点，重置到职业初始四属性并保留已有自由点，清空硬技能学习，消耗该难度额度。

高级洗点精华/赦免徽章配方未实现；降低属性后装备重新检查/自动处理等完整原版行为仍需补齐，不应拿洗点当作已验证的需求绕过方式。

## 10. 战斗、命中、格挡与抗性

### 10.1 命中与防御

普通需要命中检查的攻击：

`命中率 = clamp(floor(200×AR/(AR+防御)×攻击者等级/(双方等级和)), 5, 95)%`

同等级且 AR=防御时为 50%。防御降低被打中的概率，**不直接减掉伤害**。玩家法术投射物当前按碰撞命中，不统一套武器 AR 检查。

基础 AR：`5×(敏捷−7)+职业命中常数`，随后加适用平加 AR 与百分比。职业常数见规则目录。

奔跑中的玩家防守时，命中检查返回 100%，不是把防御置零再保留 95% 上限；行走保留正常命中规则。当前奔跑状态判断和耐力耗尽组合仍属于需要校准的实现细节。

### 10.2 格挡

持盾时：

`格挡率 = clamp(floor(B×(敏捷−15)/(2×人物等级)), 0, 75)%`

B 包括盾牌基础格挡、职业因子和适用加成。无盾不会因为职业因子获得格挡。**原版目标**是奔跑时只将最终结果除 3 向下取整。格挡与 AR 是分开的检查；刺客武器格挡、完整格挡动画和 FBR 未接入。

**已修复**：派生属性保存站立/行走的基础最终格挡，不读取奔跑开关；战斗仅在本帧确实奔跑移动时折减一次。基础 75% 在奔跑中为 25%，不是旧实现的 8%。只开奔跑但站立、耐力耗尽转为行走时保留基础格挡；最后一个移动帧即使路径刚耗尽仍按奔跑处理，下一静止帧恢复。格挡动画/FBR 与原版耐力状态转换全过程仍需后续对照。

### 10.3 物理伤害

原版普通武器攻击分开处理：底材 → 无形 → 武器局部增强伤害 → 平加伤害 → 属性/技能/光环等非武器增强 → 致命/双倍 → 转换/元素附加 → 目标减伤。不同技能有不同分数与例外。

当前已把局部增强计入物品伤害，派生属性不会再重复乘一次；按 Weapons 数据的 StrBonus/DexBonus 计算属性贡献。普通近战已接通亚马逊 CS 与物品 DS（含武器 Lo 20%）：先检查 CS，失败后检查 DS，成功只将物理部分翻倍一次，再计算物理抗性。火/冰/闪电/魔法装备附伤分别受抗、不翻倍；当前攻击武器及适用非武器/背包护符生效，另一把武器和备用组附伤不计入。101 物理翻倍、75 物抗后为 50.5，另加 10 火伤总损失 60.5；不是四倍或所有元素双倍。

这只覆盖当前主攻击武器的普通近战路径；完整双持交替、射击/投掷、武器支配、技能转换、CB/OW、所有条件和各阶段舍入尚未等价，当前 CS→DS 的 RNG 调用顺序也未证明与 1.14d 逐次一致。

### 10.4 抗性与免疫

| 难度 | 玩家四抗基础处罚 | 当前上限 |
|---|---:|---:|
| 普通 | 0 | 75 |
| 噩梦 | −40 | 75 |
| 地狱 | −100 | 75 |

四抗分别是火、冰、闪电、毒；物理和魔法是其他通道，不包含在“所有抗性”中。当前抗性伤害 helper：

`实际伤害 = floor(floor(max(0,伤害)×256)×(100−max(−100,抗性))/100)/256`；抗性至少 100 则免疫，负抗下限 −100。中间值保留 1/256 生命单位，不先向下取整成整点生命。

例如 100 火伤打 50 火抗为 50；打 −50 火抗为 150；101 伤害在 75 抗后为 25.25 而不是 25。原版提高最大抗性、吸收、魔法减伤、破免技能及相应 1/5 效率管线仍待实现；不能把普通减抗当成已实现的破免。

当前玩家物理百分比减伤使用最高 50 的处理，并有平减物理伤害。完整吸收顺序、所有抗性上限和技能减伤不能由这个简化推导。

### 10.5 资源与吸取

- 自然回蓝每 25 Hz 帧按 `floor(floor(maxMana×256/3000)×(100+回复加成)/100)/256` 执行；暖气有效等级加成 `30+12×(L−1)%` 与装备回复相加。两次向下取整不能合并，因此不是精确 120 秒回满；900 法力、L20 暖气为每秒 26.5625，另加头盔 Eth 15% 时每帧 283/256。
- 自然生命回复及完整 Replenish Life 等未接全，主要依药水、治疗与已接入吸血。
- 普通近战吸血/吸蓝只取受抗后的物理生命损失，并以目标剩余生命为上限；装备元素不吸取。难度效率普通 1、噩梦 1/2、地狱 1/3，再受怪物 Drain 限制；JSON 省略的零 Drain 不能默认成 100，骷髅零 Drain 不吸取。
- 吸取按经典定点候选算式保留 1/256；3 点实际物理损失、普通难度 10% 吸取回复 76/256，而不是整点 0 或包含额外元素。完整 1.14d 舍入顺序、Life Tap、特殊技能资格、毒伤和复杂吸收仍未原版对照。

## 11. 动画、状态与怪物

### 11.1 逻辑节奏

原版规则目标使用 25 帧/秒；本版模拟也是 25 Hz，渲染独立。FCR、IAS、FHR、FBR 不是简单“每 1% 就快 1%”，原版有职业、武器、形态及技能专属断点。

当前有职业基础 FCR 表驱动施法冷却，但不是完整原版动画；近战 IAS 使用简化冷却公式。持续施法或攻击不再用整个冷却期锁住 WASD/摇杆，允许持续移动与战斗输入同时生效；移动不会重置技能冷却或免除蓝耗。这是紧凑战场的操作取舍，不是原版移动施法/完整行动帧复刻。FHR/FBR 的数值可被收录，不代表硬直/格挡帧已执行。原版详细断点见职业及战斗研究。

### 11.2 移动与冰冷

当前基础行走速度 6、奔跑 9 地图单位/秒，再按 FRW 百分比缩放；野外奔跑每帧扣 0.2 耐力，停止时每帧回 0.6。这是本项目近似，未完整复刻原版移动、负重和耐力公式。

冰伤对允许冰冷的怪物设置减速时长，噩梦/地狱分别缩短至普通的 1/2、1/4；当前减速幅度和攻击冷却仍简化。冰冷、冻结、眩晕、击退、缓慢目标、毒覆盖、流血不能互相混用。

### 11.3 怪物数值与 AI

原始 MonStats/MonLvl 提供生命、等级、AR、防御、伤害、经验、六抗等。普通难度通常用怪物原生等级；噩梦/地狱普通怪通常用区域等级，Boss/特定 noRatio 怪保留固定逻辑。冠军/独特/随从还有等级和生命/经验系数。

当前 AI 分类为近战、远程、萨满、Boss：追击、攻击、发射、复活沉沦魔。萨满复活仅接受普通 fallen 数字 ID 尸体，排除巫师、冠军、首领及已消费尸体；同一会话同一怪物只有首次死亡给经验并滚动掉落，复活后再次死亡仍参与清区任务检查。2026-11-18 修复了 fallenshaman 被前缀误算成 fallen、以及复活怪重复给经验/掉落的错误；未更改首次经验、怪物数值或旧装备。未警觉敌人需在七格内有视线或实际受伤才参战，警觉后在十一格内继续模拟；活怪移动时保留约 0.75 格间距，避免重叠集火。近战启动先发动作事件，六帧后检查目标仍在 1.35 格内且无墙阻挡才结算；冰冷时前摇十二帧，怪物死亡或真实转场时清除未完成挥击；自然步行跨地表边界不是这种转场。这些感知、间距和前摇是原创可玩性规则，并非已核准的原版 AI 参数；怪物移速仍统一近似。

Boss 原始生命/伤害/抗性存在，不代表安达利尔毒雾、都瑞尔冲锋、墨菲斯托技能、迪亚波罗技能、巴尔五波等专属行为已完成。精英词缀很多仍只是标签；先祖、封印 Boss、五波怪不是完整生成链。

当前各局部区域仍按固定规模紧凑生成：鲜血荒地约 18 普通怪，一般区域约 26，再追加特定超级独特/随从；邪恶洞窟固定 24 个敌人。第一幕共享地表保留这些每区生成输入，不把全世界怪物数当作单区数量。数量与密度是本版纵切设计，不是原版全地图密度复现。

## 12. 装备底材、品质与属性

### 12.1 物品由什么组成

一件物品包含：底材 code、名称、品质、ilvl、占格、位置、鉴定状态、无形、耐久、伤害/防御、属性、孔与镶嵌顺序、需求等级、价格、数量和唯一 uid。

- **底材**决定基础伤害、防御、类型、速度/系数、需求、尺寸、孔数上限等。
- **普通/扩展/精华**是底材层级，不是魔法品质。
- **ilvl**是这件物品的生成等级；**qlvl**是底材/定义等级；**alvl**决定随机词缀可用等级。
- 无形、孔和鉴定是独立标记，不是互斥的“品质”。

当前运行时有 635 个归一化底材。游戏内“装备图鉴”完整保留固定 LoD 1.14d 数据中的 2,971 条有身份装备定义，包含禁用、历史和未完成条目；不是可掉落件数，也不是装备生成菜单。

### 12.3 装备与位置规则

装备位：头盔、项链、身体、手套、腰带、靴、左右戒指，以及两套主手/副手组合。只计算当前手部组合。

装备需要已鉴定、未损坏、满足人物等级/职业/力量/敏捷。待装备物品自己的 +力量/+敏捷不能用来满足它自身的需求。替换时需要把旧物品放回背包；空间不够就取消整个操作，不丢弃旧装备。

背包装备详情、桌面悬浮属性与触屏物品浮层中，未满足的等级、力量、敏捷和职业要求逐条显示红色；尚未辨识和已损坏的耐久行也标红，满足后恢复普通属性文字颜色。数值使用当前实际无形/降低需求修正与穿戴判定，不重复显示未修正的底材需求。预判不计入待穿物品自身的属性、备用武器或损坏装备的加成，并检查替换后失去旧装备支持的情况；查看不会改写角色或装备随机值。需求全部满足并不保证背包有空间装回旧装备，空间和弹药匹配仍由实际装备操作验证。

- 双手武器通常排斥盾牌。
- 弓弩可以保留匹配箭/弩矢，尚不表示发射与消耗已完成。
- 野蛮人可双持可单手使用的武器；部分双手剑配副手时使用单手伤害。
- 刺客双持只允许爪。
- W 只切换手部组合，不是切换全部衣服。

### 12.4 属性支持边界

当前可汇入若干四属性、生命/法力、伤害/防御、命中、四抗、MF/GF、速度、吸取、技能等基础字段；局部增强只作用一次。背包中部分护身符属性可纳入派生值，仓库/方块/备用装备不会同等生效。

装备光环、触发技能、充能、oskill、每级属性、完整套装奖励、随机 staffmod/automod、珠宝镶嵌、全部历史属性 bug 未实现。物品详情中的“未实现”提示是实质限制，不是装饰说明。

## 15. 宝石、符文与符文之语

### 15.1 宝石

七类：紫宝石、黄宝石、蓝宝石、红宝石、绿宝石、钻石、骷髅；每类碎裂、裂开、普通、无瑕疵、完美五级，共 35。

同一材料在武器、头盔/护甲、盾的效果不同，依原始对应字段读取。例如完美黄宝石常用于护甲 MF，但盾中不是同一效果。不能把“宝石加成”统一做成任意位置同一种属性。

### 15.2 符文

33 枚符文，从 El 到 Zod，编号、中文名、代码、需求等级见规则目录。符文是独立可镶嵌材料，不是“越高阶颜色越好”的随机词缀。

MF 不提高符文掉落概率。高阶符文升级配方有对应宝石与数量条件，不能用任意三枚符文合下一阶。

### 15.3 符文之语成立条件

1. 普通或超强底材，允许无形；魔法/稀有/套装/暗金不成立。
2. 底材实际类型满足 itype 继承并避开 etype 排除。
3. **总孔数恰好等于序列长度**，不是只把前几个孔填对。
4. 按正确顺序镶入指定符文，全部填满。
5. 当前模式允许该符文之语。

例：叶子 Leaf 为 Tir → Ral 的两孔合法法杖；远古誓言 Ancient's Pledge 为 Ral → Ort → Tal 的三孔合法盾。顺序反了或用错误类型，只保留普通镶嵌效果，不退款；材料需求等级可能提高物品需求。

固定 LoD 表有 78 个完成定义，原版离线匹配 55 个；本版只额外开放 Edge（边缘，原始身份 `Runeword31`、server=1）作为赌博折扣的 D2R 离线覆盖，合计 **56 个匹配启用，其他 22 个 server 定义仍禁用**。Edge 必须在普通/超强合法弓或弩的恰好三孔中按 Tir → Tal → Amn 镶入；其装备光环等属性并未因此全部实现。Spirit（精神）、Insight（眼光）、Infinity（无限）仍不能制作，不采用 D2R 的全面开放。详见 20.4，完整序列、类型与原始模式标志见规则目录。

**成立≠所有属性已运行。** 触发、光环、充能、oskill 等仍未实现。镶嵌支持符文与宝石，不支持珠宝；属性重新计算要避免局部增强重复作用。

## 17. 掉落、TC、MF 与金币

### 17.1 TC 不是均匀随机抽装备

TreasureClassEx 指定 Picks、NoDrop、Item/Prob 和品质因子；选择可能继续指向另一 TC。底材确定后再判断品质与具体暗金/套装/词缀，不是先固定“5% 暗金”然后随便挑底材。

当前递归读取真实 TC、按权重/NoDrop 选择、处理部分同组升级与自动底材 TC，最多 6 件，players1。ilvl 来自生成上下文，不能一律等于人物等级。

首杀掉落、女伯爵双 TC、超级独特专用 TC、同局暗金唯一生成、多人 NoDrop、原版超级宝箱和某些负 Picks 截断尚未完整实现。因此当前杀女伯爵不能保证符合原版专门符文掉落规则。

### 17.2 品质与 MF

品质依次尝试暗金 → 套装 → 稀有 → 魔法 → 超强 → 普通 → 劣质，受 ItemRatio、ilvl/qlvl、TC 因子、可用定义限制。

当前有效 MF：魔法直接使用 MF；暗金/套装/稀有在 MF>10 时分别用 `floor(K×MF/(K+MF))`，K=250/500/600；小 MF 分支依代码处理。它影响品质判定，不改变符文/底材的 TC 选择。

例如 100 MF 在该分支中暗金有效 71、套装 83、稀有 85，而不是所有品质概率都翻倍。详细 128/1024 整数判定阶段见装备研究；多个概率阶段不能合并成一个浮点“稀有度”。

### 17.3 词缀

先按 ilvl/qlvl/magic_lvl 算 alvl，再按可用等级、类型、排除、职业、组号过滤，frequency 加权。魔法可有前缀/后缀/双词缀；稀有最多 3 前缀+3 后缀，珠宝数量有另外限制。

当前魔法分布为前缀单独 25%、后缀单独 50%、双词缀 25%；稀有词缀数量分布还未原版验证，随机 staffmod/automod 未接全。完整前后缀原始表见装备目录，包含不允许随机生成的历史条目。

### 17.4 金币

当前地面金币按 quantity 加到人物金币。GF/原版金币量、城镇存款/携带上限、死亡与商店完整定价尚未复原；不在后台模拟共享银行。

## 18. 地图、传送点与难度

### 18.1 目录与真实可达性

136 个区域按幕为 39/35/28/6/28；包含城镇、七个不同 ID 的古墓、牛场与 133–136 服务器超级事件区域。39 传送点按幕为 9/9/9/3/9。目录存在不等于离线可进入。

当前地图是原创种子生成。**局部区域尺寸**仍为：城镇 34×28、邪恶洞窟 32×28、其他洞窟 36×34、室内 38×30、室外 44×34（`src/world.ts`）；这些是拼接前各区的尺寸，不是共享地表世界的总尺寸。局部生成器处理内部地面、出口、设施与怪物可达性；不是原版 DS1 地块拼装、地标和随机算法复刻。

第一幕 11 个地表区域共用同一个 world 与全局坐标：罗格营地（1）、鲜血荒地（2）、冰冷之原（3）、石块旷野（4）、黑暗森林（5）、黑色荒地（6）、泰摩高地（7）、埋骨之地（17）、修道院大门（26）、外侧回廊（27）、内侧回廊（32）。保留原每区 seed、怪物 UID 与数值输入，再平移到共享坐标；只在合法、双向开放且布局相邻的出口间挖出宽 3 格的连接道路，不凭几何相邻添加剧情捷径。弗拉维驻守在鲜血荒地与冰冷之原之间的连接走道侧边，留出道路中线，可从两侧靠近交谈。

共享 world 中仍有三个独立的地表可走组件：**1/2/3/4/17**、**5/6/7/26/27**、**32**。石块旷野（4）必须经地下通道（10）前往黑暗森林（5），没有直接地表捷径；军营、监牢、教堂等仍是真实转场，不能从地表绕过。自然步行跨地表边界不会跳坐标、重建 world，也不会清掉按住输入、技能冷却或投射物；区域名与目标随站位更新。这是第一幕局部连续地表，不是五幕无缝大地图或原版 1:1 世界。

同一次游戏会话缓存世界与地牢，往返保留怪物、掉落和探索状态；读档仍按种子重新生成，不保存整张世界。IndexedDB v1 不变，原存档装备不重随机。

既有地图生成测试曾覆盖 136×3 难度，只检验当时生成器的内部可达性，不作为本轮连续地表验收，也不证明战役入口全部开放或剧情可完成。初始正常门槛可探索第一幕的大部分区域；安达利尔交付后能进入第二幕部分区域，但王宫/真墓等未完成链仍会挡路；完整战役未验收。

### 18.2 传送点与传送门

- 初始营地传送点已有；其他需要点击石台激活，进入区域不自动激活。
- 使用传送点须靠近石台，目的地已激活且幕已解锁。
- 弹窗顶部为第一幕至第五幕页签，一次只列所选幕的目的地；每次打开默认当前区域所属幕。未解锁幕仅供查看，目的地全部禁用；当前位置、未发现目的地也不能点击传送。页签浏览不改变角色解锁或存档，底部难度入口仍受原有门槛限制。
- 键盘左右方向键循环切幕，Home/End 选择第一/第五幕，Tab 进入目的地内容，Escape 关闭；触屏五个页签同排展示，点击区高度至少 44 px。
- 地表连通出口（exit seam）是路标：点击只寻路，沿道路自然跨界；探索地图显示箭头。地牢黑石入口等真实入口显示方框，需要靠近并交互转场，不能在日志里任意瞬移。
- 回城卷轴只能在城外开启当前角色的双向门对；再开门按唯一 UID 移除旧门对，返回野外时消耗该门对。第一幕共享地表中的城镇端使用营地对应的全局出生点，野外端记录开门区域与全局位置。
- 凯恩/牛场/峡谷/真墓等特殊门有独立任务条件，不当作普通邻接；回城门的替换与消耗只处理该门对，不清除其他特殊门（`src/engine.ts`）。这不代表特殊门的完整任务链已经完成。
- 保存后不保留运行时传送门，读档不会恢复门对。

### 18.3 难度解锁

原版目标：普通击败巴尔解锁噩梦，噩梦击败巴尔解锁地狱；怪物等级、抗性、吸取与经验规则随难度变化。

首版虽然提供三个难度的原始数值和选择 UI，但没有完整五幕巴尔通关链，不能在正常新角色流程中解锁后两难度。切换难度的当前实现还会将传送点列表重置为营地，并非完善的各难度传送点进度管理；任务键已按难度分别保存。

### 20.4 赌博详解：基德、经典算法候选与 D2R 风格交互

**当前已实现，不是仅有服务标签；也不是原 D2R 二进制实测结论。** 在城镇靠近基德交谈，默认直接进入赌博面板；点击“返回基德商店”仍可普通购物，再点击“赌博”切回。规则采用当前固定 LoD 数据和经典算法重建候选；免费刷新及买后单槽补货采用 D2R 风格交互，Edge 是唯一新增的 D2R 离线符文之语覆盖。普通商店库存与赌博报价互不混用。

#### 20.4.1 货物、隐藏结果与连续购买

- 候选取实际 `gamble` 表的 **125 个 code**，不是从全部装备底材均匀抽取。每个货位独立生成 ilvl，再按普通底材 `qlvl ≤ ilvl` 过滤候选；可出现重复底材。
- 一次生成 **14 个货位**：第一个必为戒指 `rin`，第二个必为项链 `amu`，其余从合法候选随机选择。
- 每个 offer 在陈列前已生成完整隐藏 `item`，包括升级底材、品质、词缀/具体定义和已鉴定标记。界面只显示普通层级的底材名称、图标与当前金币报价，购买前不泄露隐藏品质/属性；这里的“普通底材”不表示输出品质为普通。
- 点击图标、右键图标或激活赌博购买按钮后，购买的是**该 offer 原隐藏 item 的克隆**，不在付款时重掷它。成功进入当前 **10×8 背包**后扣款并显示已鉴定结果，不消耗鉴定卷轴。
- 成功只补已买的货位：新 offer UID、新 item UID、新隐藏输出，其他 13 位保持不变。通常保持该位普通底材；`ci0`（Circlet）/`ci1`（Coronet）补货先随机二选一，`ci2`（Tiara）/`ci3`（Diadem）的陈列与报价归 `ci1`，不提前暴露升级结果。
- “刷新货物”**免费换掉全部 14 位**，重新确保戒指/项链，不扣金币、不动腰带、持有物品或普通商店库存。旧 offer UID 随即过期；关闭/离开赌博上下文再打开也不是恢复旧报价。

#### 20.4.2 ilvl 与品质

每次新隐藏输出采用 `ilvl = clamp(clvl − 5 + floor(rng × 10), 5, 99)`；随机偏移均匀为 −5…+4，边界截断后 ilvl 不再必然有十个等概率的不同值。例如 clvl50 为 ilvl45…54。品质使用一次 `floor(rng×100000)` 的离散 roll：

| roll 区间（含端点） | 请求品质 | 100,000 个结果中的数量 | 概率 |
|---|---|---:|---:|
| 0–49 | unique 暗金 | 50 | 0.05% |
| 50–149 | set 套装 | 100 | 0.10% |
| 150–10149 | rare 稀有 | 10,000 | 10% |
| 10150–99999 | magic 魔法 | 89,850 | 89.85% |

**MF、players/player count、难度均不参与赌博品质 roll**，不套怪物掉落的 ItemRatio/TC/MF 流程。具体暗金/套装仍须符合实际升级底材、定义等级、启用和 rarity 条件；上表是请求品质，不保证最终存在对应暗金或套装。全部词缀、staffmods/automods 和暗金单局唯一性尚未完整实现。

#### 20.4.3 底材升级顺序与来源冲突

先取普通底材的 `ubercode`（exceptional 扩展）与 `ultracode`（elite 精华）映射，**exceptional 优先**：

1. 无 exceptional 映射则保留底材；计算 `T = 90×(ilvl − exceptional.qlvl)+1`。
2. `T ≤ 0` 直接保留普通底材，**不抽 exceptional，也不继续抽 elite**。
3. 否则抽 `floor(rng×10000) < T`，成功即输出 exceptional，不再尝试 elite。
4. 仅 exceptional 失败后，若有 elite 映射，计算 `eliteT = 33×(ilvl − elite.qlvl)+1`；正阈值才抽新的 `floor(rng×10000) < eliteT`，失败保留普通底材。

elite 是条件后续 roll，不能把两种阈值直接相加作为最终概率。**公开资料存在冲突**：Arreat Summit 写 `+1%`，换成万分单位为 `+100`；D2MOO 重建及所引用现行 D2R 模拟器使用 `+1/10000`，即代码里的 `+1`。例如 ilvl 等于对应 qlvl 时，两者分别为 1% 与 0.01%。本版明确选择 `+1` 和上述顺序，不把官方 `+100` 偷换成相同公式，也不声称此选择已由原 D2R 二进制实测证明。

#### 20.4.4 精确报价：本版整数顺序

价格由陈列的普通底材和**当前 clvl**决定，不按隐藏品质、隐藏 ilvl 或升级结果收费。戒指固定 **50,000**、项链固定 **63,000**（均为折扣前）。其他底材严格按 `gambling.ts` 的以下顺序计算；`trunc` 是向零截断，带符号中间量不能擅自改成 floor，缺失映射的权重/费用为 0：

```text
q = 普通底材 qlvl；C / Ce / Cu = 普通 / exceptional / elite 的 cost
A = 有 exceptional 时 max(0, 50×(clvl − exceptional.qlvl)+1)，否则 0
B = 有 elite 时 max(0, 25×(clvl − elite.qlvl)+1)，否则 0
S = max(1, trunc((minstack + maxstack)/2))
W = A×Ce + B×Cu + (10000 − A − B)×S×C
L = max(5, clvl)
M = trunc((2×L + 1)/3) + 20
K = trunc(250×(L + max(q − 45, 0) − trunc(q/2))/3)
price = trunc(M×(trunc(W/10000) + K)/15)
pay = price − floor(price×discount/100)
```

报价权重 A/B 的 50/25 不是升级 roll 的 90/33。不能把多次截断合并到最后，也不能将折扣改成 `floor(price×(100−discount)/100)`：本版先截断减免额再相减。可核对例为 **clvl50 的 Hand Axe `hax`：15,239 金币**，30% 折扣后为 **10,668**。这是本版确定的计算结果；D2MOO 定价代码自身留有 `TODO: rounding`，模拟器只能辅助交叉检查，**不宣称报价与原版/D2R 完全等价**。

#### 20.4.5 基德的运气、Edge 与旧物品兼容

- 新生成属性 `cheap` 映射为 `mods.vendorDiscount`，保留实际随机值。Gheed's Fortune（基德的运气）为 **10–15%**，当前武器组已激活的 Edge 为固定 **15%**，加法叠加。
- 折扣仅读已鉴定且达到需求等级的当前装备，以及背包内符合相同鉴定/等级条件的护符；破损有耐久装备、备用武器组、仓库/方块内护符不贡献。正常合法配装的一份基德护符＋当前 Edge 最高为 **30%，不是 35%**；代码对聚合值的 0…99 防护截断不是合法配装上限，也不表示已实现全部唯一物品限制。
- 30% 时戒指 **35,000**、项链 **44,100**。展示与付款都重新读取当前折扣，不能拿开面板时的旧折扣锁价。
- 旧 `unsupported:cheap::15:15` 可只读出确定的固定 15（乘已记录数量），**不修改旧 item**；如果已有 `vendorDiscount`，优先读取该值，不重复叠旧元组。旧 `unsupported:cheap::10:15` 丢失了当时的抽值，不能猜成 10/15、取平均或重掷，暂不提供该项折扣。
- Edge 原始身份为 **`Runeword31`、server=1**，原表/标志不改；普通或超强合法弓/弩，恰好三孔，按 **Tir `r03` → Tal `r07` → Amn `r11`** 制作，允许合法无形标记。只有这一项 D2R 离线覆盖；**LoD 离线 55＋Edge 1＝56**，其他 **22 个 server 定义仍禁用**，不开放 Spirit / Insight / Infinity。制作与折扣接入不等于 Edge 全部伤害、装备光环或战斗效果完成。

#### 20.4.6 拒绝、无形、耐久与保存

- 引擎要求未暂停、人物未死亡、位于城镇、当前 NPC 是有 gamble 服务的基德，并与打开会话的同一基德对象保持 **≤2 地图单位**距离；基德交谈默认经过相同资格检查进入赌博；从普通商店切回也走同一入口，刷新/购买要求赌博面板。移除 NPC、远离、野外、非基德/缺服务、错误面板均拒绝，不能只靠 UI 按钮绕过。
- 金币不足、背包满、空格总数够但没有所需连续矩形（碎格）、过期/错误 offer UID、普通商品 UID 或隐藏 item UID 冒充报价，均拒绝且**不扣款、不新增物品、不补货**。空间检查和实际 `placeItem` 都成功后才扣当前折扣价并补该位。
- `createItem(..., source='gambling')` 不进行普通掉落的随机无形判定；原定义强制 `ethereal` 的属性仍保留，不能为了“赌博不随机无形”删除强制无形暗金。
- 暗金候选失败转 rare、基础耐久 3×；套装候选失败转 magic、基础耐久 2×，再按已支持的耐久属性处理，**gambling 耐久上限 255**。强制无形仍按既有无形规则处理；普通掉落生成路径保持原行为，不把赌博的鉴定/无形/cap 规则全局套用。
- 临时 offers、隐藏未购买输出和赌博会话不写入 **IndexedDB v1**。买到的物品作为人物背包正常保存，原 UID/属性/鉴定结果延续；刷新货物或读档不重掷既有物品，不迁移猜测旧折扣值。
- 赌博面板出售仍走旧 `item.price/4` 及难度/幕上限的近似，不能把赌博买价当精确卖价，普通交易/维修/任务优惠仍未完整还原。

## 21. 死亡、尸体、保存与继续

### 21.1 当前死亡行为

- 生命归零进入死亡状态，停止移动/攻击与后续模拟奖励。
- 普通死亡无经验处罚；噩梦/地狱扣当前等级升级跨度的 5%/10%，不降到本等级起始经验以下。
- 当前金币先扣 `floor(携带金币×min(20,等级)/100)`，余下掉到死亡位置，人物携带变 0；这不是原版金币/存款/保护额度全部实现。
- 首具尸体保留装备，人物暂时失去装备属性。
- 复活回本幕城镇，再去尸体位置取装备；空槽优先穿回，冲突物品尝试放背包，空间不足则仍留尸体。
- 保存退出/继续后，尸体移到载入城镇附近。

原版回尸体经验返还、多具尸体选择、多次死亡装备分配、携带/仓库金币与 hardcore 永久死亡规则未完整复原。当前只保存一具尸体；不要把死亡系统当作已经无损覆盖全部边界。

### 21.2 保存什么

存储使用浏览器 IndexedDB，数据库 `sanctuary-h5`、对象表 `characters`、数据库 schema 版本 1。记录以角色独立 `id` 为主键，内容为 `{id, version: 1, player, seed, timestamp}`，保存职业、名字、等级经验、四属性、资源、自由点、硬技能、物品/装备/腰带/仓库/方块、任务、解锁、传送点、永久奖励及尸体等。

旧 localStorage 键 `sanctuary-h5-save-v1` 仅用于迁移：校验合法后导入固定迁移 ID `legacy-localstorage-v1`。迁移事务只在记录不存在时新增，因此刷新或另开页面不会用旧快照覆盖已更新角色；原 localStorage 数据保留，不再作为新的存档写入目标。旧数据损坏时提示并保留，允许创建新的独立角色。

不保存临时地图怪物状态、地面掉落、探索雾、投射物、特效、路径、冷却和传送门；第一幕共享地表也只保留同会话缓存，不写入世界快照。读档用种子重建地图并刷新怪物，从已解锁幕对应城镇开始，不回到原野外站位；RNG 状态不是逐帧检查点恢复。IndexedDB v1 与已保存装备的 UID、随机属性保持不变，不为地表拼接重随机原装备。

### 21.3 何时保存与风险

新角色创建、死亡、手动保存、约每 20 秒模拟时间、页面隐藏/离开等时点会尝试写存档。浏览器禁止存储、空间不足或隐私设置可能失败并提示；关闭浏览器时的事件不构成绝对写盘保证，重要进度先手动保存。

- 多角色独立存档，同名也不会覆盖；每次写入先捕获角色快照并按序提交，切换角色不会把在途写入串到另一角色。
- IndexedDB 不可用时，角色列表会显示原因并禁用新建/继续，避免误以为可以持久保存。
- 存档属于当前站点 origin：换端口/浏览器/隐私窗口可能看不到。
- 清理站点存储会删除角色。
- 没有账号同步、云备份、联机或多窗口冲突管理。
- 校验会拒绝损坏 JSON、错版本、非法职业/等级与关键物品字段，失败不自动覆盖旧存档。
- 当前还不是对所有容器重叠、物品 uid 唯一性和全量字段的完整防篡改验证，不是反作弊系统。

## 24. 常见问题与术语

### 24.1 常见问题

**为什么七职业都能建，却推荐法师？** 属性/装备目录完整，技能执行还不完整；法师有开局可用的火弹。圣骑士、死灵、德鲁伊没有当前受支持的职业技能。

**开局没技能点是不是错误？** 不是。人物开局 0 自由技能点，法师初始火弹由法杖授予；升级/任务才获得可分配点。

**为什么点了技能但没有施放？** 技能卡只查看详情；已学或装备授予、支持的主动技能需要点“绑定左键/右键”，成功后自动关闭面板。野外单击对应鼠标键、手机轻点“攻击/施法”尝试释放一次，按住连续释放；1–8 仅切换右键技能。营地、暂停/面板内禁止攻击，法力不足、失去装备授予、未获得或未实现技能仍不能施放。开局法师的火弹由初始短杖授予；切到空备用武器组会失去火弹有效等级，现标红显示不可用，桌面右键尝试会提示原因，按 X 切回原武器组可恢复。不会自动学习或重绑技能。此前短按会漏掉输入的问题已修复，保留原冷却与法力限制。

**为什么显示“学习规则数据”，点了也放不出来？** 该技能只收录前置和数值，未执行专用行为；可用于前置/部分协同，但不能绑定。

**暖气为什么不明显回蓝？** 已接入有效等级加成，并与装备回复相加；每 25 Hz 帧以 1/256 法力做两次取整，低法力上限时显示变化很小。人物面板可查看“法力回复加成”，技能不需要绑定施放。

**为什么打完洞窟还没奖励？** 需要全部活怪为零，再向阿卡拉交付；萨满复活怪会取消待领奖资格。

**为什么杀安达利尔还没到第二幕？** 需要向瓦瑞夫交付，之后旅行。

**为什么方块按钮灰着？** 需要取得真实方块，而正常第二幕任务取得链未完成；不免费赠送来伪装流程。

**为什么精神/眼光/无限不能做？** 本版保留 LoD 离线限制，仅为赌博折扣额外覆盖 Edge：55＋1＝56 个匹配，其他 22 个 server 定义仍禁用，不采用 D2R 的全面开放规则。

**为什么某装备属性显示未实现？** 原始定义已收录，但该属性处理器未执行；显示名字不等于有实战效果。

**为什么旧 Leaf 或技能护符还显示未实现？** 本批新制作／生成的物品已写入火焰／技能树加成；早先存为 unsupported 元组的旧物品没有自动重建。为保留角色和随机结果，本次不重随机、不清空存档；历史物品重建尚待处理。

**为什么背包开着还受伤？** 面板不自动暂停；Q/F、Shift+1–4 与腰带点击仍可喝药，但不能继续移动。请回城整理，或先关闭面板再用 Escape 真正暂停。

**为什么刷新后回城、掉落消失？** 当前保存角色不保存临时世界状态；怪物/地面物品和门重新生成。

**为什么另一个端口没有存档？** IndexedDB 按 origin 分开；浏览器、域名、协议、端口或隐私窗口变化都会影响。

**新建会让旧角色不见吗？** 不会。当前使用 IndexedDB 多角色存档，每个角色有独立 ID，同名也可共存；进入人物列表即可选中旧角色继续。旧 localStorage 单槽数据会自动校验并导入，且原数据保留。

**测试都通过是否代表原版全还原？** 不代表。测试覆盖本版已实现合同；未写入/未执行的原版行为仍需开发和对照。
