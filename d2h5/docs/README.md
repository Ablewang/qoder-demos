## 推荐阅读路线

1. **想试玩**：总手册的“快速开始”“操作与界面”“当前第一幕流程”“常见问题”。
2. **想评审设定**：总手册全文，再看实施计划的缺口和阶段安排。
3. **想查一个技能/符文之语/区域**：打开规则目录，用编辑器或浏览器查找名字、英文名或 ID。
4. **想核对 1:1**：先看对应研究文档的版本与可信度说明，再查当前固定提交的数据，最后用合法原版客户端验证。研究记录中的暂定值不能直接作为已验证的实现。
5. **游戏内查装备**：点击顶部“图鉴”或按 L；10 个分类、2,971 条完整身份定义，支持名称/code 搜索、翻页、原始参数与状态查看。历史/禁用条目仍可查阅，查阅不生成装备或写入角色存档。

## 文档之间如何分工

- **总手册**负责可读的中文解释，不在正文重复几千行原始词缀数据。
- **规则目录**负责当前固定版本的数据快照；条目存在不保证属性、AI、任务或技能已经执行。
- **研究文档**保留逐条公式、来源、完整附表和未决问题，不能因为实现了第一版就删除不确定性。
- **已知缺陷及修复**集中在总手册第 23 章；已接通普通近战 CS/DS、装备元素与物理吸取，修正奔跑格挡、紫药、暖气逐帧回蓝及火球伤害半径。当前仅 11 个职业技能白名单；这些修复不是全装备、210 技能或五幕通关完成证明。
- **深度调研审计**见四篇研究文档的新增审计段落：21 技能树、27 任务阶段、属性执行管线、版本证据和原版客户端尚未验证的项目。正常主线仍硬停在第二幕。
- **完整可玩验收合同**见实施计划：逐项区分原始定义、可达运行、独立测试与合法原版客户端对照，不以图鉴数量或画面相似替代完成。
- **实施计划**负责优先级、责任与验收，不代替玩家说明书。

## 本地启动

在 `d2h5` 项目目录运行：

```sh
pnpm install
pnpm dev -- --port 5173
```

打开 [本地游戏](http://127.0.0.1:5173)，观看或跳过原创开场后点击“开始游戏”，进入人物列表继续或新建。当前使用 IndexedDB 多角色独立存档，新建不会覆盖旧角色，同名可共存；旧 localStorage 存档自动校验并幂等导入，原数据保留。推荐首轮创建法师，利用初始法杖提供的火弹体验战斗；其他职业的完整技能玩法仍待实现。

## 更新约定

- 每次规则或功能变化，同步更新总手册的实现状态及实施计划。
- 数据目录可在项目目录用 `pnpm exec tsx scripts/export-reference.ts` 重新生成；生成器只读取本地项目数据，不下载新版本。
- 规则目录不能手工替换成 D2R 或 current master 数据。
- 测试结果以记录日期为准，不能将一次通过写成所有未来版本都已通过。
