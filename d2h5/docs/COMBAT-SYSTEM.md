# 庇护之地 H5：完整战斗、难度与属性适配规范

制定日期：2026-11-19。返回[文档入口](README.md) · [玩法手册](GAME-DESIGN.md) · [实施计划](IMPLEMENTATION-PLAN.md)。

> 本文是战斗系统的实现合同，不是“全部战斗已经还原”的完成声明。当前运行仍主要使用固定 LoD 1.14d 数据；D2R 规则差异必须逐条迁移、核验，不能把旧数据改个标题就称为重制版。设计中的公式、数据已收录、功能已实现、测试通过、原版对照通过是五种不同状态。

## 1. 目标、版本与不能妥协的原则

### 1.1 目标版本

- 战斗设计目标是 **D2R 经典七职业扩展模式，以 2.7 已公布规则作为固定对照起点**。不是宣称复刻 2026 年最新补丁的全部内容；后续版本变化须有独立差异表和测试。
- 保留 25 Hz 逻辑帧，桌面与触屏使用同一战斗内核；表现层帧率、模型大小和分辨率不影响结果。
- 当前原始数据仍固定为 LoD 1.14d 候选镜像提交 `0edfaf6d006f2eb82857c066e07ce03614285981`，不整包替换、不从 current master 隐式更新。需要 D2R 差异的字段通过有来源的适配表覆盖。
- D2R 2.4 的技能、宠物和行动规则调整，2.6 的冰冷精通破免惩罚，2.7 的 Next Hit Delay 规则等必须单列，不能混成“所有版本一样”。旧版 bug 不自动成为 D2R 目标。
- 普通、噩梦、地狱是三套有原始依据的数据环境；`/players 1–8` 是独立的生成缩放，不是第四种难度。
- 终局六首领采用 D2R 离线事件入口，但完整六首领必须有专属行为和可用的克制体系；只生成六个高血量通用近战怪不算完成。

### 1.2 非原版改编项必须隔离

10×8 背包、便利商店售卖大紫/全符文/乔丹/钥匙、紧凑地图和锁定视角属于改编。它们不参与怪物强度推导，不根据玩家买了高级物品就偷偷强化怪物，也不作为正常配装验收的必要前提。便利商店不能被写成原版商品表。

不赠送剧情物品，不预置高等级测试角色来证明地狱正常可达，不自动解锁幕和难度。用户真实角色、物品 UID、原始名字、随机属性、孔序和存档不得因适配而重抽。

### 1.3 规则可信度

| 标记 | 意义 | 能否直接作为生产规则 |
|---|---|---|
| 已核验公式 | 技术研究/原始字段有一致证据和独立数值样例 | 可以实现，但仍需行为对照 |
| 原始数据 | 当前固定表中存在字段和数值 | 只能说明定义存在，不证明硬编码行为 |
| D2R 差异 | 已确认补丁修改，需适配覆盖 | 只能用于注明的目标版本 |
| 待核验 | 舍入次序、单位判定、冲突资料尚未解决 | 不得用猜值放行，保留阻断项 |
| 改编 | 为 H5 明确改变的功能 | 可以实现，但不能称原版一致 |

## 2. 战斗单位、数据边界和执行架构

### 2.1 三类定义不互相偷算

1. **装备定义**决定底材、局部属性、词缀、随机值和来源条件，不直接扣怪物生命。
2. **技能定义**决定动作、命中资格、伤害通道、武器比例、协同、消耗、弹道/区域/持续效果，不直接写目标生命。
3. **怪物定义**决定基础/有效等级、生命、防御、抗性、攻击、回复、AI/动作和词缀，不根据玩家装备自动抬数值。
4. **战斗内核**接收攻击上下文和伤害包，依统一阶段结算。
5. **引擎**推进动作、实体、状态和事件，最后提交生命、法力、死亡、经验、掉落。
6. **渲染/UI**读取结果，不能再次命中、扣血、回蓝或随机掷值。

当前文件分工：`items.ts`、`rules.ts`、`world.ts` 提供来源和派生，`engine.ts` 提交运行结果；新增纯战斗内核应能脱离 DOM/Three.js 测试。暂不要求数据库升级，也不把临时动作状态写入 Player 存档。

### 2.2 攻击上下文

一次攻击至少携带：

| 字段 | 内容 |
|---|---|
| 攻击身份 | actionId、来源单位 UID、目标 UID、开始 tick、skillId、武器 UID/手别 |
| 攻击种类 | 近战武器、箭/弩、投掷、法术飞弹、持续区域、召唤攻击、反伤、毒/伤口 |
| 资格 | 需要 AR 吗、能盾挡吗、能武器格挡/闪避吗、能 CS/DS/CB/OW/吸取吗 |
| 伤害分量 | 物理/火/冰/电/魔法直接伤害；毒速率及长度另存 |
| 转换与比例 | 武器伤害分数、物理转换比例、各特效适用比例，不复用最终面板数值倒推 |
| 来源快照 | 硬点、软点、当前武器局部属性、适用全局属性、状态及光环 |
| 版本上下文 | 规则版本、难度、生成时 players、PVE/PVP/宠物身份 |
| 随机与结果 | 按阶段固定 RNG 顺序、碰撞/命中/格挡结果、各分量实际生命损失 |

伤害包不得只有 `damage: number`。同一次攻击的物理与火伤必须能够分别减免、分别判断吸取资格，毒和 OW 不可伪装成一次性直接伤害。

### 2.3 有来源的属性层

归一化属性必须保留 `sourceUid/sourceKind/stat/parameter/value/scope/condition`。

- scope：底材、武器局部、护甲局部、攻击武器、全身、当前技能、召唤物、目标状态。
- condition：当前武器组、物品已鉴定、耐久、等级/力量/敏捷/职业要求、怪物种族、近战/远程、套装件数。
- 同名数值不代表同一个阶段。例如武器 ED、盔甲宝石 ED、技能 ED、对恶魔 ED 不能无差别相乘。
- 被动、光环、诅咒、每级属性按各自层和上下文合并；不同技能之间的互斥不能靠“所有数值相加”。

### 2.4 装备激活与旧数据安全

当前手与备用手、左手与右手必须隔离。未鉴定魔法属性、破损装备、不满足需求装备、仓库/方块中的护符不提供不该生效的数值。基础武器/护甲和未鉴定魔法属性要分开处理。

力量/敏捷需求按来源排除自身后核算并处理依赖循环，不允许装备靠自己的力量 bonus 单独撑起自己。旧存档先读再重算，不能为使角色合法而删除物品或重新抽取词缀。

旧 `unsupported:code:param:min:max` 若只保留随机范围、没有当时 roll：不得迁移时新抽一个值、取中值或擅自取最大值。固定 `min=max` 可以在核验处理器后恢复固定效果；随机值遗失的记录必须明确记录无法无损适配，保持原物品不变。这是数据迁移阻断，不是允许装备悄悄变强的兼容开关。

## 3. 数值单位和随机合同

- 一秒 25 tick；200 帧=8 秒，10 帧=0.4 秒，120 秒=3000 帧。
- 生命、法力和伤害使用 **1/256 点定点数**。用整数 bits 做逐帧运算，显示时才转换为生命点。
- `floor` 向下取整，`trunc` 向零取整；负值时不能互换。
- RNG 区间端点、每次抽取位置、是否在未命中时跳过后续特效必须固定。地图、贴图和 UI 不消耗战斗 RNG。
- UI 的整数字样不是结算数值，例如显示 25 不意味着将 25.25 真实损失改成 25。
- 不跨阶段合并浮点表达式；命中率显示也不是伤害乘数。
- 同一 actionId 命中同一实体的重复提交必须按控制器规则拒绝；死亡、经验、任务奖励和掉落只提交一次。

## 4. 一次攻击的完整生命周期

```text
输入/AI意图
  →验证当前动作、资源、技能/装备、距离和施法条件
  →开始动作与资源事务
  →到达实际行动帧
  →创建攻击判定/飞弹/区域/召唤事件
  →碰撞、视线、目标资格及 Next Hit Delay
  →AR/自动命中判定
  →盾挡/闪避/武器格挡等独立判定
  →构建来源隔离的直接伤害包
  →符合条件的 CB（先于普通攻击损失）
  →CS/DS及技能专用转换、武器比例
  →防御结算、吸收与实际生命损失
  →吸取/生命偷取及命中触发
  →毒、OW、冰冷、击退、眩晕等状态应用
  →受击恢复/打断、死亡与只一次的经验/掉落
```

此图是阶段边界合同，不意味着所有技能有完全相同的内部回调顺序。`onAttack`、`onStrike` 和特殊技能动作回调必须使用已核验的各自位置；未命中或被格挡不能自动触发 onStrike。

资源事务需区分“拒绝施放”“合法开始后被打断”“行动已经发生”。法力何时扣、是否退、蓄力与引导行为按技能执行；不能普遍规定“取消就全退蓝”。普通武器挥空是合法攻击，不等于客户端没收到输入。

## 5. 命中、目标防御、格挡和闪避

### 5.1 命中率

对需要 AR 的攻击：

```text
CTH = clamp(floor(200 × AR/(AR+Defense) × attackerLevel/(attackerLevel+defenderLevel)), 5, 95)
```

相同等级且 AR=Defense 为 50%。80 级、4000 AR 对 85 级、2000 防御，原始约 64.646%，显示/掷值按整数规则处理。

```text
BaseAR = 5 × (Dexterity−7) + ClassToHitFactor
FinalAR = floor((BaseAR+适用平AR) × (100+适用AR百分比)/100)
```

七职业起始 AR：亚马逊95、刺客80、野蛮人85、德鲁伊70、死灵80、圣骑85、法师75。

- 防御只影响命中概率，不从伤害中直接减去。
- 需要 AR 的武器飞弹仍进行 AR 检查；法术飞弹按技能 flags，不因外观像箭就套 AR。
- 奔跑中的玩家：适用攻击绕过 AR 检查达到100%，仍可以按奔跑格挡概率挡住；不是把防御归零后仍截95%。仅移动/奔跑状态成立时应用，不因开了“奔跑模式”但站着就取消防御。
- Ignore Target Defense 对普通适用怪有效，不适用于 Boss/冠军/暗金等规定目标；等级项和5–95上限仍保留。
- 装备 -%目标防御在规定 Boss/玩家目标上折半，不能与信念防御减益共用一条“所有减防折半”规则。

### 5.2 防御

```text
BaseDefense = floor(Dex/4) + Σ各护甲局部最终防御 + 适用平防御
FinalDefense = floor(适用基础防御层 × (100+全局/技能防御%)/100) + 合格晚阶段条件防御
```

局部护甲 ED 不能再当全局 ED 重乘。局部 ED 护甲选最大底防+1等生成规则在物品生成层处理；内视、石肤、对远程/近战防御分别在其规定层应用。战吼/诅咒的数值要有来源与互斥。

### 5.3 盾挡

```text
BlockBase = 盾牌原始block + 职业BlockFactor + 增加格挡 + 圣盾适用bonus
CTB = clamp(floor(BlockBase × (Dex−15)/(2×角色等级)), 0, 75)
RunningCTB = floor(CTB/3)
```

盾牌的界面显示值常已含职业常数，禁止重复加职业值。80级、BlockBase75、Dex175：站立75%，奔跑25%。佣兵不能因为拿盾就取得玩家盾挡。重击等专用技能不可套普通盾挡；法术、刺客武器格挡、亚马逊三类躲避按独立 flags 和状态执行。

Boss 盾挡必须真的执行，不能只显示字段；原版幕首领格挡取普通/噩梦/地狱：安达利尔0/20/40，都瑞尔0/25/50，墨菲斯托20/40/50，迪亚波罗25/40/50，巴尔40/45/55，目标D2R逐条复核后应用。

## 6. 武器物理伤害与双倍

### 6.1 普通武器攻击

```text
EthMin = floor(BaseMin × (无形?1.5:1))
LocalMin = floor(EthMin × (100+武器局部ED)/100) + 武器局部适用平伤
WeaponMin = LocalMin + 适用非武器Min + 适用DamagePlus
AttributeED = floor(Strength×StrBonus/100) + floor(Dexterity×DexBonus/100)
OffWeaponED = AttributeED + SkillED + MasteryED + AuraED + 非武器ED + 对目标种族ED − 适用伤害减益
AttackMinBits = 规定取整(WeaponMin × (100+OffWeaponED)/100 × 256)
```

最大值对应计算。局部 min/max 不得在派生层再加一次。`Damage +X` 与单独最小/最大伤害是不同属性，技能可用性不同。最终 min≥max 的端点修复必须在正确阶段执行，不能随处 `max(min,max)` 掩盖计算错误。

| 武器类别 | StrBonus/DexBonus | 属性伤害加成 |
|---|---|---|
| 常规近战 | 100/0 | 力量每点约1% |
| 锤 | 110/0 | 力量每点1.1%，百分比取整 |
| 匕首、爪、普通投掷/标枪 | 75/75 | 力敏各0.75% |
| 弓弩 | 0/100 | 敏捷每点1% |
| 亚马逊专用矛/标枪 | 80/50 | 力量0.8%、敏捷0.5% |

以原始 Weapons 字段为准，不只依赖中文分类名。投掷与近战选择不同伤害端点；弓弩普通攻击必须发出真实武器飞弹而不是近战敲打。

### 6.2 手算案例

底伤20–30，无形、局部ED200%，额外最小10/最大20，力量ED150%、技能ED100%、光环ED50%：

1. 无形30–45；局部ED90–135。
2. 适用平伤后100–155。
3. 非武器ED相加300%，得到400–620。
4. CS/DS成功后800–1240物理；火/冰/电/毒附伤不跟着翻倍。

这是普通攻击案例，不直接推广到重击、踢击、复仇、狂战士或刃系。

### 6.3 CS/DS

```text
P(double) = C + (1−C)×D
```

60% CS与30% DS不是90%，而是72%；期望物理倍数1.72。武器支配暴击有自己的资格/级联，不能把三个概率直接相加。最多普通玩家物理双倍一次，不产生通用4倍。怪物 Crit 和佣兵特例是独立系统。

### 6.4 专用技能适配

| 技能/机制 | 必须区别于普通攻击 |
|---|---|
| 重击 | 盾底伤、圣盾、允许的Damage+X、专用ED；不取武器普通端点，不普通吸取/CS/DS |
| 踢击 | 人物+靴底伤专用公式，不能用武器伤害替代 |
| 复仇 | 取允许的武器与平伤基础构建元素，不能把所有非武器ED或Grief统一复制进元素 |
| 狂战士 | 合格物理双倍后转换魔法，转换部分不普通吸取；防御惩罚为真实状态 |
| 多重箭/炮轰/闪电标枪及刃系 | 按目标D2R技能的武器比例和触发资格；旧版比例不直接覆盖D2R修改 |
| 双持/旋风/狂乱 | 各手攻击上下文、节拍、范围、修正和D2R规则，不拿两手属性相加作单次攻击 |

缺少专用公式的技能不得改成“通用近战且看起来差不多”。

## 7. 元素、魔法、技能成长和协同

### 7.1 五段技能基础成长

对有效技能等级 s：

```text
counts = [min(s−1,7), clamp(s−8,0,8), clamp(s−16,0,6), clamp(s−22,0,6), max(s−28,0)]
RawDamage = Base + Σ(counts[i] × LevelIncrement[i])
BaseDamageBits = RawDamage × 2^HitShift
SynergyDamageBits = trunc(BaseDamageBits × (100+合格硬点协同%)/100)
FinalSkillDamageBits = trunc(SynergyDamageBits × (100+合格精通/技能伤害%)/100)
```

这是使用该数据模型的伤害通道，不是所有技能的统一公式。持续地狱之火、陷阱、闪电最小值、充能弹数量、暴风雪落点、九头海蛇、召唤单位必须读取各自服务器函数和D2R差异。

### 7.2 硬点、软点、授予

- 实际技能等级=硬点+合格单技能授予+全技能+职业/树/元素 bonus；某些授予与 oskill 有特殊规则。
- 大多数协同只吃硬点；项链/火炬/技能护符不能被当成额外协同硬点。
- 前置和学习上限检查硬点，装备临时授予不能替代技能树前置。
- 装备充能技能不要求本职业已学，但有自己的固定等级、次数和施法条件；不能借用角色硬点等级。
- 聚气、触发、oskill、被动、光环不是相同来源。

初始法师短杖+1火弹：有效等级1，硬点0；当前固定LoD参数为3–6火伤、2.5法力。该用例必须通过当前实际施法、目标扣血、扣蓝，而非仅面板文本。

### 7.3 元素独立结算

物理、火、冰、电、魔法分别有自己的伤害范围与抗性。火伤不吃物理ED和物理双倍；法术不获得普通武器元素附伤，除非技能规则明确允许。冰冷伤害与冰冷长度是两个量，不能有冰伤就固定减速两秒。

## 8. 抗性、免疫、破免与穿透

### 8.1 玩家抗性

```text
StoredResist = 装备 + 技能 + 任务 + 状态 + 难度惩罚
MaxResist = min(75+最大抗性bonus,95)
EffectiveResist = clamp(StoredResist,−100,MaxResist)
```

火冰电毒难度惩罚0/−40/−100。先减难度再截上限，不是“地狱最高只能−25”。物理和魔法不套该惩罚；玩家正物理抗上限50%，怪物不套50%或75%上限。地狱怪没有统一额外50%物抗。

175全抗装备在地狱得到75有效；250装备得到150存储但仍75有效，过量部分能对抗减抗。需同时保留 stored/effective/max，不能只留下截断后的75导致信念计算错误。

```text
PostResistBits = floor(max(0,DamageBits) × (100−max(−100,EffectiveResist))/100)
```

怪物最终抗性≥100时普通对应通道免疫。1000伤害、75抗→250；−100抗→2000。负抗不能超过规定−100下限。

### 8.2 破免和穿透的先后

| 来源 | 通道 | 可以单独打破原始免疫吗 |
|---|---|---|
| 信念 | 火/冰/电，另有独立减防 | 合格免疫按1/5 |
| 降低抵抗 | 火/冰/电/毒 | 合格免疫按1/5 |
| 伤害加深、衰老 | 物理 | 合格免疫按1/5 |
| 装备-敌抗、元素精通穿透 | 指定通道 | 通常不能单独破原始免疫 |
| D2R破免护符 | 对应伤害通道 | 符合护符目标资格，独立阶段 |

原始免疫、破免符解除免疫、普通非免疫必须是不同状态。无破免符时：先合格破免；仍≥100则普通装备穿透无效；跌至<100后再按目标版本允许的穿透应用。合格破免已经发生后，破免技能的其余4/5不能当场补算。

案例：110电抗、信念−150，破免阶段只减30得80，再装备−20得60，1000电伤扣400。130电抗同信念后100，仍免疫，普通装备−100不帮忙。

D2R需特别落实：破免符只作用于原本对应免疫的合格怪物；元素破免后的基准抗性与物理破免不同；信念/降低抵抗对被破免的怪物有惩罚，**D2R 2.6 起冰冷精通对被破免目标按1/5**。物品负抗、毒长度、宠物/陷阱继承和版本细节分别验收，不照搬LoD“破免后冰冷精通全额”的实现。

多源破免的整数截断边界、同类信念竞争、净化和圣域的特殊判定属于明确待核验项；不为了让任意纯元素构筑打得动所有免疫而人为改抗性。

## 9. 减伤、护盾、吸收和资源

### 9.1 防守管线

通道许可明确后，基准阶段：

```text
单位/技能专用修正
  →白骨/飓风装甲等允许的吸收池
  →能量护盾的转移（魔法/元素等资格按技能）
  →物理平减伤 / 适用通道MDR
  →各通道有效抗性
  →该通道百分比吸收
  →该通道平吸收
  →实际生命损失
```

- MDR分别作用于魔法/火/冰/电，不一般作用于毒。
- 能量护盾转移前不先减元素抗；毒、CB、OW不进入ES。心灵传动硬点T的法力/伤害比k=2−T/16，ES比例e上限95%，法力M时转移量=min(e×合格伤害,M/k)，法力不足只部分转移；逐阶段bits舍入仍需客户端确认。
- 白骨装甲只吃允许的物理直接伤害，飓风装甲只吃允许元素；盾不能复制当前玩家75抗的生命池。
- 玩家DR%=clamp(存储物抗+状态,−100,50)，存储过量不能提前丢弃。
- 百分比元素吸收最高40%；先按当时缺血量治疗，再减去吸收量。满血不能利用被浪费的治疗再“减两次”。
- 吸收不能导致无意超最大生命；多通道顺序需要固定并测试。
- PDR/MDR跨通道溢出历史 bug、精确护盾舍入以及各单位减伤矩阵尚未核验的部分不能臆造。

例：500物理、平DR20、50物抗→240损失。100火伤已过抗、20%吸收：缺血充分时先治20再受80，净损失60；满血时净损失80，不是60。

### 9.2 吸取与生命偷取

普通生命/法力吸取只使用 **受减免后实际扣掉的合格物理攻击生命**；上限为该阶段目标剩余生命。CB、毒、OW、普通法术和已经转换成元素/魔法的分量不贡献普通吸取。

```text
Leech ≈ AppliedPhysical × LeechPercent/100 × MonsterDrain/100 ÷ DifficultyDivisor
DifficultyDivisor = 1 / 2 / 3
```

不能先把地狱1%吸取整除3得0；逐阶段定点算法另有精确实现样例。900实际物理、10%吸取、Drain50、地狱→约15生命。Drain0骷髅不可吸取；不能概括成所有亡灵都不吸取。

生命偷取诅咒是独立50%合格物理回复路径，可绕普通难度/Drain，重击例外按其规则支持；不让火球获得50%回复。目标只剩3血时，101物理不能按101回血。

### 9.3 基础资源和回复

玩家默认无天然回血。Replenish Life R 每帧R bits，R40每秒3.90625血。回血光环、药水、击杀回血是不同来源。

```text
BaseManaBitsPerTick = floor(MaxMana×256/3000)
ManaBitsPerTick = floor(BaseManaBitsPerTick×(100+回复%)/100)
```

900法力、20级暖气258%：每帧272bits，每秒26.5625。暖气、冥思和装备回复百分比依合格规则相加；最大法力也影响回复基数。

初始体力/精力不能重复加。生命百分比、装备体力、每级生命和法力百分比不全在同一乘法桶。药水疗程、同类叠加/覆盖、关键回复、抗毒/解冻临时抗性与上限分别定义，不能所有药水只“加一个瞬时数”。

## 10. 压碎、撕裂、毒与回复抑制

### 10.1 压碎性打击 CB

命中后合格CB先于普通攻击损失，用目标当前生命；不能靠面板物理值计算。

| 目标 | 近战 fraction | 远程 fraction |
|---|---|---|
| 普通怪、冠军、随机暗金 | 1/4 | 1/8 |
| 固定超级暗金、首领 | 1/8 | 1/16 |
| 玩家/佣兵 | 1/10 | 1/20 |

```text
MonsterCBLoss ≈ CurrentLife × fraction ÷ SpawnPlayersLifeFactor × (100−max(0,物抗))/100
```

物免/完全抵抗时为0；负物抗不放大CB。CB不CS/DS，不普通吸取，不重复吃已经放大的玩家数生命。P3、10万当前血Boss、50物抗、近战CB：3125血，再结算普通伤害。

精确bits除法顺序和全目标类谓词必须通过独立对照，不能靠近似符号宣称字节级还原。

### 10.2 撕裂伤口 OW

持续200帧、8秒，不平行叠加成数十条出血。攻击者等级L决定每帧负回复bits：

| 等级 | bits/tick |
|---|---|
| 1–15 | 9L+31 |
| 16–30 | 18L−104 |
| 31–45 | 27L−374 |
| 46–60 | 36L−779 |
| 61–99 | 45L−1319 |

普通怪速率按表；冠军至首领伤害折半，玩家近战/远程有1/4、1/8惩罚。不是物理武器伤害，不用物抗再缩一次，不提供吸取。70级Q=1831，普通目标每秒约178.8086血；状态持续200帧，但资料记录199次实际损失，完整总量为199×1831/256=1423.31640625，不按200次扣血。

刷新长度但不平行叠层，保留首次伤口伤害率；帧边界仍需目标客户端确认。OW抑制自然回复但不阻止药水，死亡后立即停止，不从已死单位再给经验。

### 10.3 毒素

```text
PoisonSource = { minRateBits, maxRateBits, lengthFrames, sourceUid, sourceKind }
普通装备毒：TotalRate=ΣRate；Length=按有效毒来源数平均Length
TotalPoisonPoints = RateBitsPerTick × LengthFrames /256
```

一件物品的前后缀毒按一个来源合并；不同镶嵌宝石/珠宝可为独立来源。不能仅把最终显示的毒总量相加，也不能把毒总伤当每次命中一次性伤害。

示例两来源100/200bits每帧，长度100/200帧，合并300bits、150帧，未减免175.78125总毒，持续6秒。

```text
ResistedRate = floor(RateBits × (100−PoisonResist)/100)
ResistedLength = 按规定取整(Length × (100−PLR)/100)
```

玩家PLR另有0/−40/−100难度惩罚、−100下限/75上限；毒抗改速率而非长度。装备−敌毒抗在合格目标上还影响毒长度，降低抵抗诅咒不因此直接改PLR。

Venom将普通物品毒贡献长度限制10帧，不把原几秒全部伤害压缩至0.4秒。淬毒匕首/毒枪/瘟疫枪按专用混合规则，不能复用普通装备平均长度。

毒不是MMO式任意平行堆层，强度/覆盖按原规则；对玩家毒通常留至少1生命，对怪、宠物、佣兵可致死。直接命中分量仍能击杀玩家。覆盖与第一帧损失边界列为待核验，不隐藏在泛用持续伤害循环里。

### 10.4 怪物回复与 PMH

```text
RegenBitsPerTick = floor(MaxLifeBits × DamageRegen/4096)
```

DamageRegen2约每秒1.2207%最大生命；4约2.4414%。从原始每怪字段取，不给所有Boss随意统一回血。直接损伤帧、毒/OW、PMH分别控制回复资格；额外停回复若存在必须按离线目标版本核验。

PMH有攻击来源/单位/Boss例外；**超级六首领不受普通PMH抑制**，不能把一种低级词缀当成禁用六Boss回复。毒和OW应能按各怪抗性/资格真实提供克制。DamageRegen4、65万血的Boss名义回复约15869血/秒，没有CB、OW/毒和正确构筑的通用小火弹路径不能被当正常终局验收。

## 11. 动作、速度、受击与控制

### 11.1 行动状态机

```text
Idle / Walk / Run
  ↔AttackWindup→AttackActionFrame→AttackRecovery
  ↔CastWindup→CastActionFrame→CastRecovery
  ↔BlockRecovery / HitRecovery / Stunned / Frozen
  →Dying→Dead
```

每技能动作可以有多个行动帧、rollback、引导或连续动作；多个按键不绕过时序。动画和碰撞同源；显示挥刀而每帧立刻扣血不是完成。技能延迟与施法动画是两个时钟。

当前“边移动边持续施法”为H5操作改编，与原版施法动作锁位不完全一致。适配时要明确移动-施放动作规则并保证脱离/取消输入，不用卡住控制补偿缺少动作状态。

### 11.2 IAS与攻击速度

普通攻击的有效IAS核心层：

```text
ItemEIAS = floor(120×IAS/(120+IAS))
EIAS = ItemEIAS + SkillIAS − WSM + 适用速度状态
AnimationRate = floor(BaseAnimRate × (100+受该动作限制后的EIAS)/100)
```

最终行动帧、周期、回滚、上限依职业、武器动画类、形态和技能。不得再使用 `基础挥刀帧/(1+IAS/100)` 当全部武器的公式。缺AnimData/COF/技能帧资料是阻断项，不准猜一个13帧统一给七职业。

弓弩/投掷/双持/旋风/狂乱、狼人熊人、圣骑连续技和刺客爪均单独验收。寒冷、衰老、信念等速度/防御效果不能都按“最终秒伤×0.5”处理。

### 11.3 FCR

FCR使用职业/形态/技能断点，不线性缩短。法师普通施法断点：0/9/20/37/63/105/200%，对应13/12/11/10/9/8/7帧。闪电/连锁闪电使用专用较长动作表。德鲁伊变形和Trang吸血鬼不能沿用人形表。

13帧=0.52秒、7帧=0.28秒；法力消耗/技能延迟/飞弹限制仍可能限制真正命中频率。每档前一值、断点值、后一值都要测试。

### 11.4 FHR/FBR与真实打断

对符合受击恢复资格的直接伤害，T=最大生命/16，某些飞弹用/8：

| 实际伤害 | 候选受击恢复概率 |
|---|---|
| <T | 0 |
| T–<2T | 37.5% |
| 2T–<4T | 75% |
| ≥4T | 100% |

不是“大于1/12必打断”。毒、无GetHit动画单位、死亡/冻结状态、低于1点等资格需判断。

```text
EffectiveRate = floor(120×FHR或FBR/(120+对应数值))
RecoveryFrames = ceil(256×该动作Base / floor(AnimSpeed×(50+EffectiveRate)/100))−1
```

FHR、FBR有不同基础动画和状态资格；圣盾改变格挡动作，法师15帧起始受击与9帧起始盾挡不是同一张表。怪物GetHit、Boss免打断、佣兵特例分别读取资料。

### 11.5 控制与时长

- 冰冷伤害、chill、freeze不同。冰长度按目标抗性、普通/噩梦/地狱分别为1、1/2、1/4的长度系数和原始coldeffect处理，不固定所有怪减速50%。
- Cannot Be Frozen不免冷伤，圣冰也不普遍被它取消；Boss不可直接完全冻结。
- 击退按技能、目标尺寸、免疫 flags 和碰撞选择；不能穿墙/挤进不可达格。
- 眩晕玩家星星和怪物定身不同；Boss、冠军适用概率和时长依规则。
- 弹道命中使用移动轨迹而非只测每帧终点，避免高速穿透小怪；碰墙爆炸按技能控制器。
- D2R Next Hit Delay 按补丁的技能作用域，不用一条“目标全局CD”屏蔽所有伤害；散弹、多段、穿刺、跳跃、回旋控制器各自定义命中集合。

### 12.2 players缩放

```text
LifeXpFactor(P) = (P+1)/2，P∈[1,8]
```

| P | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| 生命/经验因子 | 1 | 1.5 | 2 | 2.5 | 3 | 3.5 | 4 | 4.5 |

生命生成次序：

```text
BaseLifePoints = floor(MonLvl对应HP × MonStats对应HP百分比/100)
GameLifePoints = floor(BaseLifePoints × LifeXpFactor)
FinalLifeBits = floor(GameLifePoints × EliteLifeMultiplier ×256)
```

749血、P2：先取1123生命，再精英乘数。噩梦999基础、P1冠军×2.5→2497.5实际生命。不能连乘后一次取整。

- players不泛化提高抗性，不调整玩家伤害/掉率品质或所有Boss特殊攻击。
- NoDrop与虚拟非同区队友计数属于独立掉落模型，不能用生命因子直接缩NoDrop；MF不提高符文品质、不影响钥匙特定概率。
- UI明确显示难度/P和已生成快照；若P选择未完成，只能明确当前固定P1，不能显示一个不生效的8PP按钮。

## 13. 怪物适配：从普通怪到六首领

### 13.1 基础等级与有效等级

分别保留 `baseLevel/effectiveLevel/statLookupLevel/spawnPlayers`。普通怪Normal取原始种类等级，噩梦/地狱一般取区域等级；固定Boss/noRatio使用专门字段，不把所有金名怪当固定Boss。

| 统计量 | 使用等级 |
|---|---|
| HP、防御、基础经验 | 一般用baseLevel |
| AR、A1/A2攻击伤害 | 一般用effectiveLevel |
| 命中等级项、掉落ilvl | effectiveLevel |
| 首领、noRatio、特殊法术 | 按专用定义 |

```text
HP=floor(MonLvl[base].L-HP[d]×MonStats.HP[d]/100)
Defense=floor(MonLvl[base].L-AC[d]×MonStats.AC[d]/100)
AR=floor(MonLvl[effective].L-TH[d]×MonStats.A1TH[d]/100)
Damage=floor(MonLvl[effective].L-DM[d]×MonStats.A1Damage[d]/100)
XP=floor(MonLvl[base].L-XP[d]×MonStats.Exp[d]/100)
```

A1、A2、技能攻击各自适配，不把怪所有飞弹伤害都拿A1物理端点。`noRatio`用直接值的规则不要再次乘MonLvl。

### 14.2 触发、聚气与状态事件

| 事件 | 资格 | 不允许发生的误算 |
|---|---|---|
| OnAttack | 合格近战动作，挥空/格挡也可能触发 | 不等同于命中；旋风不泛用攻击CTC |

### 14.4 推荐配装和怪物克制不等于人为平衡

- 物理构筑：需要命中、正确武器局部/全局ED、速度、CB/OW与吸取，不只堆面板最大伤害。
- 元素构筑：需要技能有效等级、硬点协同、FCR/延迟、精通/穿透、法力与对免疫的合法应对。
- 毒构筑：需要真实速率/长度、毒免处理、覆盖、减毒抗与安全持续输出。
- 召唤构筑：需要单位命中/攻击、技能等级、协同/状态、AI和主人到宠物的属性继承。
- 生存：真实抗性、过量抗、格挡与敏捷成本、资源回复、控制、减伤/吸收和动作打断。

这些形成原版体系，不新造“怪物跟玩家战力线性成长”。推荐等级、装备水平和击杀时间只做诊断观测，不写成自动改怪数值的隐藏规则。

### 16.3 诊断记录

1. 技能已获得且使用正确当前组吗？未鉴定/破损/需求导致属性失效吗？
2. 实际攻击频率/行动帧是否正确？输入是否漏掉或反复取消？
3. 弹道碰墙/错位/穿透是否造成发出但未命中？

5. 局部ED、平伤、协同/精通是否漏算/重算/错误封顶？
6. 是否真正免疫或强抗？合法破免/穿透是否执行？
7. 怪物P/精英/难度缩放是否重复，HP生成floor是否正确？
