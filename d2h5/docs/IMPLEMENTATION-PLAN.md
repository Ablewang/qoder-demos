## 目标与版本边界

以原版 PC Diablo II: Lord of Destruction **1.14d** 扩展模式为基线，不包含 D2R 2.4+ 的平衡调整、共享仓库、恐怖地带、破免符。采用原创材质、石雕/皮革 UI 与锁定斜视角 three.js 场景；角色使用程序化骨骼，不复制原版音乐、贴图、动画或程序代码。离线浏览器单人游戏；不创建云端账户、数据库或公开部署。

“1:1”是最终逐条验收目标，不是数据导入后就可以声称完成。旧版 TXT/JSON 不能解释所有服务器函数、动画碰撞及历史 bug；必须以合法原版客户端行为作最终对照。现有研究中的 Established/Data/Provisional 标记必须保留。Ladder-only 内容与离线规则须单独审查。
