# 4000 周 · 粗略产品文档

> 状态：点子阶段 / 待开发
> 一句话：把一个人的一生画成约 4000 个格子——你自己的、孩子的、另一半的、父母的——然后一周一句，把格子填满。

---

## 1. 这个点子是怎么想出来的

**出发点**：头脑风暴的要求是"有趣、有用、有意义、有创意、有亮点"，我想找一个**视觉冲击最强、纯前端就能做惊艳**的点子。

**思考过程**：

1. **灵感来源**：
   - 奥利弗·伯克曼的书《四千周》：按 80 岁算，人的一生大约只有 4000 周（80 × 52 ≈ 4160）。
   - Tim Urban（Wait But Why）的"Your Life in Weeks"：把一生画成一张格子图，一行 52 格，一共 90 行。
   - 第一次看到这张图的人几乎都会愣一下——**"原来已经用掉这么多了"**。这种视觉冲击就是天然的亮点。
2. **只看图不够，要让它"有用"**：一张静态图看一次就完了。所以加上**每周一句**：每周给当周的格子写一句话、涂一个颜色。格子从"倒计时"变成"日记"，从焦虑变成珍惜，也形成了每周回来一次的习惯。
3. **用户的扩展：不止给自己**（这是这个产品真正与众不同的地方）
   - **给孩子**：从出生那周开始，每周一句——"第一次翻身""今天叫了爸爸"。这就是一本成长日记，长大后可以作为礼物交给 TA。
   - **给另一半**：两个人的格子按日历对齐，**从认识那周起，两条人生开始重叠**。重叠的那些格子就是"我们"。
   - **给父母**：Tim Urban 还有一篇《The Tail End》：如果你一年回家见父母 2 次，他们还剩 20 年，那你们一生中**只剩约 40 次见面**，而你和父母相处的时间可能 90% 已经用完了。把这个算出来、画出来，非常戳人，也是最有"意义"的部分。
   - （可选）**给宠物**：宠物的格子很短，更让人珍惜。
4. **核心转变**：从"我还剩多少周"（焦虑）→ "我和我爱的人，一起过了多少周、还能一起过多少周"（珍惜）。

**五个维度的自检**：
- 有趣：一屏几千个格子，当前周在闪，视觉上很酷
- 有用：轻量的周记 / 成长记录工具
- 有意义：陪伴的可视化，提醒人珍惜时间和身边的人
- 有创意：多人格子对齐，"重叠的周"
- 有亮点：父母的"剩余见面次数"、两人人生的重叠区、年底"年轮"海报

---

## 2. 目标用户与场景

| 用户 | 场景 |
|---|---|
| 自己 | 每周日晚上写一句，记录这一周 |
| 新手父母 | 给孩子从出生起每周记一句，做成长档案 |
| 情侣 / 夫妻 | 记录在一起的每一周，纪念日回看 |
| 在外工作的子女 | 看到"和父母的剩余见面次数"，决定多回家 |

---

## 3. 核心概念

- **一生（Life）**：一个人的格子图。包含姓名、出生日期、关系、主题色、预期寿命（默认 90 年，可调）。
- **格子（Week）**：一周 = 一格。状态：过去 / 本周 / 未来。可以有：一句话、一个颜色或 emoji、可选一张照片。
- **里程碑（Milestone）**：特别的周，如出生、入学、毕业、相识、结婚、孩子出生，格子上有特殊标记。
- **关系视图**：多个"一生"按日历时间对齐展示。

---

## 4. 核心功能

### MVP

1. **创建一生**：自己 / 孩子 / 伴侣 / 父母 / 其他；填名字、生日
2. **格子图**：一行 52 格、按年分行；过去的格子着色，本周闪烁，未来留白；按年龄标刻度（0、10、20……）
3. **每周一句**：点击本周（或任意过去的周）写一句话 + 选颜色/emoji；有内容的格子有明显区别
4. **里程碑**：给某周打上里程碑标记，格子图上可见
5. **多人对齐视图（亮点）**：选两个或以上的人，按真实日期对齐
   - 我 + 伴侣：相识之后的格子高亮为"一起的周"
   - 我 + 孩子：孩子的第一格对齐到我人生中的某一格
6. **陪伴计算器（亮点）**：对父母，输入"一年大概见几次、每次几天"，算出剩余见面次数 / 天数，用格子或点阵画出来
7. **本地存储 + 导出导入**：IndexedDB，JSON 备份

### 第二版

8. **年轮海报**：年底生成一张当年 52 格的海报（颜色 + 高亮句子），可分享
9. **每周提醒**：PWA 通知，或生成日历订阅（.ics），每周日晚提醒写一句
10. **"送给 TA"**：把孩子的成长格子导出成一个可以分享的只读链接或长图——"你出生后的第 1 周到第 900 周"
11. **共写**：和伴侣共享同一个"我们"的格子（需要后端，后期再考虑）
12. **回顾**："一年前的今天这一周你写了……"

## 5. 页面结构（草图）

```
[首页 / 人物列表]
  我的格子  (大卡片，显示 "第 1,823 周 / 已填 312 周")
  孩子 · 小满  (第 87 周)
  另一半 · 阿洋
  爸爸 · 妈妈
  [+ 添加一个人]
  [对比视图]

[某人的格子图]
  顶部：名字 · 第 N 周 · 已活 X% (孩子的版本不显示百分比，改为"已陪伴 N 周")
  主体：52 × 90 的格子（可缩放），本周闪烁
  点击格子 → 底部弹出：日期范围、那周写的话、编辑

[本周记录]
  "这一周，用一句话记住它"
  输入框 + 颜色/emoji 选择 + [保存]

[对比视图]
  选择人物 → 多条格子图按日期对齐；重叠区域高亮
  父母卡片显示：剩余见面约 N 次
```

视觉方向：留白多、安静、温暖；格子是唯一的主角。不要做成冷冰冰的"倒计时"。

## 6. 技术方案（建议，开发会话可再定）

- **纯前端**，无需后端（MVP）
- Vite + TS；格子渲染约 90 × 52 ≈ 4700 个，建议用 **Canvas** 或单个 SVG，避免 4700 个 DOM 节点；需支持缩放和点击命中
- 存储：IndexedDB（可用 idb / Dexie），提供 JSON 导出 / 导入
- PWA：可加到桌面，离线可用，后期做通知
- 日期计算注意：周的定义（从生日那天起每 7 天一格，而不是自然周），时区，闰年
- 海报：Canvas 生成图片

数据模型草稿：

```ts
type Life = {
  id: string
  name: string
  relation: 'self' | 'child' | 'partner' | 'parent' | 'pet' | 'other'
  birthDate: string        // YYYY-MM-DD
  lifeExpectancyYears: number
  color: string
  meetPerYear?: number     // 父母：每年见几次
  daysPerMeet?: number
}

type WeekEntry = {
  lifeId: string
  weekIndex: number        // 从出生起第几周
  text?: string
  color?: string
  emoji?: string
  milestone?: string
  updatedAt: number
}
```

## 7. 情感与措辞边界（很重要）

这个产品碰的是"时间""衰老""死亡"，措辞稍不注意就会变成贩卖焦虑：

- **父母的格子**：不要显示"剩余 XX 周"这种死亡倒计时的字样，而是"还能再见约 N 次"——重点放在"见面"，并给一个行动按钮（如"去打个电话"）
- **孩子的格子**：不显示未来和百分比，只显示"已陪伴 N 周"
- **预期寿命**可调、可隐藏未来格子
- 整体语气：**珍惜，而不是倒计时**

---

## 8. 衡量是否成功

- 每周记录率（有多少人连续 4 周都写了）
- 平均每个用户添加的人数（多人扩展是否成立）
- 年轮海报 / 陪伴计算结果的分享率
