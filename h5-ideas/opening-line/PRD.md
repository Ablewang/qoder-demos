# 开口嘴替 · 粗略产品文档

> 状态：点子阶段 / 待开发
> 一句话：选好对象和场景，帮你生成那句最难开口的"第一句话"——社恐、宝妈、老人都用得上。

---

## 1. 这个点子是怎么来的

圆桌讨论里**得出的最重要洞察之一**是：**"最难的是开口说第一句话。"** 社恐的学生、带娃的妈妈、想孙子的爷爷、不会跟父母聊天的儿子，都卡在这一步。

这个点子由两个人的点子融合而来：

- **小鹿（20 岁，社恐大学生）** 提了"社恐嘴替小抄"：
  > "给奶茶加小料、找老师请假、拒绝学姐拉我进社团，每次都要在心里排练八百遍。"
  > 想法：选场景和紧张程度，生成三句话就能说完的台词卡；做到了攒勋章。
- **沈老师（心理咨询师）** 提了"开口卡"：
  > "一个抑郁的大学生，对着'在吗'删了十几遍，最后什么也没发出去。"
  > 想法：生成一句有温度、没压力的求助开头（"最近有点难，能陪我吃顿饭吗"），自己复制去发。

**在圆桌上，大家发现自己都需要它**：
- 林晓（二胎妈妈）："我最难的是跟老公说'今晚你带娃'，憋到最后就变成吵架。"
- 小鹿（亲戚防御塔讨论中）："我缺的不是怼人的话，是不尴尬的话。"
- 老周（67 岁）："给我一张'怎么跟孙子说想他了'。"

**评审意见**：
- 投资人老K发现：亲戚防御塔、社恐小抄、开口卡、爸妈话题盲盒，**本质是同一个"嘴替"引擎换不同场景**。
- 独立开发者阿木：难度低、惊艳度高。**MVP 先人工写 200 条模板，以后再接 AI。**最容易踩的坑是"台词太正确，不像真人说的话"。
- 圆桌公认第 3 名。

### 和"吵架翻译器"的关系

- **吵架翻译器**：已经有话想说，但说出来会伤人 → 帮你**换个说法**
- **开口嘴替**：有话想说，但**根本开不了口** → 帮你**说出第一句**

二者可以是同一个产品的两个入口（见文末待定问题）。

## 2. 场景库（按人群）

| 人群 | 场景举例 |
|---|---|
| 社恐 | 打电话订餐 / 跟老师请假 / 拒绝邀请 / 问路 / 退货 / 让室友小声点 |
| 职场 | 提加薪 / 拒绝加班 / 催同事进度 / 离职 |
| 伴侣 / 家庭 | "今晚你带娃" / 说"我需要一点自己的时间" / 先道歉 |
| 求助（沈老师的场景） | "最近有点难，能陪我聊聊吗" / 向朋友借钱 / 告诉家人自己在看心理医生 |
| 老人 → 晚辈 | "跟孙子说想他了" / "问儿子过年回不回" / 不想显得唠叨地关心 |
| 修复关系 | 好久没联系的老朋友 / 吵架后先开口 / 跟父母说"爱你" |

## 3. 核心流程

```
选对象（朋友 / 伴侣 / 父母 / 孩子 / 老师 / 领导 / 陌生人）
  ↓
选场景（或自己写一句"我想跟他说……"）
  ↓
选状态（我很紧张 / 有点尴尬 / 还好）
  ↓
得到一张台词卡：
  ┌──────────────────────┐
  │ 开场：……              │
  │ 正事：……              │
  │ 如果对方说不行：……      │
  │ 收尾（溜走）：……       │
  └──────────────────────┘
  [复制第一句] [换一个说法]
  ↓
（可选）说完回来点"我做到了" → 一枚勋章
```

---

## 4. 功能范围

### MVP

1. **200 条人工精写的模板**（阿木的建议），覆盖上面的场景
2. **台词卡**：开场 / 正事 / 被拒绝怎么接 / 收尾
3. **一键复制**第一句
4. **"我做到了"勋章墙**（小鹿："本周成功打电话 1 次，配文：妈我出息了"）——只存本地

### 第二版

5. **AI 自定义**：模板没有的场景，自由输入，AI 生成（要求像真人口语，不能有"我感到……我需要……"的心理学腔）
6. **老人模式**：大字体、语音输入（用手机输入法自带的语音转文字）
7. **勋章海报**：分享"本月我开口了 5 次"
8. **与吵架翻译器合并**

### 明确不做

- 不帮人写操控、PUA、欺骗性的话术
- 不代替用户发送——**一定是用户自己发出去**（沈老师：要把人"送回"真实的关系里，而不是留在屏幕里）

---

## 5. 求助场景的伦理边界（沈老师强调）

- 页面底部**固定放心理援助热线**
- 输入中识别到高危词（自伤、轻生等）时，**优先**展示专业求助资源，而不是只生成一句话
- 定位是"桥"，不是"岛"：沈老师原话——"它可以当一座桥，帮人走回真实的人际关系和专业帮助；不能变成一座岛，把人留在屏幕里。"

---

## 6. 技术方案

- MVP：**纯前端** + JSON 模板库，2~3 天可完成
- 勋章：localStorage
- 第二版 AI：后端代理调用大模型；高危词先用关键词规则兜底，再交给模型
- 若与吵架翻译器合并，共用同一个后端和 prompt 框架
