# 家族口述史"然后呢" · 粗略产品文档

> 状态：点子阶段 / 待开发
> 一句话：子女每周抽一个问题发给爸妈，爸妈按住说一分钟，孙辈可以按"然后呢"追问，一年后攒成一本家族有声书。

---

## 1. 这个点子是怎么来的

这是**两个人的点子在讨论中碰出来的**：

- **阿杰（29 岁，上海打工人）** 提了"爸妈话题盲盒"：
  > "和家里打电话，3 分钟就绕回催婚，然后双方都不说话了。"
  > 想法：每周抽 3 个话题（"爸，你第一份工资花在哪了"），回答存成金句卡。"我妈年轻时候的故事，我以前从来没听过。"
- **老周（67 岁，洛阳退休语文老师）** 提了"一分钟老故事"：
  > "我一肚子故事，没人坐下来听。"
  > 想法：每周录一分钟往事，孙子听完能按"然后呢"。"那个'然后呢'按钮，说明真有人在听。"

**在圆桌讨论里**，阿杰第一轮就选了老周的点子："我每周跟爸妈打电话就三句：吃了吗、身体好吗、挂了啊。要是能听我爸讲一分钟他年轻时候的事，'然后呢'我能按一百次。"于是两者合并：

- 阿杰的点子解决了**"不知道问什么"**（年轻人这一端）
- 老周的点子解决了**"没人听"**（老人这一端）
- 合在一起正好是一个闭环：**有人问 → 有人讲 → 有人追问 → 越讲越多**

**评审意见**：
- 投资人老K：推荐。"一年攒下一本家族有声书，年底印成书就有付费点。"风险是**子女三分钟热度**，改法是"由子女发起，老人那一端只留一个按钮"。
- 圆桌公认第 2 名。

**它为什么有意义**：老人走了以后，最后悔的往往是"从来没问过他年轻时候的事"。这个产品在还来得及的时候，把这些声音留下来。

---

## 2. 角色

| 角色 | 做什么 | 难度要求 |
|---|---|---|
| **发起人**（子女） | 创建家族空间，每周抽题发给老人，听回答 | 正常 |
| **讲述人**（父母 / 祖父母） | 打开链接 → 看到大字问题 → 按住说话 | **极简：只有一个按钮** |
| **听众**（孙辈、其他亲戚） | 听，按"然后呢"，提问 | 简单 |

---

## 3. 核心流程

```
子女：抽一个问题（或自己写）→ 发到家族群 / 私聊给爸妈
  ↓
老人：点开链接 → 大字显示"爸，你第一份工资花在哪了？" → 按住大按钮说 1 分钟
  ↓
全家：听到回答 → 可以按「然后呢」或者打字追问
  ↓
老人：下次打开，看到"有 3 个人想听然后呢" → 接着讲
  ↓
一年后：自动整理成按人生阶段排列的"家族有声书"
```

---

## 4. 功能范围

### MVP

1. **问题盲盒**：内置 200+ 好问题，按人生阶段分类（童年 / 求学 / 工作 / 恋爱结婚 / 养孩子 / 那个年代）
   - 例："你小时候最想当什么？""你和妈妈第一次见面是什么场景？""那年恢复高考你在干嘛？""你最后悔的一件事？"
2. **老人端：一页一个按钮**
   - 超大字号显示问题
   - 按住说话（或者点"我想打字"）
   - 不需要注册、不需要登录
3. **听众端**："然后呢"按钮 + 文字追问
4. **故事墙**：按时间线 / 人生阶段排列所有回答

### 第二版

5. **语音转文字**：自动生成文字稿，方便看
6. **年度家族书**：整理成精美的 H5 长页面或 PDF；可选付费印成实体书（带二维码，扫码听原声）
7. **金句卡**：从回答里挑一句话生成卡片
8. **多位老人**：爷爷奶奶、外公外婆都可以加入同一个家族

### 明确不做

- **不用 AI 模仿老人声音或生成"老人会怎么说"**（真实性是这个产品的全部价值）
- 不做公开社区，所有内容只在家族内可见

## 5. 技术方案与难点

这个点子**需要后端**（多人之间传递录音），阿木把它归为"需要录音 + 提醒，有难度"。

### 录音（最大的坑）

- 微信里打开的网页录音问题很多；用微信官方录音接口需要**认证公众号 + 备案域名**，单条最长 60 秒（正好对应"一分钟"）
- **MVP 的绕法**：
  - 方案 A：老人用**微信输入法 / 手机输入法的语音转文字**，说完自动变成文字（最简单，但失去原声）
  - 方案 B：标准浏览器录音（MediaRecorder），引导老人"用浏览器打开"（老人可能不会）
  - 方案 C：老人直接在微信里发语音给子女，子女转存上传（老人零学习成本，子女多一步）
- **建议**：MVP 先用方案 C 或 A 验证需求，原声录音放第二版

### 提醒（第二个坑）

- 网页发不了推送通知。**绕法**：不推送，让**子女在家族群里发链接**——提醒本来就是人做的事，这也更有人情味

### 其他

- 后端：存问题、回答（音频文件存对象存储）、"然后呢"计数
- 身份：家族空间用"邀请链接 + 口令"，不做账号体系
- 可选部署：Qoder Sites 后端 / melo-cli fun 项目

---

## 6. 风险

| 风险 | 应对 |
|---|---|
| 子女三分钟热度 | 每周只要抽一题，压力小；"然后呢"计数给老人正反馈，老人会反过来催子女 |
| 老人不会用 | 老人端只有一个按钮；或允许子女代为上传 |
| 问到敏感往事（饥荒、去世的亲人） | 问题库标注"温柔话题 / 深度话题"，深度话题先提示"可以跳过" |
| 隐私 | 家族私有空间，不公开、不做推荐 |
