## 0. 一页速览

| 项 | 方案 |
|---|---|
| 玩法 | **八问回合制饭桌卡牌**：一次一道问题，四句完整回答，每问选一次，无计时、冷却或自动刷题 |
| 4 种卡 | 太极无限挡 1 / 反问 2 张挡 3、下一问追问 +1 / 真心 2 张普通挡 2、直球挡 1、下一问帮腔 −1 / 发疯 1 张全挡、自耗 1 格 |

### 历史草案的 6 个选项（已被第 9 节的本地执行范围覆盖，不等待这些选择）

1. 玩法形态：A 卡牌 + 轻塔防（推荐）/ B 纯回合制卡牌 / C 经典塔防
2. 美术风格：A 年画剪纸 Q 版（推荐）/ B 像素风 / C 手绘表情包风
3. 音效：A 音效 + 背景音乐（推荐）/ B 只要音效 / C 都不要
4. **域名与托管：你手上有没有已经备案的域名？** A 现有域名托管 / B 新办备案 / C 海外静态托管先验证（审核时长不保证，先确认现有条件）
5. 数据统计：A MVP 不接第三方、先做受邀试玩（推荐）/ B 后续明确隐私边界再接匿名统计
6. 「实战小抄」是否作为加分项塞进 MVP（推荐：时间够就做，几乎零成本）

## 1. PRD 待定问题逐条回答

### 1.1 玩法："塔防"还是"卡牌对战"？

**推荐：A「卡牌 + 轻塔防节奏」的混合形态。**

- 不做"摆塔、修路线"：竖屏手机上没地方摆，而且玩家需要**读字**（题库笑点全在文字里），一边读字一边摆塔太累。
- 也不做纯回合制：PRD 里"工资多少冲得很快"这种**压迫感**是笑点之一，回合制就没了。
- 混合方式：问题气泡带倒计时，沿着饭桌往你的碗移动（塔防的"怪物沿路线走"）；你只需要点卡出招（卡牌的简单操作）。同时最多 3 个问题在桌上，形成"被围攻"的感觉。

| 选项 | 优点 | 缺点 | 工作量 |
|---|---|---|---|
| **A 卡牌 + 轻塔防（推荐）** | 有压迫感、操作只有点卡、好截图 | 需要调节奏数值 | 基准 |
| B 纯回合制卡牌 | 最简单、长辈也能玩、读字从容 | 紧张感弱，玩一次就腻 | 约少 3 天 |
| C 经典塔防 | 游戏性最强 | 竖屏难做、文字被弱化、工期超 | 约多 7~10 天，赶不上腊月 |

### 1.2 美术风格？

**推荐：A「年画 / 剪纸感的 Q 版扁平风」**：红金主色、圆头大眼、亲戚都长得**和善可爱**（不丑化、不夸张丑态——这是"不冒犯长辈"在美术上的落实）。

| 选项 | 说明 |
|---|---|
| **A 年画剪纸 Q 版（推荐）** | 最喜庆、和春节最搭、AI 出图后容易统一风格；海报放进朋友圈也好看 |
| B 像素风 | 好做、有怀旧梗，但喜庆感弱，像"又一个小游戏" |
| C 手绘表情包风 | 最好笑，但长辈形象容易显得被嘲讽，和"化解"的立意冲突 |

产出清单：8 位亲戚 × 3 个表情（发问 / 生气 / 变队友时笑）= 24 张立绘，加饭桌、菜品 3 道、玩家背影、海报底图、称号印章。做法：AI 按统一提示词出图 → 人工挑选、统一描边和配色 → 切图导出 WebP。

### 1.3 要不要音效？

**推荐：A 要，音效 + 一段短背景音乐；首次默认静音，右上角常驻声音键，主动开启后才播放，并记住本机选择。**

- 音效 7 个：筷子碰碗（出卡）、鞭炮（暴击）、碰杯（真心化解 / 队友挡下）、叹气（被问住）、锣（上菜 / 换波）、瓷碗"咣当"（发疯翻车）、红包"叮"（奖励）。
- 背景音乐：一段 30 秒民乐循环，**只用免版权素材或自制**，不用《恭喜恭喜》等有版权的歌。
- 一个真实场景：很多人会**在饭桌上偷偷玩**，所以静音键必须一眼能找到，并记住用户选择。
- 微信要求用户先点一下才能出声，首页的"开席"按钮就是解锁点（见 2.6）。

### 1.4 上线时间节点倒推排期

依据[香港天文台 2027 年公历与农历日期对照表](https://www.hko.gov.hk/tc/gts/time/calendar/pdf/files/2027.pdf)逐格核实：2027 年腊月初一 = 1 月 8 日，**腊八 = 1 月 15 日**，北方小年（腊月二十三）= 1 月 30 日，南方常见小年（腊月二十四）= 1 月 31 日，**除夕 = 2 月 5 日**（腊月二十九），春节 = 2 月 6 日；不据此推断法定放假安排。

PRD 写的是“1 月中旬腊月前”，但严格的腊月前应在 **1 月 7 日结束前**上线，因此以更早日期执行：**1 月 7 日正式上线，1 月 15 日仅为已经错过腊月前要求的应急止损线，不算按时达标。** 首局目标仍为 2~3 分钟，12 月底前必须可玩。详细排期见第 4 节。

### 1.5 其他我顺手定下的小问题（不需要你拍板，有意见可以改）

| 问题 | 决定 | 理由 |
|---|---|---|
| 要不要"选身份" | **做**，4 个：未婚打工人 / 已婚未育 / 刚毕业 / 考研考公中 | 决定题目和 Boss，代入感强，成本只是题库打标签 |

| 游戏名 | 保持「过年亲戚防御塔」 | 已有传播辨识度，"防御塔"是梗，不需要严格塔防 |
| 屏幕上的称呼 | 叫"问题"不叫"怪物" | 老周的意见：亲戚不是怪物，只有问法有点猛 |

## 2. 技术方案

### 2.1 技术栈

| 层 | 选型 | 理由 |
|---|---|---|
| 构建 | Vite + TypeScript | PRD 指定；冷启动快 |
| 依赖管理 | **pnpm** | 用户指定 |
| 游戏画面 | **原生 DOM + CSS 动画（Web Animations API）** | 本游戏核心是中文文字（换行、字号、点击区），DOM 天然擅长；画面上最多 8 个人物 + 3 个气泡，性能毫无压力。PixiJS 会多 100KB+ 且要自己处理中文排版，不划算 |
| UI 框架 | 不用 | 只有 6 个页面，自写一个页面状态机就够，首包更小 |
| 战报海报 | Canvas 2D 手绘 | 见 2.5，比 html-to-image 在微信里稳定得多 |
| 二维码 | `qrcode`（npm 包） | 运行时生成，方便带渠道参数 `?from=poster` |
| 测试 | Vitest | 游戏引擎是纯逻辑，可以完整单测 |
| 题库校验 | `tsx` 跑一个校验脚本 | 检查字段齐全、字数上限、敏感词 |
| 部署 | 静态托管 + CDN（见 2.6 域名部分） | 无后端 |

运行时依赖仅计划使用 `qrcode`；开发依赖 `vite`、`typescript`、`vitest`、`tsx`，二维码类型声明按选定版本需要再加。已有 Node.js 24 环境，pnpm 锁定依赖并提交唯一的 `pnpm-lock.yaml`，不混用 npm/yarn 锁文件，不预先批准全部安装脚本。

确认后准备的命令接口：`pnpm install` / `pnpm dev` / `pnpm typecheck` / `pnpm test` / `pnpm validate` / `pnpm build` / `pnpm preview`；发布门槛为类型、测试、题库校验、生产构建全部通过。本阶段仅记录接口，**不安装依赖、不创建脚手架、不部署**。

### 2.3 核心模块

**引擎（engine）** 是整个项目的心脏，设计成"状态 + 推进函数"：

```ts
type CardType = 'taiji' | 'counter' | 'crazy' | 'sincere';

interface ActiveQuestion {
  uid: number;            // 本局内唯一
  qid: string;            // 题库 id
  askerId: string;        // 哪位亲戚问的
  hp: number; maxHp: number;
  patienceLeft: number;   // 秒，归零 = 冲到碗里 = 被问住
  patienceMax: number;
  progress: number;       // 0~1，UI 据此算气泡在桌上的位置
}

interface BattleState {
  phase: 'intro' | 'wave' | 'reward' | 'boss' | 'end';
  wave: 0 | 1 | 2;
  mood: number;                         // 心态值 0~100
  charges: Record<CardType, number>;    // 太极为 Infinity
  taijiCooldown: number;
  lockTimer: number;                    // 出卡后 0.5 秒动画锁
  pauseTimer: number;                   // 发疯暴击"全桌安静"时冻结倒计时
  active: ActiveQuestion[];             // 桌上的问题（最多 3 个）
  targetUid: number | null;             // 当前要回应的问题，默认最急的
  angry: Set<string>;                   // 被激怒的亲戚
  allies: { relativeId: string; used: boolean }[];
  flopStreak: number;                   // 连续翻车次数（保底用）
  score: number;
  log: BattleEvent[];                   // 全部事件，战报从这里统计
}

step(state, dt): BattleEvent[]          // 每帧推进：倒计时、刷题、超时、队友拦截
playCard(state, type): BattleEvent[]    // 出卡结算
```

- 渲染层每帧调用 `step`，拿到事件后播放动画和音效；**引擎不知道 DOM 的存在**，所以可以用种子随机数写单测。以上类型是接口草图，真正开工时还要记录 `pendingQuestions`（待上桌队列）、`spawnTimer`、本局种子、剩余配额与下一波抵消激怒次数；当前阶段不实现它们。
- 切到后台（`visibilitychange`）时自动暂停。帧时间增量限幅，避免后台回来一次扣掉几十秒；用户主动暂停也冻结所有战斗时钟。
- 抽题：每局固定 **4 + 5 + 4 = 13 个常规问题**（其中第 2 波恰有 1 道暖心题）与 1 个身份 Boss。优先使用本机最近 3 局没出现过的题；本局同题不重复，追问用独立题池不占 13 题配额；方言彩蛋整局出现概率 30%，不是要求每局必有。
- 普通问题不从奶奶处发出，队友不能被选为后续发问者。如果预抽题的 `askers` 全是队友，则重新抽符合身份的其他题 / 亲戚，不减少该波题数；同波尽量不重复亲戚，但候选不足时允许重复，不能卡死。Boss 固定由虚拟目标 `table`（全桌）发问，不作为可结盟角色。
- 桌上达到该波并发上限时停止新增，追问排到队首；有空位后才能进入。暴击冻结期间，问题倒计时和刷题时钟一起暂停；出卡动画锁仅禁止下一次出卡 0.5 秒，不冻结战斗。
- **本波配额已发完且桌面 / 追问队列清空**后才换波；奖励出现时战斗暂停，5 秒无人选默认喝汤。Boss 开始前清空桌面，单独出现且不可被队友拦截。活跃时间约 2~3 分钟，教学、后台暂停不计入；最迟 180 秒活跃时间时鸣锣收席，仍在桌上或未发出的题记为“未作答”（0 分，不额外扣心态），禁止零失误奖励，然后结算，避免追问无限拉长。
- 抽题、随机结果、得分都写入事件日志。允许重新开局，不做服务器验分、排行榜或“全国百分位”，本地随机成绩只是娱乐。

### 2.4 数据结构（题库 JSON）

**问题**（`questions/love.json` 等，数组）：

```json
{
  "id": "love-001",
  "category": "love",
  "kind": "normal",
  "askers": ["sangu", "wangayi"],
  "for": ["single"],
  "text": "有对象没？",
  "dialect": { "region": "湖南", "text": "有对象冇？" },
  "stats": { "hp": 2, "patience": 12, "hit": 12 },
  "answers": {
    "taiji":   ["在找了，月老说我的单子在排队，前面还有好几亿人。", "这个话题先盖盖子，我先替您把菜夹到碗里。"],
    "counter": ["{asker}，您介绍对象也排号吗？我能线上取号不？"],
    "crazy":   ["有了！我和 KPI 同居三年，感情稳定，就是它不让我下班。"],
    "sincere": ["{asker}，我知道您惦记我。遇到合适的我会告诉您，先不着急。"]
  },
  "react": {
    "counter": "……你这孩子，吃菜吃菜。",
    "flop": "你这孩子说的啥胡话？那到底有没有嘛！"
  },
  "allyLine": "行，那姑等着！来，吃个鸡腿。"
}
```

字段说明：

| 字段 | 说明 |
|---|---|
| `kind` | `normal` 普通 / `fast` 快题 / `tough` 难缠 / `warm` 暖心（奶奶式纯关心）/ `boss` 全桌齐问 / `followup` 翻车追问 |
| `askers` | 可以问这题的亲戚，抽题时随机挑一个；`{asker}` 占位符会替换成称呼 |
| `for` | 适用身份；`["all"]` 表示所有身份 |
| `dialect` | 可选；出现时随机 30% 用方言版文本，气泡上标"方言" |
| `stats` | 可选，不写就用 `kind` 的默认值（见 3.4） |
| `answers` | **4 类必须齐全**；太极建议 2 条（同一题出两次太极时轮换，不够用 `fillers.json` 通用台词） |
| `react` / `allyLine` | 可选，不写用 `relatives.json` 里该亲戚的通用台词 |

**题库数量目标：72 题**，其中常规 + 暖心题 64 道（满足 PRD 至少 60 题），身份 Boss 4 道，翻车追问 4 道。婚恋 10 / 收入 8 / 生育 6 / 买房 8 / 考学 8 / 比较 8 / 工作 10 / 暖心 6 / Boss 4 / 追问 4，按 10 个文件组织。初稿通过身份标签交叉覆盖，每个身份的可选主题池 ≥ 40 道（包括暖心题）；本局仍只抽 1 道暖心题与 1 道身份 Boss。

每题 4 类回答至少各 1 条（72 × 4 = 288 条），太极再加至少 1 条备选，共 ≥ 360 条；另有约 12 条通用太极台词与每位亲戚 3~4 条反应台词。示例区只展示每类 1 条，正式生产再补备选。

**校验脚本**（计划为 `pnpm validate`）检查：id 唯一、4 类回答齐全、每种数组非空、`kind` / 分类 / 身份合法；问题 ≤ 16 字、回答在 `{asker}` 替换后 ≤ 32 字（Unicode 字符含标点，排版仍需真机验证）；血量 1~5、耐心 8~18 秒、心态伤害 0~30；真人角色 id 必须在名册中，只有 Boss 允许虚拟发问者 `table`。`stats` 缺失按类型默认值，部分覆盖字段逐项与默认值合并。6 类主话题最低配额、身份主池 ≥ 40、72 题总量都作为发布前硬检查。

敏感词命中只作为人工复核提示，不能替代语境审阅；问题本身允许出现“生孩子”“催婚”等敏感场景，禁止的是歧视和人身攻击。每题至少两位不同的人读完整四卡，尤其检查反问是否把同样的压力丢给另一位家人。

### 2.5 战报海报生成方式

**用 Canvas 2D 手绘，不用 html-to-image。** 后者在微信里经常遇到字体丢失、跨域图片画不出来、iOS 偶发白图，调试成本高。

- 尺寸：**1080 × 1440（3:4）**。朋友圈单图对过长的图片会裁切预览，3:4 能完整显示；称号和"能活几天"放在画面中部，即使被裁也能看到。
- 绘制顺序：底图（美术预先做好的红金背景 + "2027 春节 · 亲戚防御战报"标题字，标题直接画在图里，省掉字体问题）→ 3 行战绩 → 称号印章（大字）→ 签文评级 + "今年过年能活 X 天" → 本局金句 → 右下角二维码 + "长按识别：你能撑几天？" → 底部小字"防的是盘问，不是亲情；不想回答也没关系"。
- 字体：动态文字用系统字体（苹方 / 思源黑体 / 微软雅黑）；称号用一个书法字体的**子集**（只包含所有称号用到的约 60 个字，约 30KB），绘制前用 `FontFace.load()` 确保加载完成。
- 二维码：`qrcode` 生成，**黑白高对比、带留白、边长 ≥ 220px**，不要做成红底或加花样，否则微信识别率下降。
- 导出：`canvas.toDataURL('image/jpeg', 0.9)`（约 200~400KB）→ 塞进全屏 `<img>`，提示"长按图片保存，发朋友圈"。**不用下载链接**（微信里点下载没反应）。dataURL 和 blob URL 都要真机试，哪个稳用哪个。
- 所有图片同域加载，避免 Canvas 被"污染"导致无法导出。
- 海报模块（含 qrcode）用动态 `import()` 懒加载，不占首屏。
- **金句可换**：结算页默认挑一句（优先暴击的发疯台词或真心台词），玩家可点“换一句”在本局实际播放的台词里轮换。换句只改变海报文案，不改变分数或日志。
- 二维码必须使用确认后的**正式 HTTPS 游戏入口（含部署路径）+ 固定 `from=poster` 参数**，不能从当前测试页 URL 直接复制，不能留下 localhost 或预览域名。二维码版本与纠错选 M，保留 4 模块白色边距。
- 导出前等待同域图片与字体解码完成；书法字体需要可商用授权，30KB 是子集目标不是保证。图片或字体失败时给出重试入口；字体不可用可明确以系统字体生成，不能把空白图显示成成功海报。
- `<img>` 使用可长按保存的图片内容，微信内优先测试 dataURL；blob URL 的行为因平台而异，只有通过同样真机验收才采用。海报页不锁全页触摸、不拦截长按，保留返回游戏和“在系统浏览器打开”说明（不强制调用原生分享）。

### 2.6 微信内置浏览器适配要点

**不依赖微信 JS-SDK**（没有公众号），所有绕法都按"没资质"设计。

| # | 坑 | 处理 |
|---|---|---|
| 1 | 声音必须用户点击后才能播 | 首页"开席"按钮点击时 `AudioContext.resume()` 并播放一段静音以解锁；音效用 Web Audio 预解码（延迟低），背景音乐用 `<audio>`；iOS 静音键会让 Web Audio 无声，属正常 |
| 2 | `100vh` 不准，底部被遮挡 | 用 JS 写入 `--app-height = window.innerHeight`，监听 resize；`viewport-fit=cover` + `env(safe-area-inset-bottom)` |
| 3 | iOS 微信页面跳转后出现底部前进/后退栏，挤压画面 | **全程单页，不改 URL、不用 `history.pushState`** |
| 4 | 安卓微信"字体大小"设置会放大页面文字，卡面溢出 | `-webkit-text-size-adjust: 100%`；`WeixinJSBridge` 就绪后调用 `setFontSizeCallback({fontSize: 0})` 并监听 `menu:setfont` 重置 |
| 5 | 下拉露出"网页由 xxx 提供"、页面回弹 | 根容器固定定位、`overscroll-behavior: none`，阻止游戏区 `touchmove` 默认行为 |
| 6 | 点击延迟、双击缩放、长按弹菜单 | `touch-action: manipulation`；游戏区 `user-select: none` + `-webkit-touch-callout: none`；**海报 `<img>` 例外**，必须允许长按 |
| 7 | 切出微信（看消息）时游戏继续跑 | `visibilitychange` 暂停战斗和音频，回来显示"继续吃饭"按钮 |
| 8 | 微信缓存很凶，更新题库后用户看不到 | `index.html` 设 `Cache-Control: no-cache`；其他资源带哈希文件名、长缓存 |
| 9 | 域名在微信里被提示"非微信官方网页"或拦截 | 用**国内已备案域名 + 国内 CDN**；页面和海报**不出现诱导分享文案**（"分享给 3 个好友解锁"之类违反微信外链规范），"你能撑几天？"这类问句没问题；游戏里的"奶奶塞红包"只是道具，不涉及真钱 |
| 10 | 横屏 | 检测到横屏时显示"请竖着拿手机，像在饭桌上偷玩那样" |
| 11 | 兼容范围 | iOS 14+、安卓 8+；微信内核（XWeb）、Safari、系统 Chrome 都要过一遍 |

**关于域名（需要你确认，见第 0 节第 4 条）：**

| 选项 | 说明 |
|---|---|
| A 已有备案域名（推荐） | 可选现有静态托管，或二级域名 + OSS/COS + CDN；需域名持有人确认、HTTPS 与缓存配置，费用按实际访问流量计算 |
| B 没有备案域名 | 先确认是否走国内备案路线；材料、接入服务商和审核可能需要数周，不能承诺 1~3 周必过。方案确认后尽早启动，并保留 12 月初复核节点 |
| C 先用海外静态托管 | 可用于内测，国内速度、微信可访问性都需真机验证；不把海外托管或已有备案当作“不被拦截”的保证 |

纯静态不等于零成本：1.5MB 资源 × 10 万次完整冷加载约 150GB 出站量（未计缓存与海报本地导出节省），流量预算和告警需在推广前确认。不新建无关的服务器，不承诺可以借用他人的域名。

### 2.7 数据统计与隐私（需要用户确认）

**推荐 MVP 不接第三方统计**：无登录、无投稿、无照片上传、无需填写收入或家乡；身份卡只是剧情选择，可随便选。本机仅记录静音偏好、教学完成、最近题 id 和个人最高成绩；存储不可用时仍可开局，不恢复半局存档，不做跨设备同步。

没有后端时，网页**不能确认实际截图、保存到相册或朋友圈发布**。首轮用 10 人受邀测试记录完局人数、愿不愿保存战报、实际扫码是否成功；例如 10 人有 6 人表示保存就是“本组 6/10”，不能称全站截图率。保存意愿不是“好笑”的唯一标准，还要听到哪句使玩家笑了。

| 待选择 | 好处 | 代价 |
|---|---|---|
| A 不接第三方（推荐） | 保持纯本地内容与最小隐私负担，不新增服务器或追踪脚本 | 没有全站漏斗数据，只能靠受邀测试和托管流量计数 |
| B 后续接第三方匿名事件统计 | 可看开局 / 完局 / 海报生成漏斗 | 浏览器环境、IP 等可能被服务商处理，需要隐私说明与服务商核对；只有明确确认后再设计接入 |

若选 B，仅报告聚合事件 `open`（固定渠道枚举）、`start`、`game_end`（分数段）、`poster_make`、`replay`；不上传每句台词、个人标识、精确时间线、原始 URL。长按最多记为“尝试长按”，**不是保存成功**；统计加载失败不能阻断游戏。`platform/analytics.ts` 只有在选 B 时才需要创建，不提前造开关或适配框架。

### 2.8 性能预算

- 首屏（首页可交互）：JS ≤ 60KB（gzip），首屏总下载 ≤ 400KB。
- 全部美术 + 音效 ≤ 1.5MB，首页显示时后台预加载，点"开席"时已就绪。
- 图片全部 WebP（iOS 14+ 支持）。

### 2.9 测试与上线验收（开发完成后执行）

- 引擎单测：四卡结算、伤害先于激怒、奶奶豁免、消气不结盟、暖心返卡上限、Boss 最后一击计分、队友不能拦 Boss、满桌追问排队、翻车保底、零真心高分不获上上签、暂停 / 180 秒收席、互斥结算和真实战报。
- 内容：`pnpm validate` 每次改题库都跑；发布前常规 / 暖心题 ≥ 60、身份标签覆盖过关，十题示例不是整库交付。
- 真机：iPhone 微信与 Safari、至少两类 Android 微信与系统 Chrome，含一台较旧千元机。验 320px 宽屏、短屏、刘海 / 底部安全区、大字体、横屏、静音开启、后台停留 30 秒再回来、特殊卡耗尽、快速连点、生成海报时失败 / 重试。
- **发布阻断项**：四个身份都能首次开席 → 正常结束或离席 → 结算 → 生成图片 → 长按保存到相册；另一个设备从保存的海报扫码打开正式游戏并完整玩一局。iOS 微信、Android 微信两条链都必须通过，不能只说“桌面浏览器图片正常”。
- 连玩三局测试题目重复感与台词可读性；受邀 10 人（包括至少两位长辈）完成语气审核。记录活跃时长，目标中位数 120~160 秒；看不完四卡或短屏遮住手牌就是阻断问题。
- 性能数字和截图意愿均为待测目标，当前只有方案，没有启动开发服务器或完成浏览器验收。

### 3.4 数值规则

**问题默认数值**（按 `kind`，单题可覆盖）：

| 类型 | 血量 | 倒计时（秒） | 被问住扣心态 | 说明 |
|---|---|---|---|---|
| normal 普通 | 2 | 12 | 12 | |
| fast 快题 | 2 | 9 | 15 | 工资、年终奖这类"冲得快"的 |
| tough 难缠 | 3 | 13 | 15 | 介绍对象、拿别人比较 |
| warm 暖心 | 1 | 14 | 0 | 奶奶式纯关心；超时 0 分、不扣心态，不计盘问失误，不用让玩家背内疚感 |
| followup 追问 | 1 | 8 | 8 | 发疯翻车后亲戚追加的一问 |
| boss 全桌齐问 | 5 | 18 | 30 | 每局 1 个 |

**玩家初始**：心态 100；太极无限；反问 3 张；发疯 3 张；真心 2 张。每次出卡后有 0.5 秒动画锁，防止连点。

**4 种回答卡规则：**

| 卡 | 次数 | 伤害 | 效果 | 定位 |
|---|---|---|---|---|
| **太极** | 无限，冷却 2.5 秒 | 1 | 无副作用 | 保底输出；只靠太极打不过同时来 3 题的局面 |
| **反问** | 3 张 | 3 | 当前问题先承受伤害，再**激怒**该亲戚：仅后续新问题血量 +1、倒计时 ×0.75。激怒不叠加；奶奶 `neverAngry` 豁免。对 Boss 施加相同伤害并激怒仍在桌上的非队友、非奶奶亲戚，但不追溯增强当前 Boss | 爽，但会把后续局面打难 |
| **发疯** | 3 张 | 随机 | 40% **暴击**：伤害 3 + "全桌安静 3 秒"；35% **普通**：伤害 2；25% **翻车**：伤害 0、心态 -10、该亲戚激怒（奶奶豁免），产生 1 个追问加入队列。连续翻车 2 次后下一次必暴击；任一非翻车结果清零计数 | 随机制造节目效果，无付费、无抽奖 |
| **真心** | 2 张 | — | 消耗 1 张，无视普通题血量、心态 +8，并按下表结算消气、结盟；最高评级要求真实化解和队友拦截，不只要求分高 | 化解最优，但不要求玩家无限让步 |

**真心卡例外结算表（只应用一行，不重复加分）：**

| 目标出卡前的状态 | 问题结算与得分 | 心态 / 返卡 | 结盟与计数 |
|---|---|---|---|
| 普通 / 快题 / 难缠 / 追问，亲戚未生气 | 清除该题，化解 +250 | +8 | 亲戚成为队友，真实化解数 +1；同一亲戚全局至多结盟一次 |
| 上述题型，亲戚已生气 | 清除该题，消气 +100（不再算普通挡下 +100） | +8 | 清除激怒，但本次不结盟、不计真实化解；将来再遇到该亲戚可正常结盟 |
| 暖心题（奶奶） | 清除该题，化解 +250 | **总计 +20**；先扣 1 张再返 1 张，净次数不变 | 奶奶结盟，真实化解数 +1；每局恰好 1 个暖心题，不能刷返卡 |
| Boss，出卡后血量仍大于 0 | 对 Boss 造成 3 点感化伤害，暂不计通关分 | +8 | 清除在场非队友亲戚的激怒，不结盟、不计真实化解 |
| Boss，真心为最后一击 | 清除 Boss，全桌化解 **+500** | +8 | 真实化解数 +1，无新增队友；不要逐个亲戚重复算次数 |

如果 Boss 最后一击是太极、反问或发疯，即使之前用过真心，也只算普通挡下 +100（发疯暴击另 +50）。所有心态恢复不超过 100；所有特殊卡次数最多 5。出卡判定使用点击瞬间的目标与台词，避免目标切换后播放错文案。

**队友规则**：每位队友全局有 1 次拦截机会，按结盟先后顺序替你拦下下一道新普通 / 快题 / 难缠 / 追问。Boss 与暖心题不可拦截；拦截也不消耗玩家卡。拦截用真实队友台词呈现，不需要问答。该亲戚已在桌上的其他气泡继续计时，不能因结盟自动消失。

**上菜间隙奖励池**（随机出 3 个选 1，每次必含“喝口热汤”和“真心 +1”，第三项随机）：喝口热汤（心态 +20）/ 奶奶的好运卡（真心 +1，仅游戏道具）/ 表弟递来手机（发疯 +1）/ 爸爸使了个眼色（反问 +1）/ 起身去盛饭（下一波开始后的首个新问题延迟 5 秒，不影响已在场问题）/ 妈妈帮腔（下一波第一次触发激怒时抵消一次）。

**计分：**

| 事件 | 分数 |
|---|---|
| 挡下一题（血量打空） | +100 |
| 暴击（额外） | +50 |
| 真心化解 | +250（Boss +500） |
| 队友拦下一题 | +150 |
| 被问住（暖心题除外） | -50 |
| 暖心题超时 | 0 |
| 对生气亲戚用真心消气 | +100（不叠加挡下或化解分） |
| Boss 真心部分感化 | 0（等最后一击判定） |
| 发疯翻车 | -30 |
| 结算：剩余心态 | × 3 |
| 结算：零被问住、无未作答且完整吃完三道菜与 Boss（滴水不漏） | +200 |

每题结算互斥：挡下 / 真心化解 / 真心消气 / 队友拦截 / 被问住 / 暖心超时 / 未作答只能记一种。暴击 +50、翻车 -30 与心态加扣可另外记录；没有对应事件就不能写战报。

真心卡本身不再加“挡下分”，但正常化解 250 + 后续队友拦截 150，**若队友确实用出了拦截**，单张真心的分值为 400。高评价门槛与这个收益一起鼓励化解；临近 Boss 才结盟未必能用出拦截，不承诺每张真心必得 400 分。

### 3.5 "今年过年能活几天"与签文评级

先从日志汇总分数与打法，再判定称号和签文，最后显示天数：

- 心态归零（离席）：**0.5 天、下下签**（"借口去厨房，顺便偷吃一盘饺子"）。不把离席解释成玩家不孝或真的与亲戚断交。
- 非离席时：先算 `基础天数 = 1 + 6 × max(总分, 0) / 1800`，四舍五入到 0.5，限制在 1~7 天。
- **上上签的全部条件**：非离席、13 个常规问题与 Boss 均已结算（Boss 挡下或化解）、总分 ≥ 1800、真实真心化解 ≥ 3、队友实际拦截 ≥ 2。满足时天数为 7，称号必为“家族和平大使”，彩蛋“7 天，还想住到元宵”。
- 不满足上述全部条件时，**即使零真心全挡拿到高分，天数也最多 6.5、评级最多上签**；玩法可爽赢，最高评价只给化解。
- 7 天只是游戏的娱乐刻度，**不表示 2027 年官方假期天数**，也不是生存、心理健康或家庭关系预测。
- 常数 1800 在试玩后按真实分布调整，目标是中位数约 4 天、最高评级约 5%~10%；这只是调参目标，不是已测得数据。

| 签文 | 条件（按上述门槛处理后） |
|---|---|
| 上上签 | 7 天，且全部化解门槛满足 |
| 上签 | 5.5~6.5 天 |
| 中签 | 3.5~5 天 |
| 下签 | 1.5~3 天 |
| 下下签 | 1 天及以下（含离席） |

### 3.6 称号规则

称号看**打法风格**，签文看**成绩**，两者都上海报。按优先级从上往下判定，命中即止：

| 优先级 | 称号 | 条件 | 海报一句话 |
|---|---|---|---|
| 1 | 厨房洗碗避难者 | 心态归零离席 | 顶不住了，我去刷碗了。 |
| 2 | **家族和平大使**（最高荣誉，金色印章） | 真心化解 ≥ 3 且队友拦截 ≥ 2 | 一句真心话，二舅当场倒戈。 |
| 3 | 发疯艺术家 | 暴击 ≥ 3，或发疯是出得最多的特殊卡且 ≥ 3 次 | 精神状态，遥遥领先。 |
| 4 | 反问刺客 | 反问 ≥ 3 次且是出得最多的特殊卡 | 问我之前，先过我这关。 |
| 5 | 太极宗师 | 太极出卡占比最高且被问住 ≤ 1 | 四两拨千斤，三姑拿我没辙。 |
| 6 | 埋头干饭王 | 被问住 ≥ 4 | 问啥都不知道，菜是真好吃。 |
| 7 | 年夜饭幸存者（兜底） | 以上都不满足 | 活着吃完了这顿饭。 |

**副标签**（满足就加，海报最多显示 2 个）：零翻车 / 滴水不漏（零被问住）/ 一句话让全桌安静（触发过暴击冻结）/ X 舅最疼的孩子（某亲戚成为队友，用亲戚称呼）/ 和奶奶最亲（暖心题用了真心）/ 一张反问都没出。

### 3.7 战报文案生成规则

从战斗日志里统计，生成最多 3 行"战绩"：

1. **挡得最多的一类**：从实际由玩家挡下的事件按 `(亲戚, 分类)` 分组，取最大组：`挡下{亲戚}{动词} ×{次数}`。分类动词：婚恋→催婚、收入→问工资、生育→催生、买房→问房、考学→问成绩、比较→拿我比较、工作→聊工作。不能把不同亲戚的次数全写在三姑名下。
2. **真心**：按实际化解事件写 `真心化解 ×{次数}，{亲戚A}、{亲戚B}来帮腔`；名字只能取实际结盟者。只有 Boss 化解时写“全桌碰杯 ×1”；仅消气不写成感化或队友。
3. **高光**：暴击次数与反问实际挡下次数谁大写谁：`发疯文学暴击 ×{n}` 或 `反问挡下盘问 ×{n}`。反问没有全桌安静效果，不能编造。零高光则写“队友拦截 ×n”或“埋头夹菜，心态剩 n”。

再加：称号 + 一句话、签文、娱乐天数、本局金句、二维码。金句只能选本局实际播放过的台词；没有出卡时用明确标为“桌边小提示”的通用句，不假冒玩家回答。海报上**不出现任何真实姓名、工资、家乡或用户填写的私人信息**；所有数量来自本局日志，不生成全国排行或击败百分比。

## 5. 题库语气标准与示例

### 5.1 语气标准

**总原则：笑点落在问法和自己的处境，不攻击亲戚本人，也不把压力转给表哥表姐。**

| 卡 | 写法 | 禁区 |
|---|---|---|
| 太极 | 不正面交代隐私，俏皮转到吃饭、排队、日常生活 | 冷漠贬低，不把无限敷衍描述成人际万能解 |
| 反问 | 用小事、爱好、喜庆话题换一个问题，如包饺子、年会、点菜、介绍对象的“排号流程” | 不问工资、病、别人的生育或成绩，不揭伤疤、不拿第三个人挡枪 |
| 发疯 | 自嘲 + 荒诞，比喻自己的 KPI、收藏夹、试吃员身份；现实中可能只适合熟悉的关系 | 脏话、人身攻击、地域黑、羞辱长辈，不把精神疾病当梗 |
| 真心 | 接住善意（合适时）+ 一点近况 + 温柔而明确的边界 / 给台阶；允许“不说收入”“暂不讨论生育” | 不强迫承认一切盘问都是关心，不强迫披露、许诺结婚生育或讨好长辈 |

**全局禁区**：外貌身材、疾病生死、不孕不育、离婚丧偶、性取向暗示、学历与地域歧视、真实人物或公司负面、政治。催婚 / 催生本身是题材，不等于可以拿别人的婚姻、生育开刀；医疗建议不进题库。
**字数**：问题 ≤ 16 字，回答 ≤ 32 字（含标点与替换后的称呼），卡面最多 3 行。超过显示能力必须改短，不能用省略号藏笑点。
**检验标准**：①是否好笑或好用；②真心句是否真的说得出口并保留界线；③年轻试玩者与至少两位长辈审阅者是否都觉得被尊重。有人明确觉得受冒犯就改，不用“一定是爱你”替内容辩护。

这里的“激怒”与“队友”是轻喜剧数值表现，不是现实亲戚反应预测；不想答的问题可以用边界卡，真的不舒服也可以暂停离开，没有道德扣分。

## 7. 本地 MVP 内部评审与执行结论（2026-11-17）

用户已授权：本会话评审后直接开发，不逐项等待选择，不开独立聊天。以下执行规则覆盖前文历史草案；PRD 保留，不修改其他项目。

### 7.1 三视角挑刺

- **产品**：强制以真心次数定所有最高评级会把维护边界变成低一等。保留“家族和平大使”的化解路线，另加“边界守护者”：反问是真诚拒绝或转题，不揭隐私、不拿第三人挡枪，优秀成绩同样能得上上签。暂停、离席不作道德判断。
- **玩法**：四句各 24~28 字，加题干约 110 字，按每秒 4~6 字阅读需约 18~28 秒，旧快题仅 9 秒不足。最多同时 2 题，第一次展示每题提供 8 秒免费读牌窗，冻结问题耐心与刷题；可提前出卡或点“读好了”。手动切回已看过的题不返还读窗。太极冷却 1.8 秒、出卡动画锁 0.35 秒在读窗仍推进，避免已开始冷却被冻住。主动暂停冻结所有时钟且可继续读牌；后台自动暂停。
- **前端**：24 张 AI 图、换皮框架、书法字体、域名备案与二维码都不是本地玩法前置条件。直接使用统一自制 SVG/CSS 人物、圆桌、灯笼、菜肴和纹样；系统字体；Web Audio 合成短音效，首次静音；无追踪、无后端。Canvas 输出真实 1080×1440 PNG，本地版明确“试玩战报 / 尚未发布”，不放假二维码或假公网地址。

### 7.2 冻结的实现数值与可达样例

- 4+5+4 题再接 1 个身份 Boss；第 2 波首题保证奶奶暖心。刷题间隔 8 / 7 / 6 秒，并发上限 1 / 2 / 2；倒计时普通 18、快题 16、难缠 20、暖心 24、追问 16、Boss 30 秒。没有额外波次加速；首页先展示玩法提示，第 1 题同样提供 8 秒免费读窗。每道新题最多一次 8 秒读窗，目标不因新题自动跳换。
- 太极伤害 1、无限；反问伤害 3、初始 3 张，仅让该亲戚下一道新题血量 +1，不缩短读秒，不叠加，不影响奶奶；真心初始 **3 张**，两次上菜都固定提供“真心 +1”，暖心先扣再返 1，心态 +20。普通真心直接化解 +250、+8心态，并招募一次性队友；已被激怒时清题并消气 +100、不招募。Boss 真心伤害 3、最后一击真心才 +500；反问末击同样是有分寸的有效解答。
- 发疯初始 3 张：40% 暴击伤害 3 + 全桌安静 3 秒，35% 普通伤害 2，25% 翻车伤害 0、心态 -10、分数 -30并排队一个追问；连续翻车两次后第三次必暴击。满桌不强塞追问，Boss 不被队友拦截。
- 太极独立清普通 / 难缠 / Boss 的就绪最短用时为 **1.8 / 3.6 / 7.2 秒**，最长正常耐心至少 16 秒；不靠随机暴击也能通关。冷却末段、同时两题和可耗尽的特殊卡保留轻策略，不用窄屏三题围攻制造难度。
- 和平可达样例：早期真心化解 2 题（500）各有一次队友拦截（300），奶奶真心化解（250，返卡并结盟），奶奶再拦 1 题（150），7 题普通挡下（700）、Boss 真心末击（500）、满心态（300）、零漏题（200）= **2900 分，14题结算、4次真心化解、3次拦截**。初始3张 + 任一上菜补1即可覆盖，奶奶净耗0。此路线写成实际引擎测试，不把公式当实测。
- 边界可达样例：3 次反问实际挡下，其余用太极，14题全挡（1400）+满心态（300）+零漏（200）= **1900 分**。完整通关且 ≥1800 分时，真心化解≥3且拦截≥2，或反问挡下≥3且漏题≤1，任一路线可得上上签 / 7天；高分但两路线未满足最多上签 / 6.5天，普通胜利并不要求最高评级。
- 真心不是承认盘问合理，更不承诺结婚、生育或披露收入；题库同时含温和拒绝、转话题和自嘲版本。输赢以完整吃完饭且心态大于0 / 心态归零为准，主动收席记真实未答，不伪装通关。
- 局长 2~3 分钟是目标而非硬截止。用时含免费读窗、不含主动暂停和奖励选择；不执行旧180秒强制收席，避免慢读者明明尚能答题却突然结算。奖励不自动替玩家选，提供喝汤+20、真心+1、发疯+1三项。
