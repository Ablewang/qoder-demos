## 1. 作品定位与背景

| 项目 | 当前内容 |
| --- | --- |
| 页面标题 | 几猫3A大作 |
| 标题画面 | 几猫 / 3A大作 |
| 类型 | 单人第一人称射击、目标推进与撤离 |
| 玩家身份 | 几猫突击小队队员；单兵行动，无人支援 |
| 地点 | 几猫港区 · 四号泊位，界面标识 B4 |
| 时间文案 | 05:42；这是固定文案，不是动态游戏时钟 |
| 危机 | 港区防御系统失控，主控封锁泊位 |
| 敌人 | 空中机械飞鸥、地面机械猎犬 |
| 核心任务 | 切断堆场、仓库、码头三处上行中继，突破封锁并登船撤离 |

工业港区包含集装箱堆场、仓库、码头、起重机、货船、撤离艇、围栏、设备和堆放杂物。湿地、海面、雨水、锈迹和工业标识构成视觉主题；低角度暖光与暗色天空并存，不能单凭色调推断为“黄昏”。

原始“项目介绍”里的 Fable5.2、国产 3A 等文字在重构中保留，但不是当前技术实现的证明。角色姓名、军衔、现实地理位置、完整战争背景均没有进一步实现，不应自行补写为既有设定。

源码：[页面标题](index.html#L9)、[标题与介绍文案](src/ui/menus.ts#L54)、[任务广播](src/game/index.ts#L52)、[天空与光照](src/config/world.ts#L11)。

### 指挥中心广播

- 开场：“几猫队员，这里是指挥中心。港区主控已封锁泊位。切断堆场、仓库、码头的三处中继。”
- 首次发现：“你已被发现！空中有机械飞鸥，地面有机械猎犬。消灭它们。”
- 第一处完成：“第一处中继已断开。敌方已察觉，机械守卫正在赶来。”
- 第二处完成：“第二处中继已断开。敌方正全力围攻，小心应对。”
- 全部完成：“三处中继全部断开！撤离艇在码头南端的舷梯旁，快撤！”
- 低生命：“伤势严重！找掩体躲避，稍作恢复。”
- 撤离：“几猫队员已登船，港区封锁解除。干得漂亮！”

广播通过 HUD 字幕队列呈现，不存在对应的语音朗读系统。“消灭它们”是广播指令，不代表必须全歼才可通关。

## 2. 任务与胜败条件

### 核心循环

`进入港区 → 寻找并切断中继 → 应对增援 → 三处全断 → 到达撤离艇 → 结算`

- 三处中继可任意顺序处理。
- 无须等待前一波敌人全部死亡再处理下一处。
- 没有任务超时失败条件；用时影响评级。
- 胜利：三处全断、玩家存活，并进入撤离判定范围。
- 失败：玩家生命降到 0。

### 切断中继的精确条件

| 条件 | 当前判定 |
| --- | --- |
| 中继状态 | 尚未切断 |
| 玩家状态 | 存活 |
| 水平距离 | 不大于 2.2 |
| 垂直高差 | 不大于 2.5 |
| 朝向 | 距离超过 0.9 时，水平朝向点积判定不小于 0.45；更近时不要求朝向 |
| 交互动作 | 持续按住 E 或触屏“交互” |
| 从零完成时间 | 约 2.4 秒 |
| 视线检测 | 没有遮挡射线检测 |

交互使用玩家与中继逻辑位置之间的距离，不是鼠标对中继模型的精确射线点击。多个目标都符合时选择最近的未完成目标。

松开按钮或失去距离/朝向条件时，内部进度以每秒 1.6 的归一化速度衰减，并非立即清零；从接近满进度衰减到零最多约 0.625 秒。退出切割状态时 HUD 会立即撤掉切割状态反馈，因此内部余量不一定在界面继续显示。受伤本身不打断交互；移动后仍满足条件可以继续。

完成后，中继有闪烁、熄灭及机械停止反馈，同时更新目标、广播、目标标记并安排增援。中继状态是任务机制，不是可任意破坏的全局供电模拟。

### 撤离

撤离艇逻辑位置为 `(29, 0, 20)`。满足以下条件即自动完成：

- 三处中继全部切断；
- 玩家存活；
- 水平距离严格小于 2.5；
- 垂直高差严格小于 3.5。

无需按 E、保持朝向、等待倒计时、清空敌人、实际登上船模型或完成攀梯动作。提前进入会提示“中继尚未断开，撤离艇无法在火力下接应”，提示有 8 秒重复冷却。

源码：[交互与撤离](src/game/index.ts#L713)、[切断后的处理](src/game/index.ts#L787)。

## 4. 操作说明

### PC 键盘与鼠标

| 操作 | 按键 | 说明 |
| --- | --- | --- |
| 移动 | W / A / S / D | 前、左、后、右，合成方向会归一化 |
| 视角 | 鼠标 | 默认请求浏览器指针锁 |
| 开火 | 鼠标左键 / Enter / 小键盘 Enter | 按住连续开火；标题页 Enter 可开始行动 |
| 瞄准 | 鼠标右键 | 按住 ADS，松开退出 |
| 换弹 | R | 满匣、无备用或换弹中不会重复开始 |
| 中继交互 | E | 按住完成 |
| 跳跃 | Space | 按下触发；没有普通键盘跳过开场的逻辑 |
| 冲刺 | 左/右 Shift | 还须满足前进、非蹲伏、非开火等条件 |
| 蹲伏 | C / 左/右 Ctrl | 按住蹲伏；头顶空间不足时无法站起 |
| 暂停 | Esc / P | 暂停面板；有子面板时优先关闭子面板 |
| 水平转向 | 左右方向键 / J、L | 键盘转向兜底 |
| 垂直转向 | 上下方向键 / I、K | 键盘转向兜底 |
| 近战映射 | F / V / 鼠标中键 | 仅有输入映射及菜单说明，没有玩家近战伤害实现 |
| 备用动作映射 | Q | 映射为 alt，但没有玩法消费；不是武器检视键 |

**指针锁限制：**未捕获时的首次鼠标按下用于请求锁定，不直接开火。浏览器不支持、拒绝或首次请求超时约 1200ms 时可降级到 drag 模式；曾经成功捕获后的失败行为不同。已经锁定后丢失指针锁会暂停游戏。

**drag 的实际行为：**鼠标移动即可转向，并不要求持续按住鼠标。光标接近边缘时还可持续转向。原菜单所写“按住鼠标按钮并拖动”不是完整描述，以实际输入实现为准。单次超过 400 像素的异常 movement 会丢弃。

源码：[键位与鼠标](src/input/index.ts#L4)、[锁定与降级](src/input/index.ts#L226)、[边缘转向](src/input/index.ts#L591)、[暂停](src/game/index.ts#L464)。

### Mobile / 触屏

首次触摸才启用触屏控件，不只依赖 UA 判断。触屏模式会退出指针锁。

| 操作 | 方式 |
| --- | --- |
| 移动 | 左侧约 45% 屏幕范围内按下，出现动态摇杆并滑动 |
| 视角 | 另一手指在右侧拖动 |
| 开火 | 按住“开火”；此手指拖动也能跟踪目标 |
| 瞄准 | 点击“瞄准”切换开/关，不是按住模式 |
| 换弹 | 点击“换弹” |
| 跳跃 | 点击“跳跃” |
| 中继交互 | 靠近可交互中继时显示“交互”，按住 |
| 冲刺 | 摇杆幅度大于 0.93 且前推量大于 0.8，自动提出冲刺请求 |
| 暂停 | 右上“暂停”按钮 |

- 动态摇杆半径 58px；摇杆、视角与开火各自跟踪触摸 identifier，支持同时操作。
- 主操作按钮布局偏右下，暂停右上，移动左下。
- 当前没有触屏蹲伏或玩家近战按钮；不应宣称触屏与键鼠按键一一齐全。
- 松开、touchcancel、失焦或停用玩法会清理动作；触屏 ADS 状态也会清理，避免卡住。
- 触摸后 800ms 内忽略合成鼠标事件，减少一次触摸触发两种输入的问题。
- 没有 `mobile=1`、`touch=1` 或 `drag=1` 强制模式 URL 参数。

源码：[触屏控件与多点输入](src/input/index.ts#L323)、[摇杆合成](src/input/index.ts#L609)。

| 操作 | 映射 |
| --- | --- |

| 跳跃 / 蹲伏 | A / B |

### 输入灵敏度基准

| 输入 | 基准计算 |
| --- | --- |
| 鼠标转向 | 每像素 0.0021 × 保存灵敏度 |
| 触屏转向 | 每像素 0.0052 × 保存灵敏度 |
| 键盘转向 | 水平 2.1 弧度/秒，垂直乘 0.6，不乘保存灵敏度 |
| 手柄转向 | 死区重映射后的 `轴值 × abs(轴值) × 3 × dt × 灵敏度`，垂直再乘 0.7 |
| drag 边缘持续转向 | 最大水平 2.4、垂直 1.2 弧度/秒，再乘灵敏度与边缘接近程度 |

玩家 ADS 还会把这些合成的视角输入按进度降至 0.6 倍。反转垂直视角应用于鼠标、触屏和手柄，不应用于键盘方向键。

源码：[输入常量](src/input/index.ts#L33)、[输入合成](src/input/index.ts#L591)。

## 5. 菜单与任务流程

| 状态 | 界面及行为 |
| --- | --- |
| title | 港区镜头巡游；“开始行动”“设置”“项目介绍”，窄屏另有操作说明 |
| intro | 首次约 3.5 秒，重试约 1.3 秒；淡入、地点卡、任务广播，普通流程等待结束；调试参数/API 可跳过 |
| playing | 玩家、武器、敌人及任务逻辑正常更新，任务时间累计 |
| paused | 隐藏玩法 HUD，显示继续、设置、操作说明、重新开始；玩法时间不累计 |
| dead | 玩家倒下、画面褪色变暗，约 1.5 秒后显示死亡面板 |
| complete | 已撤离、玩家无敌且停用控制，约 3.3 秒后显示行动简报 |

标题镜头配置速度 1.15、FOV 50；玩家基础 FOV 则为 74。进入游戏会采用玩法视野。

- 死亡面板显示生存时间与已切中继数量，提供“重试”。
- 结算显示评级、用时、命中率、摧毁机械数量和重试次数，提供“再次出击”。
- “重试”与暂停里的“重新开始任务”会增加重试计数，重置整局状态并走较短开场。
- 首次部署和结算后的再次部署会清零重试计数。
- 重置包含生命、位置、武器弹药、敌人、特效、战斗统计、中继状态、波次队列；不存在中继检查点。
- 页面隐藏时，正在玩的游戏会暂停；丢失已捕获的鼠标也会暂停。
- 设置/操作/介绍是子面板，支持关闭、Esc、Tab 焦点约束及焦点恢复。
- 新增：标题和暂停面板有“局域网联机”按钮，打开设置面板的“联机”页；入房后另有房间条，显示房主身份、人数及准备人数，可直接准备或由房主发起全员出击。仅正常游戏显示，展示/测试模式没有。见 [新增：局域网联机](#新增局域网联机)。

源码：[状态与开局](src/game/index.ts#L151)、[重置与开场](src/game/index.ts#L283)、[状态更新](src/game/index.ts#L892)、[菜单](src/ui/menus.ts#L76)。

## 6. 玩家与移动

### 生命与生存

| 参数 | 数值 / 规则 |
| --- | --- |
| 初始 / 最大生命 | 100 / 100 |
| 回复等待 | 最后受伤后超过 4 秒 |
| 回复速度 | 25 HP/秒，最多回到 100 |
| 低生命广播 | 生命小于 30 时每局首次提示 |
| 落水触发高度 | Y 小于海面 - 2.2，即小于 -3.8 |
| 落水处理 | 传回最近安全点、清速度、转身 π、扣 12 HP，可因此死亡 |
| 高速落地伤害 | 滞空超过 0.12 秒，落地冲击速度超过 13 时，伤害 `(速度 - 13) × 7` |

回血不要求静止、蹲伏或确实在掩体后。“找掩体恢复”是安全建议，不是检测条件。落水救援也不等于游泳系统；正常岸边另设防落水屏障。

### 尺寸与基础移动

| 参数 | 数值 |
| --- | --- |
| 站立胶囊高度 / 半径 | 1.8 / 0.32 |
| 蹲伏胶囊高度 | 1.15 |
| 站立 / 蹲伏眼高 | 1.68 / 1.05 |
| 步行 / 冲刺 / 蹲行速度 | 3.8 / 6.4 / 1.9 |
| ADS 速度上限 | 2.4，按 ADS 进度插值 |
| 完全后退倍率 | 0.82 |
| 地面加速 / 减速 | 34 / 26 |
| 空中加速 | 9 |
| 重力 | 21 |
| 设计跳跃顶点 | 约 1 |
| 起跳速度 | `sqrt(2 × 21 × 1)`，约 6.48 |
| 离地宽限 / 跳跃缓冲 | 0.12 / 0.13 秒 |
| 最大向下速度限制 | -40 |
| 自动跨台阶高度 | 0.42 |

提出冲刺请求还须前推量大于 0.55、横向量绝对值小于 0.6、非蹲伏、ADS 小于 0.35、未开火。冲刺状态在地面还取决于速度；离地可以延续。没有体力消耗、体力条或固定冲刺时限。

蹲伏时有足够站立空间才可站起。蹲着跳跃需要有站立空间，起跳后解除蹲伏。移动方向合成会归一化，不会因为斜向按两个键获得额外速度。

## 7. 步枪与战斗

### 武器基础

唯一武器为 **几猫九式突击步枪**。模型上的自动/半自动/保险刻字是外观，不存在供玩家切换的射击模式。

| 属性 | 数值 |
| --- | --- |
| 弹匣 | 30 发 |
| 初始备用弹 | 150 发 |
| 初始总弹量 | 180 发 |
| 射速 | 720 RPM，即 12 发/秒 |
| 单发基础伤害 | 26 |
| 玩家射线范围 | 300 |
| 非空换弹时长 | 2.1 秒 |
| 空仓换弹时长 | 2.72 秒 |
| 空仓扣扳机后自动换弹等待 | 0.32 秒，有备用时 |
| ADS 切入基础时长 | 0.18 秒 |

正常玩法没有弹药拾取，因此初始备用是有限资源。`addAmmo` API 的存在不表示地图提供补给。

### 换弹细节

- 满匣、没有备用或正在换弹时不开始。
- 约 1.345 秒的插入弹匣阶段实际补弹，补入数量为匣内空缺与备用数量的较小值。
- 非空换弹保留旧匣中的剩余弹药，不会丢弃。
- 空仓流程还包含枪机动作，结束时间更长。
- 没有玩家可操作的常规取消换弹流程；可以移动，不能在换弹中开火。
- 最后一发射出本身不会立刻自动换弹；空仓继续扣扳机产生干击反馈后才安排自动换弹。
- 从冲刺姿态过渡到射击需要武器放下程度达到阈值，并非冲刺状态下即时开火。
- 低帧率追赶射击每帧最多 3 发。

### 命中判定

玩家射击从眼睛进行瞬时射线：先找最近环境遮挡，再只在遮挡之前查询敌人，命中最近活敌。一发最多直接命中一个敌人。

- 不存在玩家子弹飞行时间、重力下坠、距离伤害衰减、贯穿墙体或穿透多个敌人。
- 枪口曳光、弹壳和枪口闪光是视觉反馈；枪口位置不是玩家伤害射线的起点。
- 正常玩家步枪伤害是 26。战斗通用函数默认值 28 不等于步枪伤害，因为步枪会显式传入 26。
- 飞鸥没有 weak 部位，常规命中为 26，45 HP 通常 2 发。
- 猎犬身体为 26，头部 weak 倍率为 2.2，即 57.2；140 HP 通常 6 发身体或 3 发弱点。
- 弱点是猎犬头骨附近半径 0.155 的近似球，不是所有镜片、灯或腿都有独立弱点。
- 飞鸥近似命中体为扁椭球，水平半径 0.5、垂直约 0.217；模型每个零件没有独立血量。

### 散布

散布为平滑后的弧度半角。令 `a` 为平滑 ADS、`v = clamp(速度 / 6, 0, 1)`、`b` 为连射扩散：

```text
目标散布 = lerp(0.0125, 0.0012, a)
         + v × lerp(0.013, 0.004, a)
         + b × lerp(0.0065, 0.0022, a)
         + (离地 ? 0.022 : 0)
         - (蹲伏 ? 0.002 × (1 - a) : 0)
```

- 平滑速率 18；每发连射扩散增加 0.17，上限 1，以 1.5/秒衰减。
- 静止站立腰射基础 0.0125，完整 ADS 基础 0.0012。
- 蹲伏直接减少腰射散布，完整 ADS 下该项归零。
- 运动、跳跃、长连射均增加散布；不能用准星贴中目标来保证射线必命中。

### 后坐、烟雾与检视

- 基础仰角后坐 0.0068；前 9 发系数 1，之后 0.38。
- ADS 乘 0.55，蹲伏乘 0.85，另乘 0.85 到 1.15 的随机系数，并带横向后坐。
- 后坐 35% 留在实际视角，65% 用弹性偏移恢复，停止射击不会完全自动回到最初准点。
- 枪热每发累积，控制停火后的枪口烟雾，没有过热锁枪或热伤害机制。
- 闲置超过 24 秒自动进行约 3.5 秒检视；移动、转视角、瞄准、开火、换弹和冲刺会让它退出。I、Q 不是手动检视键。

源码：[武器名称](src/weapon/geometry.ts#L294)、[基础参数](src/weapon/index.ts#L33)、[换弹与射击](src/weapon/index.ts#L564)、[散布与自动检视](src/weapon/index.ts#L789)、[伤害判定](src/combat/index.ts#L19)。

## 10. 结算与评分

### 统计口径

- 用时只累积 `playing`，不计标题、开场、暂停和结算等待。
- `shots`：真正发出的玩家射击次数，不是扣扳机次数。
- `hits`：玩家射线直接命中敌人的次数。
- 命中率为 `hits / shots`，夹紧到 0 到 1；零发时为 null，显示时按结算格式处理。
- `kills`：收到敌人死亡事件的数量，包括飞鸥爆炸连锁，不另校验最后一击归属。
- 重试重新统计本局射击/命中/击杀；重试计数按部署流程保留或清零。

### 评分公式

总分为以下三项之和，范围 0 到 5：

| 指标 | 得分 |
| --- | --- |
| 用时小于 270 秒 | 2 |
| 用时不小于 270、但小于 400 秒 | 1 |
| 用时不小于 400 秒 | 0 |
| 命中率不小于 50% | 2 |
| 命中率不小于 30%、但小于 50% | 1 |
| 命中率小于 30% 或未开枪 | 0 |
| 重试次数为 0 | 1 |
| 有重试 | 0 |

| 总分 | 评级 |
| --- | --- |
| 0 | 险象环生 |
| 1 | 火力全开 |
| 2 | 稳扎稳打 |
| 3 | 干净利落 |
| 4 | 精准果断 |
| 5 | 完美突击 |

击杀数、剩余生命、备用弹量和中继顺序不单独参与评分。正好 270 秒进入 1 分时间档，正好 400 秒为 0 分时间档。

源码：[战斗统计](src/combat/index.ts#L5)、[评分与结算](src/game/index.ts#L846)。

## 12. 设置与兼容

### 可保存的设置

以下设置归属于当前本地玩家，保存在 IndexedDB 的 `saltline.userdata` 数据库中。首次使用会迁移旧 `localStorage` 键 `saltline.settings.v1` 的值；旧键只保留作备份，新设置不再写入 localStorage。

| 设置 | 默认 | 范围 / 操作 |
| --- | --- | --- |
| 画质 | auto，按设备探测 | 菜单可选低、中、高、极高；菜单没有 auto/test 按钮 |
| 灵敏度 | 1 | 0.2 到 3，步长 0.05；实际也影响触屏和手柄 |
| 垂直反转 | 关闭 | 影响鼠标、触屏和手柄，不影响键盘转向 |
| 主音量 | 80% | UI 0 到 100%，内部 0 到 1 |
| 基础视野 | 74° | 菜单 60° 到 95°，步长 1 |
| 全屏 | 不保存 | 支持时提供标准或 webkit 全屏切换，不支持时隐藏 |

只有 IndexedDB 事务提交完成才显示已保存；数据库不可用或写入失败会明确显示提示，不会伪装持久化成功。游戏仍可体验，但未保存数据可能丢失。已保存画质通常在启动应用，但非空 URL `q` 或 `shot` 会保护初始参数；玩家显式点击画质仍可改变它。

### 新增：本地玩家档案

标题、暂停、死亡和结算菜单都有“玩家档案”入口，设置面板也有档案标签。首次访问自动创建一个本地玩家，带稳定用户 ID、默认昵称“几猫队员”和创建时间。昵称可修改，去除首尾空白后长度为 1–24。

档案显示已结算行动数、成功/失败次数、累计摧毁机械、开火数、累计命中率、累计行动时间、最快撤离、最佳胜利命中率，以及最近 20 场行动。每条战绩保存结果、结算时间、用时、射击/命中/击杀数、重试次数、中继进度和胜利评级；完整历史保存在数据库，不只保存屏幕显示的 20 条。

- 死亡与成功撤离分别记录一场，同一行动 ID 不重复累加。
- 累计命中率按总命中数/总射击数计算，不平均每场百分比；零射击为“—”。
- 最快撤离及最佳胜利命中率只更新成功行动；单场重试次数仍遵循原规则，不重复累计成全局重试数。
- 暂停重开、关闭页面及尚未结束的任务不算已结算行动，也不保存可继续的现场。
- showcase、bench 和 shot 截图模式不记录正常战绩，避免演示测试污染数据。
- 这是新增本地用户概念，不是账号登录；没有密码、服务器或跨设备同步。清除网站数据、换浏览器或换 origin 不会自动恢复同一档案。

菜单上的本地存储状态行（如“IndexedDB · 本地数据已保存”）只在菜单打开时显示，游戏进行中隐藏。

数据库结构、迁移和统计口径见 [本地用户数据参考](DEVELOPMENT.md#12-本地用户数据indexeddb)。

### 新增：局域网联机

原游戏是单人的。新增的局域网联机让同一 Wi-Fi 下 2–4 人进入同一个房间，在各自画面里看到队友。

**怎么开局**

1. 一台电脑在项目目录运行 `pnpm lan`，终端会列出 `http://局域网IP:4207` 地址。
2. 所有人（包括主机自己）用浏览器打开这个地址；电脑、手机都可以。
3. 一人在标题或暂停菜单点“局域网联机”→“创建房间（成为房主）”，得到 4 位房间号，如 `K7QM`。运行服务的电脑不必是房主，创建者才是房主。
4. 其他人在同一页输入房间号点“加入”。字母自动大写，易混的 I、L、O、0、1 不会出现在房间号里。
5. 非房主点“准备”（可点“取消准备”）；房主无需准备，其他成员全部准备后点“全员出击”。也可通过标题/暂停房间条准备或出击。入房后原开始/重试按钮也使用此流程，离房后恢复原单人操作。
6. 全队显示 3 秒倒计时，结束后自动重置并开始各自任务，仍走原开场，无须各自点“开始行动”。自动出击不强制鼠标锁定，电脑端首次点击再请求锁定；触屏照常操作。

**房主管理与房间状态**

- 成员列表标明“房主”“已准备/未准备”；房主可对其他成员点“移出”或“设为房主”，需在 3 秒内再次点击“确认移出/确认移交”才执行。
- 被移出的队员看到“你已被房主移出房间”，退出联机，但本地游戏继续。
- 房主离开或断线后，剩余槽位最小的队员自动继任；手动移交和自动继任都会清除新房主的准备状态。最后一人离开则房间删除。
- 房间分为“等待出击”（`lobby`）与“行动中”（`mission`）；房主出击时清除全员准备。自出击起超过 10 秒（3 秒倒计时 + 7000ms 保护期），且所有成员当前都为 `idle`（如已结算）时，服务自动回到等待出击；暂停和倒地不算 `idle`。

**能看到什么**

- 队友是无外部资源的程序化关节士兵，含髋、膝、脚、脊柱、头和持枪关节，配有圆角护甲、迷彩织物、肩甲、头盔、弹袋、背包和步枪；按槽位以橙、蓝、绿、粉饰条区分，空槽可复用。头顶显示档案昵称，房主另有标记。
- 同步位置、朝向、蹲伏、倒地及开火标记；模型根据移动和俯仰表现步行、冲刺、屈膝蹲伏、持枪瞄准、后坐力、枪口闪光与倒地，不再整体压缩身体模拟蹲伏。队友暂停时位置不动，在标题、开场或结算时隐藏。
- 标题/暂停房间条显示房间号、人数、准备人数及房主身份；画面一角徽标显示“房主”（仅自己为房主时）或“联机”、房间号、人数和延迟。触屏窄屏仅显示房间号和人数。
- 在档案中改昵称，房间里其他人会立即看到新名字。

**规则不变的部分**

- 敌人、射击、生命、增援波次、中继进度和撤离全部在每个人自己的设备上运行，与原版单人完全相同。
- 可以看到队友开火的枪口闪光与后坐力，但这是表现，不是共享子弹或伤害；你看不到队友的敌人，打不中也救不了队友，队友切断的中继不会算到你头上。
- 每个人的结算和战绩仍写入自己的玩家档案。

**常见问题**

- 显示“无法连接联机服务”：确认主机仍在运行 `pnpm lan`，设备在同一网络，且主机防火墙允许 Node 的入站连接。
- 房间已满：每房最多 4 人。
- 服务关掉或断线时会提示“与联机服务的连接已断开”，单人游戏照常继续。
- 房间只存在于服务进程内存中，主机重启服务后需要重新建房。

### 兼容策略与限制

- `viewport-fit=cover` 和 safe-area 处理刘海/圆角屏。
- 窄屏不超过 760px、短屏不超过 520px 时压缩菜单布局，触屏 HUD 另行定位。
- 横竖屏都保留适配，没有强制锁定方向；横屏通常更适合同时移动、转向和射击。
- 键鼠锁定失败有替代输入，音频解锁依赖浏览器用户手势，全屏依赖平台能力。
- 移动设备默认低画质。复杂场景的性能仍取决于 GPU、像素比、驱动和浏览器，不能保证任意手机相同 FPS。
- 已有 PC Chrome 与模拟移动端验证；不等于真机 iOS Safari 和所有 Android 机型认证。

## 13. 视听设定与功能边界

### 画面与声音

- Three.js 程序化建模生成港区、步枪、机械敌人和道具；不是依赖外部商业模型包的完整 AAA 资产管线。
- 材质包含金属、涂装、锈迹、混凝土、木材、塑料、橡胶、布料、纸箱及湿润效果。
- 地面、海面、雨、积水反射、阴影、环境光遮蔽、体积光、泛光、曝光与镜头效果共同构成画面。
- 仓库与室外有不同环境/混响，武器湿润会随是否进入仓库逐渐变化。
- 枪声、脚步、换弹、敌人、环境和音乐由 Web Audio 在运行时合成，不是外部配音与音频素材库。
- 音乐强度在巡逻、接触、波次与撤离阶段变化；暂停和后台行为由音频系统管理。
- 视觉残骸、火花、弹壳与粒子不自动代表可拾取或可互动对象。

更详细的图形与音频机制见 [开发与参数参考](DEVELOPMENT.md)。

### 当前没有的功能

| 容易误解的项目 | 真实边界 |
| --- | --- |
| 玩家近战 | 菜单、输入、音频订阅有相关名称，但没有正常玩法攻击发起/伤害实现 |
| 手动检视 | 只有闲置自动检视；Q 是未消费的备用动作 |
| 玩家护甲 | 没有护甲值或独立护甲条；敌人装甲外观不等于玩家护甲系统 |
| 冲刺体力 / 滑铲 | 没有；只有冲刺与蹲伏 |
| 双跳 / 专用翻越 / 攀梯 | 没有；现有普通跳跃、台阶跨越和楼梯碰撞 |
| 换枪 / 附件 / 升级 / 技能树 | 没有；只有一把步枪 |
| 医疗包 / 弹药掉落 / 拾取 | 没有正常玩法；heal/addAmmo API 不代表已接入地图 |
| 载具驾驶 / 泳行 | 没有；叉车、船只主要是场景或任务表现 |
| 玩家爆炸武器 / 手雷 | 没有；爆炸伤害当前主要来自飞鸥死亡 |
| 独立敌人部件血条 | 没有；仅近似身体/弱点命中与整体生命 |
| 多关卡 / 检查点 / 任务现场存档 | 没有；一张地图，重试重开；新增 IndexedDB 保存档案、设置与战绩，不保存正在玩的现场 |
| 多人 / 联网服务器 | 原版没有；新增局域网联机（2–4 人），房主统一出击，可准备、移交房主及移出成员，关节士兵同步位置/姿态/开火表现；敌人、伤害和任务仍各端独立，没有公网匹配、共享敌人、队友伤害或救援 |
| 本地用户数据库 | 新增 IndexedDB：单个玩家档案、设置、累计统计与结算战绩 |
| 动态昼夜 / 时钟 / 天气任务 | 没有此类玩法；固定时间文案和程序化天气表现 |
| 无尽生存 | 不是；三波任务增援和最多五只追兵 |
| 动态语音广播 | 没有；指挥中心信息为字幕 |

这些边界是原文件行为的一部分。若后续开发增加上述能力，应同步调整文档，不能把保留的原文案当成功能已完成。

## 14. 新手行动建议

以下是基于规则的建议，不是强制路线或隐藏机制：

1. 第一次先选适合设备的画质，并确认键鼠捕获或触屏按钮正常。
2. 从西门进入后按目标标记寻找中继；若标记不见，先退出 ADS。
3. 充分利用环境射线遮挡；超过 4 秒没有新伤害即可回血，不用找特定治疗点。
4. 对飞鸥使用短点射；对猎犬尽量瞄准头部弱点，避免浪费唯一备用弹量。
5. 换弹前移到安全位置；空仓换弹较慢，不要误以为最后一发后会自动立即换。
6. 交互时靠近并面向中继，保持约 2.4 秒；移动或受伤本身不必然中断，但离开条件会让进度衰减。
7. 切断第三处后立即查看撤离方向；无需全歼，持续追兵只会增加风险。
8. 追求“完美突击”需用时小于 270 秒、命中率至少 50%、当前部署没有重试；击杀最多并不是评分条件。
